# ZNSV Studio — 八通道称重变送器上位机（mmhand 工程副本）

> **副本说明（2026-10-28）**：本目录自「最简控制器搭建」工程 `desktop/znsv_app/`
> 原样搬运至 mmhand 工程，仅改包内导入（`desktop.znsv_app.*` → `znsv_app.*`、
> CRC 独立为 `znsv_app/crc16.py`）与路径。原始交付报告见本目录
> `代码交付报告.md`。后续将把 `znsv.py` 驱动接入 mmhand_scope 的张力链（COM23）。

ZNSV6-F8-485 八通道数字称重变送器的独立上位机，深色现代风格界面；
协议驱动为 `znsv_app/znsv.py`，协议说明书副本在 `docs/`。

## 启动

本机已装好工程 `.venv`：双击本目录 `启动ZNSV上位机.cmd`。
调试运行：`.venv\Scripts\python znsv_app/main.py`（从仓库根目录）。

⚠️ COM23 同一时刻只能被一个程序打开：本应用与 mmhand 示波器张力窗、
以及「最简控制器搭建」原工程里的 ZNSV Studio 不能同时连接同一串口。

## 界面

- **总览**：连接区（串口 / 波特 2400–600000 / 地址 1–254 / 目标 1–50 Hz）、
  8 张通道卡（大数值、raw、窗口 min/max、迷你走势）、温度与模块信息卡、链路状态卡。
- **曲线**：八通道实时大图表，纵轴自适应、时间窗口 5–180 s 可调、
  点击图例圆点开关通道、清空曲线。
- **通道操作**：数值表 + 每路零点校准/去皮、全部去皮归零、CSV 记录、事件日志。
- **设置**：小数位（显示值 = 原始值 / 10^小数位）与单位文字、协议速览。

## 使用要点

1. 接好 USB/RS485 → 总览页「刷新」选端口 → 连接（默认 115200 / 地址 1 / 20 Hz）。
   拨码非全零时实际站地址可能不同，读不到可改地址 254（广播，总线只能挂这一台）。
   **选择即所读**：应用只读你在下拉框里选中的串口；串口、波特、地址、频率、小数位、
   单位、曲线窗口都会记住（`settings.json`，连接成功与修改时保存，重启自动恢复选中，
   不会自动连接）。
2. **通道开关**：每张通道卡右上角有独立开关（曲线页图例圆点点击等效，二者同步）。
   关闭的通道：卡片变灰显示"已关闭"、曲线不画、表格置灰、零点/去皮按钮禁用；
   读取与 CSV 记录仍包含八路原始数据，重新打开即恢复。开关状态记入习惯（settings.json）。
3. **本地零位**：总览页「设为零位」把最新一帧原始值记为零点，之后显示值、曲线、
   min/max、CSV 的"显示值"列全部变为相对值（= 原始值 − 零位）；raw 列保持绝对读数。
   「清除零位」恢复绝对显示。零位只存在电脑内存，不写传感器寄存器，重启应用后清除；
   设零时曲线从新基线重新开始。
4. **换算系数**：设置页「换算系数」，显示值 =（原始值 − 零位）/ 10^小数位 × 系数，
   默认 1.0 不换算；校准方法：挂已知重量，新系数 = 期望读数 ÷ 当前读数 × 现系数。
5. **自动连接**：设置页「启动时自动连接上次串口」，启动后 0.3 s 自动连接；
   上次串口不在当前列表或打开失败时只记事件日志，不弹窗。
6. 数据年龄 / 帧率 / 超时 / 错帧显示在右下状态栏与总览链路卡；超时自动重试，串口异常才断开。
   恒 0 通道（采样足够多仍无任何非零）的卡片会自动变灰并标注「疑似未接」。
7. 写操作只有零点校准与去皮：零点校准需确认且必须空载（会覆盖零点标定）；
   不提供恢复出厂（0x0026←9 会清除全部校准）。
8. CSV：每帧时间戳、序号、8 路 raw 与显示值（含零位与系数换算）、温度；停止或断开自动落盘。
9. 通道体检：`.venv\Scripts\python znsv_app/channel_scan.py COM23 --seconds 3`
   判定哪些通道真的接了传感器；`--watch --seconds 40` 实时观察拉绳时哪个通道在动。

## 备注

- 温度按 0.1 °C 解释（说明书只给范围 0~1800、减 550）；实机不符改 `znsv.temperature_c`。
- 通道映射（mmhand 侧张力链）：2026-10-28 用户实机确认 **C1↔CH1、C2↔CH2、C3↔CH3**
  （mmhand_scope.py 常量 `TENSION_CH_FOR_CABLE=(1,2,3)`）；原工程体检报告曾测得
  传感器落逻辑通道 1/5/7，与本机确认不一致，以本机为准。换算系数 −0.009806650
  （raw g→N，受拉为正）。
