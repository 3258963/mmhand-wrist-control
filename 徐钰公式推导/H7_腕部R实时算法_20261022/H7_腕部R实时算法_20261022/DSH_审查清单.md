# DSH独立审核定位表

| 层次 | 必查内容 | 主要文件 |
|---|---|---|
| 几何 | 点归属、轴线、坐标和正转方向；本版两轴解耦成立条件 | data/geometry_source.json、算法说明.md |
| 常量生成 | e1/e2/a右手正交、轴向h、长度单位m、C2/C3修正版 | tools/generate_model.py、src/wrist_default_model.c |
| 单精度稳定性 | 差向量平方和与α/β/γ公式等价；短段误差 | src/wrist_r.c |
| API | 物理rad、deg、原始encoder rad三入口不得重复校正 | src/wrist_r.h、src/wrist_r.c |
| 失效行为 | 任一硬错误使整个R失效为NaN，无默认沿用上一帧 | src/wrist_r.c、tests/selftest.c |
| 预紧与秩 | 行归一化、叉积、统一符号、数值阈值、条件数 | src/wrist_r.c |
| 参数状态 | 未标定/门限未确认默认不能通过几何门限 | 默认参数与selftest |
| 独立对照 | 双精度3D轴向力矩路线，不以生产投影常数作真值 | tools/verify_host.py |
| 数据版本 | 源几何/R表SHA256；改几何后不能沿用旧CAD表 | data/reference_manifest.json |
| 实时性 | 完整API计时、数学库、FPU/ABI、Cache、中断影响 | README、examples |

代码的数值目标是主机软件核对，不是实机精度承诺。低pitch关注区来自当前CAD版本；确认门限需要实测不确定度与允许误差。主机编译通过不能替代H7目标项目编译、链接和执行时间验证。

审查时请重点挑战：

- 极端/非有限配置能否误通过；初始化失败后旧上下文能否继续使用；指针参数错误是否安全返回。
- 几何求值成功但诊断失败时，geometry_gate_passed能否错误为true。
- 段长门限在刚好等于阈值、低于阈值、未设置、部分设置、确认位矛盾等情形的行为。
- 角范围边界与float舍入；输入度当成rad是否能被发现，实际范围内数值巧合是否仍需接口约定。
- 正零空间元素接近0、两行近共线、全零行时的数值行为。
- fast-math、FMA/收缩、数学库替换、目标FTZ行为可能造成的变化；逐项给实际运行证据或未验证说明。

当前C代码只输出R及诊断，项目控制器需另外处理张力上下限、负载、传感器状态和失效策略。默认未实机标定标志不能被审查过程“修复”为已标定。
