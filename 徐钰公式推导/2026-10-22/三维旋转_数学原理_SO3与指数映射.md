> 上一篇（`三维旋转矩阵_绕ZXY轴_原理讲解.md`）讲的是"**怎么算**"：两角和公式 → 2×2 方块 → 摆进 3×3。

## 0. 全篇就一条链

```
        ┌─ 刚体转动：长度、夹角不变
        │
        ├─ 保长 ⇒ 线性 + 保内积 ⇒ R^T R = I        （第 1 节，图 5）
        │
        ├─ det = ±1，取 +1 ⇒ 旋转（−1 是镜像）
        │
        ├─ 正交 ⇒ 必有特征值 +1 ⇒ 一定有"不动的轴"  （第 2 节）
        │
        ├─ 对时间求导 ⇒ 反对称矩阵 so(3) ⇒ 角速度 ω （第 3 节，图 6）
        │
        ├─ 指数映射 exp(θ[â]×) ⇒ Rodrigues 公式      （第 4 节）
        │

```

记住这条链，后面所有公式都是它的推论；而绕 Z/X/Y 的三个矩阵，只是第 4 节公式在 â = e_z、e_x、e_y 处的**三个特例**。

## 1. 旋转 = 保长的线性变换 ⇒ 正交矩阵

### 1.1 先把"转动"翻译成映射

刚体绕原点转一下：刚体上每一点 x 跑到新位置 f(x)。转动有两个不会变的性质：

```
|f(x)| = |x|                     （到原点的距离不变）
|f(x) − f(y)| = |x − y|          （任意两点距离不变）
f(0) = 0                         （原点不动，纯转动）
```

### 1.2 这三条能推出"f 是线性的"，不是假设

先由 1.1 的保距得到**保内积**（极化恒等式）：

```
⟨x, y⟩ = ( |x+y|² − |x−y|² ) / 4
```

因为 f 保长，`|f(x+y)| = |x+y|`、`|f(x−y)| = |x−y|`，所以 `⟨f(x), f(y)⟩ = ⟨x, y⟩`。

再验证 f 保加法：把 `|f(x+y) − f(x) − f(y)|²` 展开，用上面的保内积逐项替换，结果恒等于 0。
于是 `f(x+y) = f(x) + f(y)`；同理 `f(λx) = λf(x)`。**所以转动一定是线性映射，一定能写成矩阵 R。**

### 1.3 保内积 ⇔ R^T R = I

```
⟨Rx, Ry⟩ = (Rx)^T (Ry) = x^T R^T R y
要它恒等于 x^T y（对任意 x, y） ⇒ R^T R = I
```

这就是**正交矩阵**。写开来是"**列向量两两正交、长度都是 1**"：

```
R = [r1 r2 r3]  ⇒  r_i · r_j = δ_ij
```

（图 5 右边：R 的第 j 列就是 `R·e_j`，即第 j 根坐标轴转完之后的位置。）

### 1.4 六条立刻能用的推论

| 推论 | 理由 |
|---|---|
| `R⁻¹ = R^T` | 两边乘 R⁻¹ 即得；**转回去 = 转置**，永远不用求逆 |
| 行向量也两两正交、长度 1 | `R R^T = I` 同理由 R 满秩得到 |
| `det R = ±1` | `det(R^T R) = det²R = det I = 1` |
| 特征值模都是 1 | 保长 ⇒ 特征向量的模不变 ⇒ 特征值只能落在单位圆上（λ = e^{iφ}） |
| 保长度、保夹角、保体积 | 就是 1.2 的结论，再加上 det 的绝对值 = 1 |
| 两个旋转相乘还是旋转 | 正交性封闭：`(R1R2)^T(R1R2) = I` |

### 1.5 det = −1 不是旋转，是镜像

```
diag(1, 1, −1)    关于 xy 平面反射：长度、夹角全都保持，但左右手被调换了
```

所以"保持形状"还不够，必须再加一条 `det = +1`，才排除镜像。
**全体 det = +1 的正交矩阵记作 SO(3)**，这才是"三维旋转"的严格定义。

## 2. 为什么一定有"不动的轴"（特征值 +1）

### 2.1 一行代数就证完

```
det(R − I) = det(R)·det(I − R⁻¹)        （提出 R）
           = det(I − R^T)               （R⁻¹ = R^T，det R = 1）
           = det((I − R)^T) = det(I − R)
           = det(−(R − I)) = (−1)³ det(R − I)
           = −det(R − I)
```

`det(R − I) = −det(R − I)` ⇒ `det(R − I) = 0` ⇒ 方程 `(R − I)v = 0` 有非零解 ⇒ **存在 v 使 Rv = v**。

这个 v 就是转轴：它**一动不动**。（图 2 里那条紫色粗线。）

> 直觉版：三维里转东西，总得有一根轴；从代数上看，就是"特征值 +1 一定存在"。
> 反过来，二维就不成立（绕 z 轴转 90° 在平面里没有不动方向）—— 这正是"三维比二维多一个特征值"的体现。

### 2.2 另外两个特征值告诉你"转了多少度"

绕 â 转 θ 的矩阵，特征值是：

```
λ1 = 1,  λ2 = e^{+iθ},  λ3 = e^{−iθ}
```

（实矩阵的复特征值成共轭出现，而 `1 + 2cosθ` 就是迹。）于是有**从矩阵直接读角度**的公式：

```
cos θ = ( tr R − 1 ) / 2        ⇒   θ = arccos( (tr R − 1)/2 )
```

### 2.3 转轴也能从矩阵里直接读出来

把 Rodrigues 公式（第 4 节）的对称部分减掉，只剩反对称部分：

```
R − R^T = 2 sinθ · [â]×

⇒  [â]× = (R − R^T) / (2 sinθ)
⇒  â = ( R32 − R23,  R13 − R31,  R21 − R12 ) / (2 sinθ)
```

**θ = 0 或 θ = π 时 sinθ = 0**，这个式子退化，得改用特征向量求 â —— 这是代码里最常见的坑之一。

数值验证（â = (1,2,3)/√14，θ = 37°）：

```
det R = 1.0                     正交误差 max|R^T R − I| = 5.2e-17
trace 反解 θ = 37.0°            反对称部分反解 â = (0.267261, 0.534522, 0.801784)  ✓
```

## 3. 无穷小视角：角速度、叉乘、so(3)

### 3.1 对时间求导，必得反对称矩阵

旋转是连续发生的，把 R 看成 R(t)。由 `R^T R = I` 对 t 求导：

```
(dR/dt)^T·R + R^T·(dR/dt) = 0
```

令 `Ω = (dR/dt)·R^T`，则 `Ω^T = −Ω`。**反对称矩阵只有 3 个独立元素**，正好装一个三维向量：

```
Ω = [ω]× = [   0   −ωz   ωy ]
           [  ωz     0   −ωx ]
           [ −ωy    ωx     0  ]
```

### 3.2 它就是叉乘

对任意 r，`[ω]× · r = ω × r`。代入分量可以逐项验：

```
ω × r = ( ωy·rz − ωz·ry,  ωz·rx − ωx·rz,  ωx·ry − ωy·rx )
```

和矩阵乘法完全一致。于是"旋转的瞬时版本"就是**叉乘**：

```
dR/dt = [ω]× · R          v = ω × r
```

（图 6 左边：v 同时垂直于 ω 和 r，`|v| = ω·|r|·sin∠(ω,r)`。）

### 3.3 为什么矩阵里会有 sin 和 cos

设 â 是单位轴，`K = [â]×`。它有个漂亮的性质：

```
K² = ââ^T − I          （投影到 â 的矩阵减单位阵）
K³ = −K                （再乘一次 K 就回到 −K）
```

于是指数级数每三项就循环一次，正弦余弦就是这么冒出来的（下一节）：

```
exp(θK) = I + θK + θ²K²/2! + θ³K³/3! + …
        = I + (θ − θ³/3! + …)K + (θ²/2! − θ⁴/4! + …)K²
        = I + sinθ · K + (1 − cosθ) · K²
```

**结论：sin/cos 不是"角度投影"的巧合，而是 `K³ = −K` 让级数周期化的结果。**
绕坐标轴时矩阵里只剩 sin/cos，是因为那时 K 的元素只有 0 和 ±1；一般轴下还会多出 `(1−cosθ)·a_i a_j` 这种二次项。

## 4. 指数映射：从角速度积到转角（Rodrigues 公式）

### 4.1 解一个微分方程

```
dR/dt = [ω]× · R,   R(0) = I    ⇒    R(t) = exp( t·[ω]× )
```

令 `θ = |ω|·t`（转过的角度）、`â = ω/|ω|`（轴），代入 3.3 的三条性质：

```
R(â, θ) = I + sinθ·[â]× + (1 − cosθ)·[â]×²
```

这就是 **Rodrigues 公式**。

### 4.2 写成矩阵（一般轴的通式）

记 `c = cosθ, s = sinθ, C = 1 − c`，`â = (a1, a2, a3)`：

```
        [ c + a1²C        a1a2C − a3s     a1a3C + a2s ]
R(â,θ)= [ a2a1C + a3s     c + a2²C        a2a3C − a1s ]
        [ a3a1C − a2s     a3a2C + a1s     c + a3²C    ]
```

三件事一眼可见：

1. 对角是 `c + a_i²C`，**不是单纯的 cos**；
2. 非对角是"对称的 `a_i a_j C`" 加 "反对称的 ±s"；
3. 只有当 â 是坐标轴时，`a_i a_j` 全为 0，才退化成上一篇那三个"只有 sin/cos 和 1"的矩阵。

### 4.3 三个特例（把上一篇的结论收编）

| â | a₁ a₂ a₃ | 退化成 | 关键项从哪来 |
|---|---|---|---|
| e_z | 0 0 1 | Rz(θ) | `R12 = a1a2C − a3s = −s`，`R21 = +s` |
| e_x | 1 0 0 | Rx(θ) | `R23 = a2a3C − a1s = −s`，`R32 = +s` |
| e_y | 0 1 0 | Ry(θ) | `R13 = a1a3C + a2s = +s`，`R31 = −s` |

**这就彻底解释了上一篇里"Ry 的符号为什么反"**：不是记号问题，而是通式里 `R13` 那一项的系数是 `+a2·s`，
当 â = e_y（a2 = 1）时它就是 **+s**；而 `R12` 那一项是 `−a3·s`，绕 z 时 a3 = 1 所以是 **−s**。
符号的来处是同一个，只是藏在 ε 张量的指标里。

数值验证（â = (1,2,3)/√14，θ = 37°）：

```
R = [  0.813019  −0.453759   0.364833 ]
    [  0.511292   0.856168  −0.074543 ]
    [ −0.278534   0.247141   0.928084 ]

与 "级数逐项累加 40 项" 相比：max|R_rodrigues − R_series| = 2.2e-16
â = e_z, θ = 90° 代入通式，正好得到 Rz(90°) = [[0,−1,0],[1,0,0],[0,0,1]]  ✓
```

### 4.4 反方向：从矩阵回到"轴 + 角"

```
θ  = arccos( (tr R − 1)/2 )                    ← 2.2 节
â  = (R32−R23, R13−R31, R21−R12) / (2 sinθ)    ← 2.3 节
```

这就是 `R ↔ (â, θ)` 的互转，姿态误差、插值、日志映射（log map）都靠它。
θ = π 时退化，需要单独处理（用 `R + I` 的列、或特征分解）。

## 5. 群的观点：SO(3)、不可交换、以及那个"球"

### 5.1 SO(3) 是个群

| 性质 | 体现 |
|---|---|
| 封闭 | 两个旋转相乘还是旋转（`R1R2` 仍正交、det = 1） |
| 结合律 | `(R1R2)R3 = R1(R2R3)`，所以写法里可以省括号 |
| 单位元 | `I`（不转） |
| 逆元 | `R^T`（转回去） |

**但一般没有交换律**：`R1R2 ≠ R2R1`。

### 5.2 不可交换的几何原因

`R2·R1` 的意思是"先 R1 再 R2"。关键在于：**R2 的转轴是在 R1 之后才被转走的**。
先绕 z 转 90°，"+x 轴"就跑到了 +y 的位置；这时再"绕 x 转 90°"，转的已经不是原来那根 x 了。
换顺序，第二根轴的位置就不一样，结果自然不同（图 4 里两个三脚架）。

### 5.3 共轭 = 换轴（很常用的一个恒等式）

```
R · R_â(θ) · R^T  =  R_{Râ}(θ)
```

意思：**"绕 â 转"经过一次换基 R 之后，变成"绕 Râ 转"**。
这正是"姿态矩阵换参考系"的数学根据：`R' = Q R Q^T`。

### 5.4 欧拉角为什么一定有奇异（万向锁）

3 个角度只是 SO(3) 的一个**局部坐标卡**。用 (α, β, γ) 三个数去标记旋转时：

- 中间那个角到 ±90° 时，另外两个角转的是同一根轴（两个自由度塌成一个），
  从角度到矩阵的映射**雅可比退化**；
- 这不是"公式没写好"，而是拓扑决定的：SO(3) 是**紧**的（有界的球），
  R³ 里的一个开集盖不住它，**任何** 3 参数坐标都必然在某处退化。

### 5.5 图 7：把 SO(3) 画成一个球

把"绕 â 转 θ"记成向量 `θ·â`，它的终点就是半径为 π 的球里的一个点：

- 球心 = 不转（I）；
- 方向 = 转轴，到球心的距离 = 转角；
- 转 190° 等于反着转 170°，所以半径画到 π 就够；
- **`R(â, π) = R(−â, π)`**：球面上对径的两点表示同一个旋转。

所以 SO(3) 其实是"这个球把表面对径两点粘起来"，拓扑上叫 **RP³**。
这正是"转 180° 正反一样"的几何解释，也解释了为什么四元数要 2 对 1（S³ → SO(3)，q 与 −q 同一个人）。

## 6. 自由度账本（为什么 9 个数只有 3 个自由度）

| 表示 | 参数个数 | 约束 | 自由度 | 备注 |
|---|---|---|---|---|
| 3×3 矩阵 | 9 | 正交 6 条（3 个长度 + 3 个点积） | 3 | 有冗余，插值会跑出 SO(3) |
| 轴角 | 4（â 三个 + θ 一个） | `‖â‖ = 1` | 3 | θ ∈ [0, π]，端点要粘合 |
| 欧拉角 | 3 | 无 | 3 | 有奇异（万向锁） |
| 四元数 | 4 | `‖q‖ = 1` | 3 | 无奇异，但 2 对 1 |

由此得到一条工程铁律：**不要在矩阵的 9 个元素上做线性插值**（插出来的不是旋转）。
要在 so(3)（李代数）或单位四元数上插值，再映射回 SO(3)。

## 7. 落到工程上的四条

1. **姿态误差**：`e = log(R_d^T · R)` 的向量部分，正好是"当前姿态到目标姿态"的旋转向量（θ·â）。
2. **微分运动学**：`dR/dt = [ω]× R` 给出"关节速度 → 末端角速度"的关系，
   雅可比矩阵的每一列就是"某个关节转 1 rad/s 时末端的角速度"。
3. **链式乘法顺序**：`R_base_palm = R_base_roll · R_roll_palm`，**父在前、子在后**；
   换成代码就是从根节点一路**右乘**下去：`R = R @ R_局部`（乘错边就跑到别的坐标系里去了）。
4. **数值漂移**：反复相乘后 `R^T R` 会慢慢偏离 I。
   每若干步做一次正交化（SVD 取 `U V^T`，或极分解），否则误差会累积。

## 8. 一页公式表

```
保长            |Rx| = |x|
正交            R^T R = I = R R^T
逆              R⁻¹ = R^T
行列式          det R = ±1     （+1 旋转，−1 镜像）
迹              tr R = 1 + 2cosθ
轴（反对称部分） [â]× = (R − R^T)/(2 sinθ)
指数映射        exp(θ[â]×) = I + sinθ[â]× + (1−cosθ)[â]×²
导数            dR/dt = [ω]× R，  v = ω × r
组合            R = Rz(γ)·Ry(β)·Rx(α) = 内旋 ZYX
小角度          R ≈ I + θ[â]×       （误差 O(θ²)）
```

## 9. 五个常见误解

| 误解 | 事实 |
|---|---|
| "旋转矩阵的元素就是 cos、sin" | 只在**绕坐标轴**时成立；一般轴下对角是 `c + a_i²(1−c)`，还有 `a_i a_j(1−c)` 项 |
| "det = −1 也是旋转" | 不是，是镜像；它保持长度但翻转手性 |
| "ω = dθ/dt" | 只在**轴固定**时成立；一般 ω 是三维角速度向量，θ 只是某次转动的标量角 |
| "R^T = R⁻¹ 对所有矩阵" | 只对正交矩阵；一般矩阵要老老实实求逆 |
| "两个旋转可以随便换顺序" | 不可以；换顺序等于换了第二根轴的位置 |
