02 / 第①步

为什么"绳长变化率"就是力臂

不用去找"力到轴的垂直距离"——绳子是折线，那个距离处处在变。只做一件事：让关节转一个极小角度，看绳被拉长多少。

转 dθ → 收线 dl = r·dθ，力矩 = f·r
τᵀdq = −fᵀdl
R = −(∂l/∂q)ᵀ
  • 能量守恒：关节做的功，等于绳被拉长吸收的功。任意 dq 都成立，所以逐项相等。
  • 半径即力臂：绳绕在半径 r 的轴上，转 1 rad 收线 r——这正是"每弧度能收多少绳"。
  • 符号是物理：正转使绳变长 ⇒ 张力阻碍正转 ⇒ 元素为负。它是带符号的量，不是距离。
03 / 第②③步

三根绳，五段不变，两段在动

P1–P4 在 base，P5–P6 在 roll_link，P7–P8 在 palm。同一刚体上的点距离恒定，所以只有 P4–P5（跨 roll）和 P6–P7（跨 pitch）会变长。再用一条性质：正交矩阵不改变长度。

li = ci + sri(θr) + spi(θp)
  • ci 是常数：五段固定长度之和（C2 为 61.259637 mm），求导后为零，算力臂时根本用不上。
  • 解耦的来历：P6–P7 的差向量 = Qr·（只含 θp 的向量），正交矩阵把模长保住，roll 被消掉。
  • 但这不是通性：加一根 base 直连 palm 的绳，交叉二阶导立刻从 ≈0 跳到 1.367 mm/rad²。

同一段绳（C2 的 pitch 段）在 θr = 0° / 10° / 20° 下逐点测量：三条曲线完全重合。这就是"解耦"的可视证据。

04 / 第④步

α、β、γ 不是拟合参数，是三个几何投影

把固定端、动端相对轴原点记成 u、v，动端随角度转：s = ‖Qv − u‖。平方展开，再用 Rodrigues 把旋转写成 cos、sin 两项，就自然只剩三个系数。

s(θ) = √α + βcosθ + γsinθ
α = ‖u‖²+‖v‖²−2(a·u)(a·v)
β = −2[u·v − (a·u)(a·v)]
γ = −2u·(a×v)

把 u、v 拆成"沿轴 / 垂直轴"两部分：绕轴旋转只改变垂直分量的夹角，所以长度必然是一条余弦波。γ 里的叉乘，就是垂直平面内的有向面积。

曲线下方：α 决定平均长度，β、γ 决定这条波的相位与幅度。拖动上面的滑块，圆点会沿着曲线走。

s² = α + ρ cos(θ − φ) ,  ρ = √(β²+γ²)
05 / 第⑤步

求一次导，力臂就落在纸上

因为 s = √D，求导只剩一步。力臂 r = −ds/dθ，负号来自物理约定：张力阻碍正转。

r(θ) 在 θ = φ（绳最长处）穿过零：极值点处长度变化率为零，力臂自然为零。

r(θ) = β sinθ − γ cosθ2√D = ρ sin(θ − φ)2s
  • 分母 2s：绳越长，转 1 rad 收线的比例越小，力臂越小。
  • 零位读数：r(0) = −γ / (2√(α+β))，三个系数直接给出答案。
  • 组装：每根绳对每个关节各用一组系数，拼起来就是 2×3 的 R。
06 / 手算

拿计算器，把 C2 的 roll 段验一遍

这一组数就是 PDF 第 7 节的实例：A = P04 ≈ (−27, −16, 5)，B0 = P05 ≈ (−32.5, −12, 18)，轴 o = (0,0,0)，a = (0,1,0)。

① 求 α
‖u‖² = 729+256+25 = 1010
‖v‖² = 1056.25+144+324 = 1524.25
a·u = −16 ， a·v = −12
α = 2534.25 − 2(192) = 2150.25
② 求 β
u·v = 877.5+192+90 = 1159.5
β = −2[1159.5 − 192]
   = −1935
③ 求 γ
a×v = (18, 0, 32.5)
u·(a×v) = −486 + 162.5 = −323.5
γ = −2(−323.5) = 647
D(0) = 2150.25 − 1935 = 215.25 mm²  →  s(0) = √215.25 = 14.671 mm
r(0) = −6472 × 14.671 = −22.0497 mm

负号的意思：零位拉紧 C2，给 roll 一个反向力矩。数值上就是"每 1 N 张力约 22 mN·m"。

最容易误读的一行

0.032668 mm 不是模型误差，而是"用 0.2° 大步伐做差分"的截断误差。证据是第二根条：同一套差分模板作用在解析长度上，差只剩 1.5e-9 mm。这也是为什么 PDF 专门辟谣"真机精度 ≤ 0.0327 mm"。

08 / 边界

它不能承诺什么

整套公式建立在四个假设上。越出这些假设，公式依旧能算出数，但那些数不再代表真机。

刚体

零件不变形，点相对零件固定。真实瓷环上的滑动接触不在此列。

无摩擦 · 同绳同张力

导向点处摩擦为零，同一根绳各段张力相同；有摩擦时"三根单一张力"的物理解释要改。

固定中心折线

绳按相邻点中心直线连接，接触拓扑不变。真实绕环、绳伸长、回差、卷绕半径都不在模型内。

短段区

C1 的 pitch 段在 −25° 只有 3.9 mm，梯度约 15.7 mm/mm。这里力臂误差被放大，必须单独标定。

满秩 ≠ 可实现

3,621 个姿态里有 1,664 个不存在全正预紧解。矩阵满秩，不代表任意力矩都能靠正张力做出来。

零位不可辨识

(β, γ, δ) 只含两个可观测量。没有外部机械基准，δ 无法单独定出；只测 Δl 时 ci 也不可辨识。

09 / 公式卡

一张纸带走

总纲
R = −(∂l/∂q)ᵀ
τ = R·f；行 = roll / pitch，列 = C1 / C2 / C3。
解耦
li = ci + sri + spi
只对当前"相邻刚体"绳路成立，改绳路就失效。
单段
s = √(α+βcosθ+γsinθ)
α / β / γ 由零位坐标算出，单位长度²。
力臂
r = (βsinθ−γcosθ)/(2√D)
θ 用 rad；结果 m/rad，数值即等效力臂。
装配
Rri = r(θr; α,β,γ)i
六组系数各算一次，ci 不进入力臂。
门限
sguard ≥ max(snum, 2εd/ηmax)
不满足 ⇒ INVALID_FOR_CONTROL，不能静默输出。

小白最容易踩的五个坑

① 角度混用度与弧度（差 57.3 倍）；② 把带符号力臂当成距离；③ m 与 mm 混用；④ 轴与点不在同一坐标系（转置用错差 183.85 mm）；⑤ 以为"算得出来就能用"——D>0 只说明数学有效。
