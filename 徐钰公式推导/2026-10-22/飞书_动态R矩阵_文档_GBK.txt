# 绳驱二轴腕部：动态 R 矩阵解算

> **一句话结论**：R 是 2 行 3 列，元素为每段绳的力臂 r = ?ds/dθ。每段只需 5 个常数（u?, u?, v?, v?, h），即可在任意姿态实时算出，单段误差 < 1e-4 mm。

> 本文档**不含 LaTeX 标记**，所有公式都是普通字符，粘贴到飞书、微信、Word 都不会变成源码。

---

## 1. 符号约定

| 符号 | 含义 | 单位 |
|---|---|---|
| o | 轴心（roll 段 = 原点，pitch 段 = (0,0,24)） | mm |
| a | 轴方向，单位向量（roll:+Y，pitch:+X） | — |
| A | 固定端（P4 / P6） | mm |
| B? | 动端零位（P5 / P7） | mm |
| θ | 转角，右手为正 | rad |
| a | 固定端到轴的距离 | mm |
| b | 动端到轴的距离 | mm |
| h | 两端沿轴错开量（带符号） | mm |
| Δ | 两个半径的有向夹角 | rad |
| s | 该段绳长 | mm |
| r | 力臂，r = ?ds/dθ | mm |

---

## 2. 几何设定

- roll 轴：过原点，方向 +Y
- pitch 轴：过 (0,0,24)，方向 +X
- 3 根绳 / 2 个自由度，每根绳跨两个关节

每段绳只跨一个关节，因此绳长可写成两段之和：

**l_i(θr, θp) = c_i + s_ri(θr) + s_pi(θp)**

其中 c 是常数长度。

---

## 3. 单段推导

### 3.1 两个向量

**u = A ? o，　v = B? ? o**

### 3.2 拆成沿轴与垂直

**h? = u · a，　u⊥ = u ? h? · a**

**h? = v · a，　v⊥ = v ? h? · a**

三个不变量：

**a = ‖u⊥‖，　b = ‖v⊥‖，　h = h? ? h?**

a 是单位向量，所以 h?、h? 就是两点沿轴的坐标；u⊥、v⊥ 都垂直于 a。

### 3.3 动端转过去

记 Rot(θ) 为“绕 a 转 θ”这个操作：

**Rot(θ) · v⊥ = v⊥ · cosθ + (a × v⊥) · sinθ**

**B(θ) = o + h? · a + Rot(θ) · v⊥**

### 3.4 距离平方

先把 B ? A 写出来（注意 h = h? ? h?）：

**B ? A = h · a + Rot(θ) · v⊥ ? u⊥**

a 与两个垂直分量都正交，所以平方时轴向那一项单独分离：

**s2 = ‖B ? A‖2 = h2 + ‖Rot(θ) · v⊥ ? u⊥‖2**

垂直部分再用 ‖ξ ? η‖2 = ‖ξ‖2 + ‖η‖2 ? 2 ξ·η 展开，并代入 ‖Rot(θ)·v⊥‖ = b、‖u⊥‖ = a：

**‖Rot(θ) · v⊥ ? u⊥‖2 = b2 + a2 ? 2 · [Rot(θ) · v⊥] · u⊥**

合起来：

**s2 = a2 + b2 + h2 ? 2 · [Rot(θ) · v⊥] · u⊥**

### 3.5 点积展开（两角和）

把 Rot(θ)·v⊥ 代入点积，得到第一步：

**[Rot(θ) · v⊥] · u⊥ = (v⊥ · u⊥) · cosθ + [(a × v⊥) · u⊥] · sinθ**

再代入 cosΔ、sinΔ 的定义，并合并成两角和：

**[Rot(θ) · v⊥] · u⊥ = ab · (cosΔ · cosθ ? sinΔ · sinθ) = ab · cos(Δ + θ)**

其中

**cosΔ = (v⊥ · u⊥) / (ab)**

**sinΔ = ? [(a × v⊥) · u⊥] / (ab)**

### 3.6 得到闭式

**s2 = α + β · cosθ + γ · sinθ**

**α = a2 + b2 + h2**

**β = ?2 · (v⊥ · u⊥)，　γ = ?2 · [(a × v⊥) · u⊥]**

## 4. 力臂与 R 矩阵

对 s 求导：

**ds/dθ = (γ · cosθ ? β · sinθ) / (2s)**

论文约定 r = ?ds/dθ，因此：

**r(θ) = (β · sinθ ? γ · cosθ) / (2s)，　r(0) = ?γ / (2√(α + β))**

R 矩阵（2 行 × 3 列，行 = 关节，列 = 绳）：

**R = ?(?l/?q)?，　R(i, j) = r_i(θ_j)**

零位时的数值：

| | C1 | C2 | C3 |
|---|---|---|---|
| **roll** | ?0.259 | ?22.050 | +17.372 |
| **pitch** | ?58.105 | +11.805 | +10.990 |

张力映射：

**τ = R · f，　f = R? · τ + t · w**

## 6. 算法流程（每段）

1. 取常数 u?, u?, v?, v?, h
2. 算 cosθ、sinθ
3. d? = v? · cosθ ? v? · sinθ ? u?
4. d? = v? · sinθ + v? · cosθ ? u?
5. s = √(d?2 + d?2 + h2)
6. r = (u? · d? ? u? · d?) / s

三根绳 × 两段 = 6 次调用，得到 R 的 6 个元素。

## 7. 数值验证（C2 / roll）

| θ | s (mm) | r (mm) |

| 0° | 14.671 | ?22.050 |
| 25° | 25.884 | ?26.99 |

**v⊥ = (?32.5, 0, 18)，　a × v⊥ = (18, 0, 32.5)**

**Rot(θ) · v⊥ = 0.8660 × (?32.5, 0, 18) + 0.5 × (18, 0, 32.5) = (?19.145, 0, 31.839)**

**B = (0,0,0) + (0, ?12, 0) + (?19.145, 0, 31.839) = (?19.145, ?12, 31.839)**

**s = ‖B ? A‖ = √(7.8552 + 42 + 26.8382) = 28.249 mm**

## 8. 工程实现要点

- 每段 5 个常数，可预计算为 float
- 单段只需 2 次 sin/cos + 4 次乘 + 1 次开方
- 9,249 个姿态验证：float32 与 double 最大差 4.67e-5 mm
- 参考实现：`src/wrist_r.c`

## 9. 常见错误

| 错误 | 后果 |
|---|---|
| 把 pitch 轴心当原点 | 力臂全错（差 24 mm 量级） |
| 用 ‖v‖ 当半径 b | 少减了轴向分量 |
| 角度用度 | cos/sin 结果错 |
| 力臂符号取反 | 控制方向反，闭环发散 |
