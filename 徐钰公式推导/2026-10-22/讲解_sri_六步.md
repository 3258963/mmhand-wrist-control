# s_ri(θr) 到底怎么算

配套页面：`3D_拆解_sri.html`（左侧 3D，右侧「下一步」按 6 步走）

---

## 0. 一句话

> **s_ri 就是"跨 roll 的那一小段绳"的长度；它只跟 θr 有关。**

`l_i(θr, θp) = c_i + s_ri(θr) + s_pi(θp)` 里，`c_i` 是常数，`s_ri` 是 roll 段的长度，`s_pi` 是 pitch 段的长度。这篇只讲 `s_ri`。

---

## 0.5 先认字母（看不懂就回来查）

**点、轴与向量**

| 符号 | 读法 | 一句话 | 单位 |
|---|---|---|---|
| P4 | — | roll 段的一端，固定在底板（base）上 | mm 坐标 |
| P5 | — | roll 段的另一端，装在转子（roll_link）上 | mm 坐标 |
| P6 / P7 | — | pitch 段的两端 | mm 坐标 |
| o | 轴心 | 转轴穿过的那一点；roll 是 (0,0,0)，pitch 是 (0,0,24) | mm |
| â | 轴方向 | 长度为 1 的箭头，说明“绕哪条线转” | 无量纲 |
| F_A / F_B | 垂足 | 从 P4、P5 向转轴作垂线，落在轴上的点 | mm |
| u / v | 位置向量 | 从轴心指向 P4、P5 的箭头 | mm |
| X / Y / Z | F0 的三根轴 | Y 是 roll 转轴，X 是 pitch 转轴的方向，Z = X × Y；pitch 轴沿 Z 平移了 24 mm | 方向 |

**长度**

| 符号 | 读法 | 一句话 | 单位 |
|---|---|---|---|
| a | 固定端半径 | P4 到转轴的距离 | mm |
| b | 动端半径 | P5 到转轴的距离 | mm |
| h | 沿轴错位 | 两端沿转轴方向差了多少，带正负 | mm |
| s | 这一段绳长 | P4 到 P5 的长度，随角度变 | mm |
| c | 其余五段之和 | 同一零件上的 5 段，长度永远不变 | mm |
| l | 整根绳总长 | l = c + roll 段 + pitch 段 | mm |

**角度**

| 符号 | 读法 | 一句话 | 单位 |
|---|---|---|---|
| θr | roll 转角 | roll 关节转过的角度，0° 是零位 | 度（公式用弧度） |
| θp | pitch 转角 | pitch 关节转过的角度 | 度（公式用弧度） |
| Δ | 夹角 | a 和 b 在“垂直于轴的平面”里的夹角，带符号 | 度 |
| rad | 弧度 | 1 弧度 ≈ 57.3°；sin / cos 只认弧度 | 无量纲 |

**结果**

| 符号 | 读法 | 一句话 | 单位 |
|---|---|---|---|
| α β γ | 三个打包数 | α=a²+b²+h²，β=−2ab·cosΔ，γ=2ab·sinΔ | mm² |
| r | 力臂 | 每转 1 弧度收多少绳；也等于轴到绳的垂距 | mm/rad（数值即 mm） |
| R | 力臂矩阵 | 2 行 3 列：行=关节，列=绳；τ = R·f | m/rad |
| τ | 关节力矩 | 绳的张力让关节转动的“劲” | N·m |
| f | 绳张力 | 每根绳绷多紧 | N |

## 1. 一根绳有 7 段，只有 2 段会变

一根绳从 base 穿到 palm，经过 P1…P8 共 8 个导向点，所以有 7 段：

| 段 | 两端在哪 | 会变吗 |
|---|---|---|
| P1–P2、P2–P3、P3–P4 | 都在 base | 不变 |
| P5–P6 | 都在 roll_link | 不变 |
| P7–P8 | 都在 palm | 不变 |
| **P4–P5** | base → roll_link | **随 θr 变** |
| **P6–P7** | roll_link → palm | **随 θp 变** |

不变的 5 段加起来就是 `c_i`（C2 约 61.2596 mm）。**剩下的就两段。**

> 页面第 1 步：只高亮 P4、P5 两个点。

---

## 2. 为什么它只跟 θr 有关（解耦）

P6–P7 的差向量可以写成：

```
(P7 − P6) = Q_r · (只含 θp 的向量)
```

Q_r 是旋转矩阵，**旋转不改变长度**，所以右边那个 Q_r 被"消掉"了——P6–P7 的长度只由 θp 决定。

同理 P4–P5 只由 θr 决定。这就是 `l_i = c_i + s_ri + s_pi` 的来历。

> ⚠️ 这不是二轴腕部的通性：加一根 base 直连 palm 的绳，这个式子立刻失效。

---

## 3. 算 s_ri 的五步

设：A = 固定端（P04），B₀ = 动端零位（P05），o = 轴心，â = 轴方向。

### 第 1 步：选段
```
A = P04, B₀ = P05
```

### 第 2 步：减去轴心
```
u = A − o     （roll：o = (0,0,0)）
v = B₀ − o    （pitch：o = (0,0,24)！）
```

### 第 3 步：量两个半径
从 A、B₀ 分别向轴作垂线，垂足记 F_A、F_B：

```
a = |A − F_A|     固定端到轴的距离
b = |B₀ − F_B|    动端到轴的距离
```

### 第 4 步：量沿轴错位
```
h = (v − u) · â      ← 带正负，不是绝对值
```

### 第 5 步：量夹角
```
cosΔ = (A−F_A)·(B₀−F_B) / (a·b)
sinΔ = 叉乘 · â / (a·b)
Δ = atan2(sinΔ, cosΔ)   ← 带符号
```

> Δ 的符号决定 γ 的符号，进而决定力臂的正负。

---

## 4. 从四个数到 s(θ)

三个点 A、B₀、轴心 o 构成一个三角形，夹角是 `Δ + θ`。余弦定理：

```
s² = a² + b² − 2ab·cos(Δ + θ)
```

但真实的两端还可能沿轴错开 h，所以再加一个 `h²`：

```
s² = a² + b² + h² − 2ab·cos(Δ + θ)
```

把它整理成"一条余弦波"：

```
s(θ) = √(α + βcosθ + γsinθ)

α = a² + b² + h²
β = −2ab·cosΔ
γ = +2ab·sinΔ
```

> 页面第 6 步：显示的就是这个 s(θ)。

---

## 5. 求导：力臂

```
s = √D，D = α + βcosθ + γsinθ
ds/dθ = (−βsinθ + γcosθ) / (2s)
r = −ds/dθ = (βsinθ − γcosθ) / (2s)
```

零位（θ = 0）：

```
r(0) = −γ / (2√(α + β))
```

**直觉**：r 就是"每弧度收进多少绳"，也就是"轴到绳的垂直距离"。

## 7. 手算 C2 / roll（和页面对一遍）

```
u = P04 = (−27, −16, 5)        v = P05 = (−32.5, −12, 18)
a·u = −16    a·v = −12

‖u‖² = 1010      ‖v‖² = 1524.25      u·v = 1159.5

α = 1010 + 1524.25 − 2(−16)(−12) = 2150.25
β = −2(1159.5 − 192)             = −1935
γ = −2 × (−323.5)                = +647

s(0) = √(2150.25 − 1935) = 14.671 mm
r(0) = −647 / (2 × 14.671) = −22.050 mm
```

用 a、b、h、Δ 复核：

```
a = √(27² + 5²) = 27.46      b = √(32.5² + 18²) = 37.15
h = (−12) − (−16) = 4

α = 27.46² + 37.15² + 4² = 2150.25     ✓
β = −2 × 27.46 × 37.15 × cos18.5° = −1935   ✓
γ = +2 × 27.46 × 37.15 × sin18.5° = +647    ✓
```

## 8. 五个常见错误

1. **pitch 忘了 (0,0,24) 的偏置** —— 用原点算，a、b、h 全错。
2. **h 用了绝对值** —— h 是 `(v−u)·â`，带正负；C1 pitch 是 −0.18，C3 pitch 是 +6.28。
3. **角度用度** —— cos/sin 要吃弧度。
4. **把力臂当成"距离"** —— 它是带符号的 `−ds/dθ`。
5. **以为 R 是常数** —— C2 对 roll 从 −22.05（0°）变到 −26.99（20°）。

## 10. 进阶：α β γ 是什么

它们只是 a、b、Δ、h 的另一种打包方式：

```
α = a² + b² + h²          ← 平均长度²
β = −2ab·cosΔ             ← 余弦分量
γ = +2ab·sinΔ             ← 正弦分量
```

写成 `α + βcosθ + γsinθ` 的好处：求导简单、六段形式统一、方便做灵敏度分析。

固件里反而不直接用它们：C1 pitch 的 α−β 只有 725（两个 7000 量级的数相减），float32 会掉精度。所以工程上存每段 5 个投影数 `(u1,u2,v1,v2,h)`，直接算差向量。
