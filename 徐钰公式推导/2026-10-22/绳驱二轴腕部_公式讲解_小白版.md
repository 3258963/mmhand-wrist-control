# 绳驱二轴腕部解析公式：这份 PDF 是怎么一步步推出来的

对象：`绳驱二轴腕部_解析公式.pdf`（2026-10-22 / v2.0，14 页）
读法建议：本文按"为什么 → 怎么推 → 怎么验 → 哪里不能信"的顺序讲，公式编号与 PDF 保持一致，方便对照原页。

---

## 0. 一句话：它在算什么

输入两个关节角 **θ_r（roll，绕 +Y）**、**θ_p（pitch，绕 +X）**，
输出一个 **2 行 × 3 列** 的矩阵 **R**：

```
τ = R(q) · f        q = (θ_r, θ_p)ᵀ ,  f = (f1, f2, f3)ᵀ
```

- 行 = 关节：第 1 行是 roll 力矩，第 2 行是 pitch 力矩；
- 列 = 绳：第 1/2/3 列分别是绳 1/2/3；
- 元素 R_ji 的物理意义：**第 i 根绳每 1 N 张力，能给第 j 个关节产生多大力矩**（单位 m/rad，数值上等于 mm/rad ≈ mN·m 每 N）。

所以它其实是一张"传动比表"：给定姿态和张力，立刻得到两个关节的力矩。**难点不在乘法，而在于绳是折线、绳长随角度非线性变化，这个"传动比"本身随姿态变。**

## 1. 主线：七步

| 步 | PDF 位置 | 在做什么 | 一句话直觉 |
|---|---|---|---|
| ① | 式 (1)–(4) | 用虚功把"力矩"换成"绳长对角度的导数" | 转一下关节，看绳被拉长多少 |
| ② | 式 (5)–(9) | 写折线绳长的通用公式（任意绳路都能用） | 折线长度 = 各段长度之和 |
| ③ | 式 (10)–(14) | 本机构的运动学 + 证明绳长可拆成单变量之和 | 只有"跨关节"的那一段会变长 |
| ④ | 式 (15)–(21) | 把单段长度化成 α+βcosθ+γsinθ 的闭式 | 长度随转角变化像一条正弦波 |
| ⑤ | 式 (22)–(25) | 对角度求导，得到力臂，装成 R | 力臂 = 单位角度收线量 |

**整份文档真正的"骨架"只有一条**：只要能把每根绳的长度 l_i(θ_r, θ_p) 写成可求导的闭式，力臂就是它导数的负值。其余章节都在为这条服务（要么保证闭式成立，要么检验它是错的）。

## 2. 第①步：为什么"绳长变化率"就是力臂（式 1–4）

### 2.1 推导

设关节产生一个任意的微小位移 dq，第 i 根绳的长度变化 dl_i，绳中张力 f_i。
绳被拉长 dl_i，相当于机构对绳做了 f_i·dl_i 的功；反过来绳对机构的功就是 −f_i·dl_i。把三根绳加起来，等于关节力矩做的功 τᵀdq：

```
dW = τᵀ dq = −fᵀ dl ,      dl = J_l(q) dq          (2)
```

对任意 dq 都成立，所以：

```
τ = −J_l(q)ᵀ f ,     R(q) = −J_l(q)ᵀ               (3)
R_ji(q) = −∂l_i/∂q_j                                 (4)
```

### 2.2 小白的直觉版

想象绳绕在一根半径为 r 的轴上。轴转 dθ，绳被收进 r·dθ，所以 **dl/dθ = r**。
而绳的张力 f 对轴的力矩正好是 **f·r**。
两者一乘就发现：**力矩 = f × (dl/dθ)**。所以"单位角度能收多少绳"就是力臂，根本不需要再去求"力到轴的垂直距离"。

### 2.3 为什么不直接算"力 × 垂直距离"

因为绳是折线：力沿每一小段的方向都不同，跨关节那一段的方向还随姿态变。逐段求垂直距离又繁琐又容易错。
而"长度函数"只有一个标量，求导是机械操作。**这就是虚功方法的价值：把矢量问题降成一个标量函数的导数。**

### 2.4 符号怎么定（初学者最容易翻车的地方）

- 关节**正转使绳变长** ⇒ ∂l/∂θ > 0 ⇒ 力臂为负 ⇒ 张力**阻碍**正转。
- 所以 R 的元素是**带符号的**，不是"绳到轴的距离"这种正数。
- PDF 里 roll 正方向 +Y、pitch 正方向 +X，右手定则，向量按列写。

## 3. 第②步：折线绳长的通用公式（式 5–9）

第 i 根绳依次经过 n 个点 p_{i,k}（P1…P8 这些导向点/固定点）。定义每段的差向量、长度、单位方向：

```
d_ik = p_{i,k+1} − p_{i,k} ,   s_ik = ‖d_ik‖ ,   u_ik = d_ik / s_ik      (5)
l_i  = Σ s_ik                                                          (6)
∂s_ik/∂q_j = u_ikᵀ ( ∂p_{i,k+1}/∂q_j − ∂p_{i,k}/∂q_j )                  (7)
R_ji = − Σ u_ikᵀ ( … )                                                 (8)
```

关键补充是式 (9)：受转动关节驱动的点，其速度是

```
∂p/∂q_j = a_j(q) × [ p(q) − o_j(q) ]                                   (9)
```

（a_j 是轴单位方向，o_j 是轴上一点；不受该关节驱动的点导数为零。）

**为什么这一步重要**：它是"万能公式"。绳路上任何一点、任何归属（哪个刚体）、轴随姿态怎么动，都能代进去。后面第④–⑤步只是它的一个特例化简。

**注意**：式 (9) 里的 a_j、o_j 必须是**当前姿态**下的值，pitch 轴会随 roll 一起转，不能钉死在世界 X 轴上——这是新手最常见的错误。

## 4. 第③步：为什么绳长能拆成"两个单变量函数相加"（式 10–14）

### 4.1 三个刚体、八个点

```
base（固定）      → roll_link（绕 roll 轴转）   → palm（再绕 pitch 轴转）
P1 ~ P4            P5 ~ P6                        P7 ~ P8
```

（这里的 P 编号是"绳内编号"，和关节序号无关。）

- 同一刚体上的两点，无论关节怎么转，距离不变 → P1–P2、P2–P3、P3–P4、P5–P6、P7–P8 五段长度**恒定**，记它们的和为 **c_i**；
- 只有 **P4–P5 跨 roll**、**P6–P7 跨 pitch** 会随角度变。

### 4.2 运动学

```
p_base = p0
p_roll = Q_r(θ_r) p0                                                   (10)
p_palm = Q_r(θ_r) [ o_p + Q_p(θ_p)(p0 − o_p) ]                         (11)
```

r 中 o_p = (0, 0, 24) mm 就是两轴之间 **24 mm 的最短偏置**。这一项不能省：两轴正交但**不相交**，pitch 轴的转动中心在 roll 轴上偏移了 24 mm。式 (11) 的写法是"先绕自身 pitch 轴转，再被 roll 整体带走"，顺序不能反。

### 4.3 解耦（整个推导最漂亮的一步）

P6–P7 的差向量可以写成 `Q_r ·（只含 θ_p 的向量）`。
Q_r 是**正交矩阵**，正交变换**不改变向量长度**，所以：

```
s_p(θ_p) = ‖ Q_r · v(θ_p) ‖ = ‖ v(θ_p) ‖     ← roll 被"消掉"了
```

同理 P4–P5 只受 roll 影响。于是

```
l_i(θ_r, θ_p) = c_i + s_ri(θ_r) + s_pi(θ_p)                            (14)
```

**这就是"解耦"**：一根绳的长度是两个单变量函数之和，两个关节可以分开推。

### 4.4 但这不是"二轴腕部的通性"

PDF 明确说：这只是**当前绳路归属**带来的结构性质。如果加一根从 base 直接连到 palm 的绳（或接触点随姿态滑动），这段就同时依赖两个角，解耦失效。
核对报告里做了反例：加一条 base P03 → palm P08 直连段后，交叉二阶导 ∂²l/∂θ_r∂θ_p 从 ≈0 变成 C2 = +1.367、C3 = −1.242 mm/rad²。

**结论**：解耦是"可以被结构打破"的，所以 PDF 第 11 节给了"结构变更规则"——一旦改绳路，必须回到第③节的通用公式，不能硬套 (14)。

## 5. 第④步：α、β、γ 是怎么来的（式 15–21）

### 5.1 建模

取跨关节那一段：A 是固定端（在父刚体上），B 是动端零位（在子刚体上）。设轴上一点为 o：

```
u = A − o ,   v = B0 − o
B(θ) = o + Q(a, θ) v ,     s(θ) = ‖ Q(a, θ)v − u ‖                    (15)
```

### 5.2 平方展开 + Rodrigues

长度平方：

```
s² = ‖u‖² + ‖v‖² − 2uᵀQ(a,θ)v                                          (16)
Q(a,θ)v = v cosθ + (a×v) sinθ + a(aᵀv)(1 − cosθ)                       (17)
```

把 (17) 代进 (16)，cosθ、sinθ、常数各自归并，就得到：

```
s(θ) = √( α + β cosθ + γ sinθ )                                        (18)
α = ‖u‖² + ‖v‖² − 2(aᵀu)(aᵀv)                                          (19)
β = −2[ uᵀv − (aᵀu)(aᵀv) ]                                             (20)
γ = −2 uᵀ(a × v)                                                       (21)
```

**它们是零位坐标的代数组合，不是曲线拟合参数**——这是初学者最容易误解的一点。单位是长度²（本文用 mm²）。

### 5.3 物理含义（想通了就再也不会记混）

把 u、v 各拆成"沿轴分量"和"垂直于轴的分量"：
- 绕轴旋转**只改变垂直分量的相对夹角**，沿轴分量完全不动；
- 所以长度只由"两个垂直分量的夹角余弦"决定 → 一定是 **A + Bcosθ + Csinθ** 的形状，不多不少；
- **√(β²+γ²) = 2‖u⊥‖‖v⊥‖** 是"长度平方摆动的幅度"；
- **γ 里的叉乘 = 垂直平面内的有向面积**，它决定相位，也就是"零位时两个垂直分量夹角是多少"。

等价写法（强烈建议记住）：

```
s² = α + ρ cos(θ − φ) ,   ρ = √(β²+γ²) ,   φ = atan2(γ, β)          (★)
```

即：**绳长随转角变化，就是一条相位为 φ、幅度为 ρ 的余弦波**。β、γ 只是这条波的"余弦分量"和"正弦分量"。

### 5.4 两个安全条件

- 工作角内必须 **D(θ) = α + βcosθ + γsinθ > 0**，否则根号无意义、方向无定义；
- 由几何恒等式有 **α ≥ ρ**（当且仅当 u⊥ ∥ v⊥ 时取等号）。α = ρ 表示某角度绳长会到 0（奇异），需要检查是否落在行程内。
- 但 D > 0 **只保证数学上不是零长**，不保证工程上可信——短段区力臂误差会被放大，这是第三部分 s_guard 门限存在的原因。

## 6. 手算一遍：C2 的 roll 段（强烈建议拿计算器跟一遍）

PDF 给的参数：A = P04 ≈ (−27, −16, 5) mm，B0 = P05 ≈ (−32.5, −12, 18) mm，
轴 o = (0,0,0)，a = (0,1,0)。

```
u = A − o = (−27, −16, 5) ,   v = (−32.5, −12, 18)
‖u‖² = 729 + 256 + 25 = 1010
‖v‖² = 1056.25 + 144 + 324 = 1524.25
aᵀu = −16 ,  aᵀv = −12

α = 1010 + 1524.25 − 2(−16)(−12) = 2150.25      ✓ 与文档一致
uᵀv = 877.5 + 192 + 90 = 1159.5
β = −2[1159.5 − 192] = −1935                     ✓
a×v = (18, 0, 32.5)
uᵀ(a×v) = −486 + 162.5 = −323.5
γ = −2(−323.5) = 647                             ✓
```

于是：

```
s_r2(θ_r) = √(2150.25 − 1935 cosθ_r + 647 sinθ_r)  [mm]               (26)
D(0) = 2150.25 − 1935 = 215.25 mm²
s(0) = √215.25 = 14.671 mm
R_r2(0) = −647 / (2 × 14.671) = −22.0497 mm                            (27)
```

**负号的意思**：零位时（此时绳接近最短状态）拉紧 C2，会给 roll 一个负方向的力矩。数值 −22.05 mm 就是"每 1 N 约 22 mN·m"。

顺便一个有意思的检查：D 的最小值 109.95 mm² 出现在 θ_r = −18.49°，对应最短长 10.486 mm。零位只比最短长约 4.2 mm，所以这一段在零位附近就已经"偏紧"，力臂对几何误差不特别敏感，但也不能大角度乱用。

## 7. 第⑤步：求导得力臂（式 22–25）

由 r = −ds/dθ，链式法则：

```
ds/dθ = (−β sinθ + γ cosθ) / (2√D)                                     (22)
r(θ; α,β,γ) = (β sinθ − γ cosθ) / (2√(α + βcosθ + γsinθ))              (23)
```

用 (★) 改写，更好懂：

```
r(θ) = ρ · sin(θ − φ) / (2 s)                                          (23′)
```

三条直觉：
1. **力臂就是"单位角度收多少绳"**，所以它是长度量纲（m/rad），单位没问题；
2. 当 θ = φ（绳最长处）时 **r = 0**——极值点长度变化率为零，符合直觉；
3. 分母有 **2s**：同样转 1 rad，绳越长，相对收线越少，所以力臂越小。

组装矩阵：每根绳对每个关节各用一组 (α, β, γ)：

```
R_ri = r(θ_r; α_ri, β_ri, γ_ri) ,   R_pi = r(θ_p; α_pi, β_pi, γ_pi)    (24)
```

- 常数 c_i 求导为零 ⇒ **不需要 c_i 就能算力臂**（只有要算绳的绝对长度时才需要）；
- 交叉偏导恒为零：**∂R_ri/∂θ_p = ∂R_pi/∂θ_r = 0**（式 25），这正是第③步解耦的推论。

## 8. 第⑥步：代入实数，得到零位矩阵

六组系数（mm²，见 PDF 第 7 节表格）：

| 绳/关节 | α | β | γ |
|---|---|---|---|
| C1 / roll | 364.5 | −182.5 | 7.0 |
| C1 / pitch | 7263.47364742 | −6537.66603142 | 3130.77161942 |
| C2 / roll | 2150.25 | −1935.0 | 647.0 |
| C2 / pitch | 820.33042151 | −563.99999989 | −378.00000006 |
| C3 / roll | 2500.25 | −2205.0 | −597.0 |
| C3 / pitch | 859.73346622 | −563.99999980 | −378.00000010 |

零位（θ_r = θ_p = 0）矩阵，单位 mm：

```
R(0) = [ −0.25943726   −22.04970101    17.37198247 ]   ← roll 行
       [ −58.10461556    11.80488412    10.99035112 ]   ← pitch 行
```

读法：pitch 行三个数明显大于 roll 行，说明这个腕部在 pitch 方向上"力臂更大"、更容易出力；C2 对 roll 的贡献是负的。

## 9. 第⑦步：怎么证明它没算错（第 8–12 节 + 第三部分）

作者没有只说"我觉得对"，而是用了多条互不依赖的路线对撞：

| 检验 | 做法 | 结果 |
|---|---|---|
| CAD 差分 | 在 3621 个 0.2° 姿态上用有限差分求 R，与解析式比 | 最大差 0.032668 mm（pitch/C1 行） |
| 同模板自洽 | 把同一套 0.2° 模板作用在**解析长度**上再求导，与原表比 | 差 1.5e-9 mm（机器零量级） |
| 独立静力学 | 不用长度导数，直接"跨关节段取矩" | 与闭式解差 1.4e-12 mm |
| 灵敏度 | 对 α/β/γ/θ 求偏导，与数值差分比 | 8–9 位有效数字一致 |
| 相位耦合 | 用 (β,γ,δ) 三种等价参数化互算 | 残差 5e-19 m² |
| 边界 | 25 条边界原始长度记录 | 2.65e-11 mm |

**最关键的一条**：0.032668 mm **不是模型误差**，而是"用 0.2° 大步伐做差分"的截断误差（≈ h²/6 量级）。证据就是第二行：同一套差分模板作用于解析长度，差只剩 1.5e-9 mm。很多人会误把它当成"模型精度 0.03 mm"，PDF 专门辟谣了这一点。

另外 PDF 还做了"可辨识性"检查：
- (β, γ, δ) 三个参数里只有两个可观测 ⇒ 没有外部机械零位基准时，δ 无法单独定出来；
- 只测绳长变化量 Δl 时，常数 c_i 不可辨识；
- 3621 个姿态里有 1664 个**不存在全正张力的预紧解** ⇒ 矩阵满秩 ≠ 任意力矩都能实现。

## 10. 这套推导什么时候不能直接用

四个前提（第 1 节明确列出）：
1. 零件是刚体，点相对零件固定；
2. 绳张紧、质量忽略、导向点处**无摩擦**，同一根绳各段张力相同；
3. 绳路按相邻点的**中心直线段**连接（固定中心折线近似），接触拓扑不变；
4. 瓷环处真实滚动/滑动、绳伸长、回差、卷绕半径变化**不在模型内**。

因此：
- **可以承诺**：在上述假设内，数学与数值是对的，且 CAD 体系内部自洽；
- **不能承诺**：真机力臂误差的具体数值（"≤0.0327 mm"不成立）、接触偏差、摩擦/弹性/回差、轴线与 24 mm 偏距的实物准确性。

两个历史问题（独立核对报告 04 提出）：早期印本在 (27)、(S4) 的 sin 项符号印反了；**以通式 (23) 为准**（当前 PDF 里 (S4)、(27) 我看到的是正确形式，但引用时仍建议用 (23) 自己代一遍）。此外复核包里的 `verify_formulas.py`、`复核结果.json` 未随包提供。

## 12. 小白最容易踩的五个坑

1. **角度用度还是弧度**：公式里全是 rad。用度求导会差 57.3 倍；sin/cos 收度数则直接算错。
2. **把力臂当成"距离"**：它是**带符号**的 ∂l/∂θ，负号表示"张力阻碍正转"。
3. **单位混用**：坐标用 m 时 α/β/γ 是 m²，输出是 m；本文表格为阅读方便用 mm² / mm。同一式子里不要混。
4. **轴和点的坐标系不一致**：pitch 轴会跟着 roll 转，轴原点还偏了 24 mm；固定板坐标与世界坐标要用式 (F1) 的 Bᵀ 正确转置（用错会差 183.85 mm）。
5. **以为"算得出来就能用"**：D > 0 只说明数学有效；短段区（C1 pitch ≤ −24°，s ≈ 3.9 mm）必须单独标定，满秩也不保证有全正预紧解。
