## 0. 30 秒速查：最核心的 8 个

| 符号 | 一句话含义 | 单位 |
|---|---|---|
| θᵣ , θ_p | 两个关节角：roll（左正）、pitch（前正）。公式里一律 rad | rad |
| l_i | 第 i 根绳从 P1 到 P8 的总长度 | mm |
| s | **一段**绳的长度，s = √D | mm |
| R_ji | 力臂：第 i 根绳每 1 N 张力给第 j 个关节的力矩 | mm/rad（数值=mm） |
| f_i | 第 i 根绳的张力 | N |
| τ_j | 第 j 个关节的力矩 | N·m |
| α, β, γ | 描述"这一段绳长随角度怎么变"的三个常数 | mm² |
| D | D = α + βcosθ + γsinθ，也就是 s² | mm² |

总公式只有一条：**τ = R·f**，其中 **R_ji = −∂l_i/∂θ_j**。

---

## 1. 先约定书写规则

| 约定 | 说明 |
|---|---|
| 下标 i | 绳的编号：i = 1,2,3，对应 C1、C2、C3 |
| 下标 j | 关节的编号：j = roll 或 pitch |
| 下标 k | 折线的第 k 段（第 k 个点到第 k+1 个点） |
| R_ji 的读法 | **先"行"后"列"**：第一个下标是关节（行），第二个是绳（列） |
| 向量的写法 | 按列向量处理；a·b 是点积，a×b 是叉积，‖a‖ 是长度 |
| 单位 | 文档表格用 mm / mm²；源码和 JSON 用 m / m²。1 m = 1000 mm |
| 角度 | 公式内部全部用 rad；表格和界面用 deg（度） |

> 为什么必须记住"rad"：长度对角度求导，若按"度"求导，结果会小 57.2958 倍（1 rad = 180/π deg）。

| 符号 | 含义 | 备注 |
|---|---|---|
| **q** | 关节角向量 q = (θᵣ, θ_p)ᵀ | 二维；公式内部 rad |
| **θᵣ** | roll 关节角（绕 F0 的 +Y 轴） | 左转为正 |

| **δ** | 编码器零位偏置：真实角 θ = q_enc + δ | 很重要，见第 8 节 |
| **h** | 差分步长，h = 0.2°（换成 rad） | 附录 D2 |

## 3. 点、刚体、绳

| 符号 | 含义 |
|---|---|
| **P1 … P8**（P01…P08） | 一根绳依次经过的 8 个点位（固定点 / 导向瓷环中心 / 绳端固定点） |
| **P01–P04** | base（固定板）上的点，永不随关节动 |
| **P05–P06** | roll_link（绕 roll 轴转的零件）上的点 |
| **P07–P08** | palm（手掌，再绕 pitch 轴转）上的点 |
| **p₀** | 某个点在**零位**时、在 F0 系中的坐标（不是手掌局部坐标） |
| **p(i, k)** | 第 i 根绳的第 k 个点（第 3 节通用公式用） |
| **p** | 点的位置向量（随姿态变化） |
| **base / roll_link / palm** | 三个刚体，从固定板到手爪的串联链 |
| **C1, C2, C3** | 三根绳的编号（Cable 1–3） |
| **c_i** | 第 i 根绳上**五段固定长度之和**（同刚体上的段，长度不变） |

> 一个绳内有 8 个点、7 段。其中 5 段两端在同一刚体上 ⇒ 长度恒定；只有 P4–P5、P6–P7 跨刚体 ⇒ 会变。

## 4. 折线绳长（式 5–9，通用公式）

| 符号 | 含义 | 单位 |
|---|---|---|
| **d_ik** | 第 k 段的差向量 d = p(i,k+1) − p(i,k) | mm |
| **s_ik** | 第 k 段的长度，s = ‖d‖ | mm |
| **u_ik** | 第 k 段的单位方向，u = d / s（**这是单位向量**） | 无量纲 |
| **l_i** | 第 i 根绳的总长，l = Σ s_ik | mm |
| **∂s_ik/∂q_j** | 段长对关节角的导数 | mm/rad |
| **a_j** | 第 j 个关节的**轴方向单位向量**（随姿态可能变） | 无量纲 |
| **o_j** | 第 j 个关节轴上的**任意一点**（原点沿轴滑动不影响结果） | mm |
| **∂p/∂q_j** | 关节转动时该点的速度，= a_j × (p − o_j) | mm/rad |

## 5. 跨关节单段：α、β、γ 这一族（式 15–23）

这一节是整篇的"发动机"，符号也最密。

| 符号 | 含义 | 单位 |
|---|---|---|
| **A** | 跨关节段的**固定端**（在父级刚体上，不动） | mm |
| **B₀** | 跨关节段的**运动端在零位**时的位置 | mm |
| **B(θ)** | 运动端转过 θ 之后的位置：B = o + Q(a,θ)(B₀ − o) | mm |
| **a** | 该关节的轴方向单位向量 | 无量纲 |
| **o** | 该关节轴上的任意一点（常取轴上原点） | mm |
| **u** | **位矢** u = A − o（注意：不是第 4 节的单位向量！） | mm |
| **v** | **位矢** v = B₀ − o | mm |
| **Q(a, θ)** | 绕轴 a 转 θ 的旋转矩阵（右手、主动旋转） | — |
| **Q(a,θ)v** | Rodrigues 展开：v cosθ + (a×v) sinθ + a(a·v)(1−cosθ) | mm |
| **α** | 常数项 = ‖u‖² + ‖v‖² − 2(a·u)(a·v) | mm² |
| **β** | cos 项系数 = −2[ u·v − (a·u)(a·v) ] | mm² |
| **γ** | sin 项系数 = −2 u·(a×v) | mm² |
| **D(θ)** | D = α + βcosθ + γsinθ = s² | mm² |
| **s(θ)** | 该段长度 = √D | mm |
| **ρ** | 摆幅参数 ρ = √(β² + γ²) = 2‖u⊥‖‖v⊥‖ | mm² |
| **φ₀** | 相位角 φ₀ = atan2(γ, β)，使 D = α + ρ·cos(θ − φ₀) | rad |
| **N** | 求导中间量 N = β sinθ − γ cosθ（分子） | mm² |
| **r(θ)** | 带符号力臂：r = −ds/dθ = (β sinθ − γ cosθ)/(2√D)（其中 ds/dθ = (−β sinθ + γ cosθ)/(2√D)） | mm |
| **u⊥ , v⊥** | u、v **垂直于轴**的分量（决定长度怎么变） | mm |
| **u∥ , v∥** | u、v **平行于轴**的分量（旋转时完全不变） | mm |

由此还有两条恒等式，用来心算检查：

```
α = ‖u⊥‖² + ‖v⊥‖² + (u∥ − v∥)²      ← 一定会 ≥ 0
ρ = 2‖u⊥‖‖v⊥‖                        ← 所以 α ≥ ρ
D 的最小值 = α − ρ ，出现在 θ = φ₀ ± 180°
```

## 6. 力臂、张力、力矩、矩阵（式 2–4、24–25）

| 符号 | 含义 | 单位 |
|---|---|---|
| **f_i** | 第 i 根绳的张力（同一根绳各段相同，假设无摩擦） | N |
| **f** | 三根绳张力的列向量 f = (f₁, f₂, f₃)ᵀ | N |
| **τ_j** | 第 j 个关节的力矩（**只算绳张力贡献**） | N·m |
| **τ** | 关节力矩列向量 τ = (τ_roll, τ_pitch)ᵀ | N·m |
| **R** | 2×3 力臂矩阵；行 = roll/pitch，列 = C1/C2/C3 | mm/rad |
| **R_ji** | R 的元素：R_ji = −∂l_i/∂θ_j | mm/rad |
| **R_ri , R_pi** | 分别指 roll 行、pitch 行的第 i 个元素 | mm/rad |
| **J_l** | 绳长雅可比矩阵 ∂l/∂q（3×2） | mm/rad |
| **c_i 的导数** | 恒为 0 ⇒ 算力臂不需要 c_i；只有算绳绝对长度才要 | — |

**符号约定（必须记住）**：关节正转若使绳变长 ⇒ ∂l/∂θ > 0 ⇒ R < 0 ⇒ 张力**阻碍**正转。
所以 R 的元素是**带符号**的，不是"绳到轴的距离"那种正数。

## 7. 坐标系与变换（式 10–11、F1）

| 符号 | 含义 |
|---|---|
| **F0** | 零位固定坐标系（模型系）：原点是 roll 轴上离零位 pitch 轴最近的点；+X 沿零位 pitch 正轴，+Y 沿 roll 正轴，+Z = X×Y |
| **o_r , a_r** | roll 轴的点与方向：o_r = (0,0,0)，a_r = (0,1,0) |
| **o_p , a_p** | pitch 轴的点与方向：o_p = (0,0,24 mm)，a_p = (1,0,0) |
| **24 mm** | 两轴**正交但不相交**的最短间距（pitch 轴抬高 24 mm） |
| **Q_r , Q_p** | 绕 F0 中零位 roll 方向 / pitch 方向的右手旋转矩阵 |
| **B** | 3×3 基矩阵：**三列**分别是 F0 的 X、Y、Z 轴在 CAD 世界系中的基向量 |
| **Bᵀ** | B 的转置；世界→F0：p_model = Bᵀ(p_world − o_W) |
| **o_W** | 世界系原点在 CAD 世界系中的位置 ≈ (0, 210, 32.452121734611) mm |
| **p_world / zero_world_m** | 点在 CAD 世界系中的坐标（JSON 字段） |
| **zero_model_m** | 同一点换算到 F0 后的坐标（JSON 字段） |

> 坑：JSON 里 B 是"按行存数组"，但它代表的是"按列放基向量"。用错（不转置）最大会差 **183.85 mm**。

## 8. 标定、误差、门限（式 28–38、E1–E2）

| 符号 | 含义 |
|---|---|
| **z** | 待传播的参数向量（角度 + 有效系数，或角度 + 选定几何参数） |
| **J_z** | R（或 r）对 z 的雅可比 |
| **Σ_z** | z 的协方差矩阵 |
| **σ** | 标准差；1.96σ 在近似高斯下约等于 95% 覆盖（不是严格上界） |
| **∂r/∂α, ∂r/∂β, ∂r/∂γ** | 力臂对三个系数的灵敏度（式 33–35） |
| **ε_d** | 绳段差向量的不确定度界（长度量） |
| **η_max** | 允许的相对方向误差量级（无量纲） |

| **s_guard** | 工程门限：s_guard ≥ max(s_num, 2ε_d / η_max)（式 E1） |

| **Δτ_j** | 关节力矩误差界：|Δτ_j| ≤ Σ|ΔR_ji|·|f_i|（式 38） |
| **RMSE / 95% 绝对误差分位数 / 最大绝对误差** | 三个误差报告口径，含义不同，不能互相替代 |

## 10. 同名不同义：最容易混的 9 组（重点）

同一个字母在不同章节表示完全不同的东西，这是读这份 PDF 最大的障碍。

| 符号 | 身份 A | 身份 B | 身份 C |
|---|---|---|---|
| **C1** | 第 1 根绳（Cable 1） | 第三部分第 1 小节（C1. 六段最小长度） | — |
| **B** | 3×3 基矩阵（第 4 节 / F1） | **B₀** = 运动端零位点（第 5 节） | **B1–B5** = 五个边界中心姿态（附录 D1） |
| **D** | D(θ) = s²（第 5 节） | D1–D4 = 附录小节 | — |
| **u** | **单位方向向量**（第 4 节，‖u‖=1） | **位矢** u = A − o（第 5 节，长度是 mm） | — |
| **s** | 一段绳的长度 | S1–S5 = 第一部分公式编号 | s_num / s_guard = 门限 |
| **φ** | 相位角 φ₀（第 5 节，本表加的下标 0） | 轴线倾转参数 φ（E2，单位 rad） | — |
| **R / r** | R = 2×3 力臂**矩阵** | r(θ) = 单个**标量**力臂 | RMSE 里的 R |
| **P / p** | P01–P08 = 点名（大写+两位数字） | p₀、p(i,k) = 位置向量（小写斜体） | — |
| **A / a** | A = 固定端点 | a = 轴方向单位向量 | A1–A3 = 第一部分小节 |

另外两个小提醒：

- **γ（伽马）** 是 sin 项系数（mm²），不是角度；图中出现的 β 角是示意图里的夹角，与公式里的 β（mm²）不是一回事。
- **c_i**（小写 c）是常数长度和；**C1**（大写 C）是绳号。大小写要分清。

## 11. 实例：把 C2 的 roll 段每个符号都填上数

这是 PDF 第 7 节的官方例子，逐步填数（长度 mm，系数 mm²）：

| 符号 | 取值 | 怎么来的 |
|---|---|---|
| A | (−27, −16, 5) | P04 零位坐标 |
| B₀ | (−32.5, −12, 18) | P05 零位坐标 |
| o | (0, 0, 0) | roll 轴上的点 |
| a | (0, 1, 0) | roll 轴方向 |
| u = A − o | (−27, −16, 5) | |
| v = B₀ − o | (−32.5, −12, 18) | |
| ‖u‖² | 1010 | 729 + 256 + 25 |
| ‖v‖² | 1524.25 | 1056.25 + 144 + 324 |
| u·v | 1159.5 | 877.5 + 192 + 90 |
| a·u | −16 | |
| a·v | −12 | |
| a×v | (18, 0, 32.5) | 叉积 |
| u·(a×v) | −323.5 | −486 + 162.5 |
| **α** | **2150.25** | 1010 + 1524.25 − 2(−16)(−12) |
| **β** | **−1935** | −2[1159.5 − 192] |
| **γ** | **647** | −2(−323.5) |
| D(0) | 215.25 | α + β·1 + γ·0 |
| s(0) | 14.6714 | √215.25 |
| **r(0)** | **−22.0497** | (β·0 − γ·1)/(2√D) = −647/(2×14.6714) |
| ρ | 2040.30 | √(β² + γ²) |
| φ₀ | 161.51° | atan2(647, −1935) |
| D 的最小值 | 109.95 | α − ρ，出现在 θᵣ = −18.49° |
| 该点到 roll 轴的距离 | 37.15 | √(32.5² + 18²) |

**读法**：C2 这根绳在零位时，每 1 N 张力给 roll **−22.05 mN·m**（负号 = 阻碍 roll 正转）。
PDF 第 9 页的"最小段长表"六行，就是把这套 `D_min = α − ρ` 和 `θ = φ₀ ± 180°` 代入六个段得到的——六个数字全部对得上，可以当作公式正确性的自检。

## 12. 四个自检恒等式（算完就验一遍）

| 检查 | 公式 | 意义 |
|---|---|---|
| 1 | D(θ) > 0（在工作角内） | 否则根号无意义、绳方向无定义 |
| 2 | α ≥ ρ | 否则存在"绳长 = 0"的奇异角 |
| 3 | \|r(θ)\| ≤ 该运动点到轴的距离 | 力臂不可能大于旋转半径 |
| 4 | ∂R_ri/∂θ_p = ∂R_pi/∂θ_r = 0 | 解耦的推论；不为 0 说明绳路拓扑变了 |
