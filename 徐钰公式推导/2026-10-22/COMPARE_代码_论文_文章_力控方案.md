# 代码、R2 论文、R2 位置命令文档：力控方案详细对比

> 日期：2026-11-03
> 对象：
> 1. **论文**：Abdallah, Platt, Wampler, *Decoupled torque control of tendon-driven fingers with tension management*, IJRR 2013（R2 食指，3 自由度、4 腱）。
> 2. **文章**：`R2 腱驱动手指：准静态模型、力控制与纯位置控制.md`（对论文/专利的二次整理，含式(4)位置命令版、5/8/1 增益计数）。
> 3. **代码**：`mmhand_scope.py` + `wrist_force_law.py` + `wrist_tda.py`（3 绳、2 自由度腕，位置伺服，力控三模式）。
>
> 结论先行：**没有绝对“最好”的方案**。  
> - 论**解耦/理论完整性**：论文的 `P⁻ᵀ` 关节空间律最好；  
> - 论**约束/预紧/摩擦/位置接口**：你的代码（TDA + 内环 f PI）最实用；  
> - 论**简单/少调参**：文章的 5 增益 `Pᵀ` 位置律最好，但它不是论文的解耦律；  
> - 论**传感器失效/工程降级**：论文/专利的 graceful degradation 最完整，文章建议“纯位置不推荐”偏保守。

## 1. 三个对象的系统假设

### 1.1 论文（R2）

```
n = 3 个关节，m = 4 根腱
τ = R f,  R: 3×4
P = [R; W],  W: 1×4,  R Wᵀ = 0
τ = (τ; t),  t = W f
f = R⁺τ + Wᵀ t
```

- 腱近似线性弹簧：`f = k_t(x − Rᵀq)`；
- TDA 保证 `f_min ≤ f ≤ f_max`，不可行时 `α` 缩力矩；
- 电机命令是 `u`（电压/电流），执行器有动力学 `G(s)`；
- 论文比较两种控制律：腱空间 vs 关节空间。

### 1.2 文章（二次整理）

沿用 R2 的 3 自由度、4 腱模型，但把论文的电机命令 `u` **改写为位置命令 `x_d`**：

```
x_d = x − k_v ẋ
      − Rᵀ K_τ (R f − τ_d)
      − Wᵀ k_int (W f − t_d)          （4）
```

并数出：

- 力控内环：`K_τ` 3 + `k_int` 1 + `k_v` 1 = **5**；
- 完整位置—力：再加 `K_q` 3 = **8**；
- 纯位置：`x_d = R⁺R x − k_q Rᵀ(q − q_d)`，**1** 个增益。

文章明确说式(4)不是论文原始电压公式，但没有强调：**它是 `Pᵀ`，不是论文的 `P⁻ᵀ`**。

### 1.3 你的代码

```
3 根绳，2 个自由度
R: 2×3,  W: 1×3
τ = R f,  t = W f
```

力矩模式：

```
τ_meas = R f
e_τ = τ_d − τ_meas
u = kp_tau e_τ + ∫ki_tau e_τ
τ_cmd = τ_d + u
f_d = TDA(τ_cmd, t, fmin, fmax)      # 含 α 缩放
e_f = f_d − f
step = incr_PI(e_f, trim_gain, trim_gain)
x += trim_sign · step
```

- 外环 τ PI；
- TDA 显式分配；
- 内环 f 增量 PI（`trim_gain` 同时作 P/I）；
- 底层 P4/舵机位置环；
- 另有 `max_step/max_trim/fmin/fmax/trim_sign` 等限幅。

代码的 `_cl_tick_force` docstring 写“关节空间解耦力矩闭环”，但**结构上它是 TDA + 腱空间内环 f PI**，不是论文 §7 的 `P⁻ᵀ` 解耦律；这个标签容易误导。

## 2. 三套控制律的数学结构

### 2.1 论文：腱空间 vs 关节空间

**腱空间（§6）：**

```
f_d = P⁻¹ τ_d = R⁺τ_d + Wᵀ t_d      (20)
u = −k_p(f − f_d) − k_d ẋ            (21)
```

闭环出现：

```
Q = [I + s K̃⁻¹ R Rᵀ]⁻¹ Q_d          (27)
```

`R Rᵀ` 是**运动学耦合**，调参消不掉。

**关节空间（§7）：**

```
u = −P⁻ᵀ K_p(τ − τ_d) − k_d ẋ        (30)
```

其中：

```
K_p = diag(k_p I, k_pi)
```

闭环：

```
Q = [I + s K̃⁻¹]⁻¹ Q_d                (35)
```

`R Rᵀ` 消失，关节解耦，实验稳定时间约快 25%。

**关键：`P⁻¹` → `P⁻ᵀ`，不是 `Pᵀ`。**

---

### 2.2 文章：位置命令版 `Pᵀ` 梯度律

```
x_d = x − k_v ẋ − Pᵀ K (τ − τ_d)    （4）
```

其中：

```
Pᵀ = [Rᵀ  Wᵀ]
Pᵀ K (τ−τ_d) = RᵀKτ(Rf−τd) + Wᵀkint(Wf−td)
```

这是**梯度/转置控制**：

- 力矩误差大，就沿 `Rᵀ` 方向挪位置，减小误差；
- 内部张力误差大，就沿 `Wᵀ` 方向挪；
- `−k_v ẋ` 阻尼；
- 底层位置环追 `x_d`。

它不是论文的 `P⁻ᵀ`：

- `Pᵀ` 没有解耦保证；
- `P⁻ᵀ` 才把 `R Rᵀ` 消掉；
- 只有 P 正交时两者才相等，而 P 不是正交矩阵。

**文章式(4) 可以看作“位置型力控/梯度下降”，不是论文式(30) 的等价改写。**

---

### 2.3 代码：TDA + 内环 f PI + 外环 τ PI

```
τ 误差 → u（力矩修正）
τ_d+u → TDA → f_d
f_d−f → 内环 PI → 位置增量
```

它更接近论文 §6 的**腱空间控制**：

- TDA 显式算 `f_d`；
- 内环逐腱追 `f_d`（类似每腱 PD，但用增量 PI）；
- 外环 τ PI 是额外加的；
- 底层位置环相当于论文的执行器。

因此：

- 有 TDA 的约束/预紧能力；
- 有内环 f PI 的摩擦抑制；
- 但**仍有 `R Rᵀ` 耦合**；
- 增益/限幅比论文多。

## 4. 逐项分析

### 4.1 解耦：论文 `P⁻ᵀ` 最好，文章 `Pᵀ` 和代码都没有

论文的核心贡献是：

```
P⁻¹  →  P⁻ᵀ
```

腱空间闭环有 `R Rᵀ`；关节空间用 `P⁻ᵀ` 后，`R Rᵀ` 消失，传递函数变成 `[I+sK̃⁻¹]⁻¹`，每个关节独立一阶。

- 文章式(4) 用 `Pᵀ`：只是梯度方向，**不能消掉 `R Rᵀ`**；
- 代码用 TDA + 内环 f PI：仍在腱空间逐根闭合，**也不能消掉 `R Rᵀ`**；
- 论文 §6 的腱空间 PD 也有 `R Rᵀ`，代码和它同类；
- 所以“解耦”这一项，论文关节空间律是唯一有理论保证的。

**注意：** 代码的 `_cl_tick_force` docstring 写“关节空间解耦力矩闭环”，但实际是 TDA+内环，不是 `P⁻ᵀ`，这个标签不准确。

### 4.2 约束/预紧：代码和论文 TDA 好，文章式(4)有衔接问题

论文：

- TDA 选 `f_d`、`t_d`、`α`；
- 关节空间律用 `τ_d=(τ_d;t_d)`；
- `fmin/fmax` 由 TDA 保证。

代码：

- TDA 算 `f_d`，内环追 `f_d`；
- `fmin/fmax`、`α`、`max_step/max_trim` 都在；
- 约束/预紧最完整。

文章：

- 式(6) 算 `f_d=R⁺(ατd)+Wᵀtd`；
- 但式(4) 只用 `Rf−τd`、`Wf−td`，**不用 `f_d`**；
- 如果 `α<1`，式(4) 仍用原始 `τ_d`，会继续推，可能饱和/积分；
- 文章没有说明 `α` 如何进入式(4)；
- 所以文章的“TDA + 式(4)”是**两套结构的拼接**，不是严格闭环。

### 4.3 摩擦/弹性：代码内环最好，文章/论文依赖模型

- 论文腱模型是线性弹簧 `f=k_t(x−Rᵀq)`，忽略摩擦/迟滞；
- 文章式(4) 是位置命令梯度，没有内环力 PI；
- 代码内环 f PI 直接看张力传感器，能抑制摩擦/死区/迟滞；
- 但内环 PI 也带来相位滞后/调参问题；`trim_gain` 同时作 P/I，不是标准独立整定。

### 4.4 增益数量：文章最少，论文 5，代码 3+限幅

- 文章：R2 3DOF **5**；你的 2DOF **4**；完整位置—力 **6**；纯位置 **1**。
- 论文：R2 **5**（Kp 3+1 + kd）；你的 2DOF **4**。
- 代码：`kp_tau`、`ki_tau`、`trim_gain` = **3** 个 PID 类增益；但还有 `max_step_f`、`max_trim`、`fmin/fmax`、`trim_sign`、`preload` 等，不是“3 个就够”。
- 代码的 `kp_tau/ki_tau` 是**两个轴共用的标量**，不能像论文/文章的 `Kτ` 那样按轴独立整定；这是代码的一个限制。
- 文章的 5 不包含积分；加积分会变多。论文也说稳态误差可用限幅积分器解决。

### 4.5 传感器失效：论文/专利最完整，代码不足，文章偏保守

- 论文/专利：force control → position + selective compliance → pure position；有 graceful degradation。
- 文章：纯位置“只能抑制内部位置漂移，不能保证预紧”，最后说“不建议参考原文做法，直接不要控制了”——这是安全策略，不是控制律。
- 代码：张力失效时力控停/冻结；位置模式仍可用；但没有自动预紧保持/降级策略。
- 对你的系统，传感器失效时至少要有：
  - 保持位置 + 禁止零空间继续收绳；
  - 或缓慢回中/断使能；
  - 不能简单“继续跑力控”。

### 4.6 纯位置式：1 个增益，但会丢预紧

文章：

```
x_d = R⁺R x − k_q Rᵀ(q−q_d)
```

`R⁺R` 是到 R 行空间的投影：

```
x = Rᵀq + Wᵀθ
R⁺R x = Rᵀq
```

零空间分量 `Wᵀθ` 被丢掉。  
如果 `x` 是绝对位置、已含预紧，这个投影会**把预紧抹掉**，不是“保持预紧”。

文章第 266 行说“纯位置不能保证预紧”，更准确是：**这个公式会主动丢掉当前零空间分量**。  
要保留预紧，应投影**增量**，或加 `Wᵀt_d`，或改用增量式位置控制。

### 4.7 代码的“关节空间解耦”标签不准确

`_cl_tick_force` docstring：

> 100Hz 关节空间解耦力矩闭环：τ PI → TDA 分配 → 位置 trim。

但实际：

- 外环 τ PI 是关节空间误差；
- TDA 是腱空间分配；
- 内环 f PI 是腱空间逐根闭合；
- 没有 `P⁻ᵀ`，所以没有论文意义上的解耦。

它应该叫“TDA + 腱空间力内环 + 关节力矩外环”，不是“关节空间解耦”。

## 5. 哪一种方案更好？

### 5.1 按目标分

| 目标 | 更好 | 理由 |
|---|---|---|
| **关节解耦/响应速度** | **论文 §7 `P⁻ᵀ`** | 唯一有 `R Rᵀ` 消除和实验验证 |
| **张力约束/预紧安全** | **代码（TDA+内环）≈ 论文 TDA** | 显式 `fmin/fmax`、`α`、`t`；代码还有内环摩擦抑制 |
| **摩擦/迟滞/位置伺服适配** | **代码** | 内环 f PI 直接吃张力误差 |
| **最少调参/最简单** | **文章 5 增益 `Pᵀ`** | 5 个标量，位置命令直接实现 |
| **理论/论文贡献** | **论文** | 解耦证明 + 实验 + TDA |
| **传感器失效/工程降级** | **论文/专利** | 三种模式 graceful degradation |
| **纯位置/无张力传感器** | 文章/专利 | 1 个增益；但会丢预紧，只能保位置 |
| **你的当前硬件（位置伺服、3 绳 2 轴）** | **代码最实用；论文 `P⁻ᵀ` 最值得作为升级/对比** | 代码能直接跑；论文需位置命令适配 |

### 5.2 对你的系统的具体建议

**短期（调试/台架）**：

- 保留代码的 TDA + 内环 f PI + 外环 τ PI；
- 它是唯一已经适配“位置伺服 + 3 绳 + fmin/fmax + 预紧”的方案；
- 但要知道它**不是解耦**，横轴耦合可能仍在；
- 先做实验测 cross-coupling，再决定是否上 `P⁻ᵀ`。

**中期（论文/对比）**：

实现三条并列：

1. **A：当前代码**（TDA + 内环 f PI + 外环 τ PI）；
2. **B：论文关节空间位置命令版**：
   ```
   x_d = x − kp P⁻ᵀ Kp(τ − τ_d) − kv ẋ
   ```
   TDA 只负责 `t_d/α/fmin/fmax`；底层位置环；
3. **C：文章 5 增益 `Pᵀ` 版**：
   ```
   x_d = x − kv ẋ − RᵀKτ(Rf−τd) − Wᵀkint(Wf−td)
   ```
   用 TDA 做 `td/α/lim`。

同一组阶跃/正弦/预紧/摩擦实验，比较：

- 力矩跟踪误差；
- 交叉轴耦合；
- 张力跟踪/约束违反；
- 稳定时间/超调；
- 增益敏感性；
- 传感器失效行为。

**长期（论文推荐）**：

- 如果目标是“解耦 + 理论完整”：选 **B（论文 `P⁻ᵀ` 位置命令版）**；
- 如果目标是“工程鲁棒 + 摩擦/约束”：选 **A（代码）**，或 **A 的 TDA + B 的外环** 的混合；
- 如果目标是“少调参/快速验证”：选 **C（文章 5 增益）** 作为 baseline，但不要声称它解耦。

### 5.3 为什么不能简单说“论文最好”

论文的 `u` 是电机命令（电压/电流），你的 P4/舵机只接受位置；直接套论文式(30) 不现实。  
专利把它改成位置命令：

```
x_d = x − kp P⁻ᵀ Kp(τ − τ_d)
```

这是论文在你硬件上最接近的落地形式。  
但它仍假设：

- 底层位置环足够快；
- 腱模型/张力测量可信；
- TDA 的 `td/α` 正确接入；
- 没有强摩擦/迟滞。

你的代码用内环 f PI 补了摩擦，但也因此回到腱空间，失去 `P⁻ᵀ` 的解耦。  
**这是一个真实的工程权衡：解耦 vs 摩擦/约束。**

## 6. 推荐实验矩阵（论文/ thesis 用）

| 实验 | 目的 |
|---|---|
| τ_roll 阶跃，τ_pitch=0 | 看 cross-coupling（A/B/C 对比） |
| τ 正弦扫频 | 带宽/相位/解耦 |
| 预紧 t 阶跃 | 内部张力跟踪/约束 |
| 单缆摩擦/迟滞 | 内环 f PI 的价值 |
| fmin/fmax 边界 | TDA/α 行为 |
| 增益 ±50% | 鲁棒性/调参敏感性 |
| 张力传感器断线 | 降级/安全 |
| 纯位置 vs 力控 | 预紧漂移 |

指标：

```
RMS τ 误差、cross-axis τ、settling time、overshoot、
RMS f 误差、fmin/fmax violation、preload drift、
gain sensitivity、sensor-failure behavior
```

## 7. 一句话结论

- **论文**：`P⁻ᵀ` 关节空间律，解耦最好，理论/实验最完整；但原始是电机命令，需专利位置化。
