## 六、接手必须知道的实现约束

1. **客户端入口格式固定**：`window.__ModuleLoader__.load({ id: '<包名>', factory(require) { ... } })`，`id` 必须等于包名 `@local/formula-panel`；React 从 `require('react')` 取，模板无 JSX，用 `React.createElement`。
2. **一个入口占两个插槽**：`sidebar.panellist` 注册 `id`，`main` 注册同名 `key`；`id` 与 `key` 必须一致，否则按钮点不开面板。注意 `:hover` 规则必须放在 `<style>` 里，不能用行内 `style` 覆盖（行内会赢）。
3. **样式只用主题 token**：`--dsw-alias-bg-base/layer-1/layer-2/bg-overlay`、`--dsw-alias-border-l1/l2`、`--dsw-alias-brand-primary`、`--dsw-alias-label-primary/secondary`、`--dsw-alias-state-success/error/idle/warn-primary`。不要写死颜色（图标美术除外）。
4. **禁止 import Harness Client 包**（如 `dsh-client-ui-primitives`）；需要控件样式就自己写，类名加前缀。
5. **单文件限制**：浏览器端 loader 只能加载一个 `client.js`，不能 `require` 本地文件，所以数据和 UI 必须同文件（数据块在 `const GROUPS = [...]`，约 250 行）。
6. **文案语言**：通过 `ctx.get('locale')` 取 `getSnapshot().active`，以 `zh` 前缀判断切中英文；条目名是中文（领域内容），界面 chrome 才做双语。
7. **资源清理**：定时器、locale 订阅都在 `apply`/`useEffect` 里用 disposer 释放；`<style>` 作为组件内 React 元素，卸载即移除。
8. **宿主插槽语义**：`sidebar.panellist` 的 id 同时就是 `main` 的派发 key；列表项由侧栏自己渲染按钮，`label` thunk 每次投影重新读，所以语言切换无需重注册。

## 七、安装、更新、卸载

安装（在 DSH 会话里调用工具，不需要 shell）：

```
plugin_manager  action: install_bundle  target: <包目录绝对路径>
```

- 本地目录是**软链安装**，改代码不用重装；但**浏览器端模块要刷新页面（F5）或重启 App 才换新代码**——重装 bundle 只保证宿主重新同步 manifest，不保证浏览器已换模块。
- 若重装报 `restart-required`，按提示重启。
- 卸载：`plugin_manager action: remove_bundle target: @local/formula-panel`（本次已验证可用，`application: applied`）。
