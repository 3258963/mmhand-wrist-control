# 三维旋转矩阵：绕 Z、X、Y 轴到底是怎么算出来的

> 一句话：**绕某根轴转 θ，就是让"沿轴的那一段一动不动"，只把"垂直轴的那一段"在它的平面里转 θ。**
> 三维矩阵 = 一个 2×2 的平面旋转 + 一个"不动"的 1；小方块摆在哪儿，就说明绕哪根轴转。

## 0. 先把结论摆出来

约定：**右手定则、列向量、角度用弧度**。θ > 0 时，右手拇指指向 +轴，四指弯曲的方向就是转动方向。

```
Rz(θ) = [  cosθ   -sinθ    0  ]
        [  sinθ    cosθ    0  ]
        [    0       0     1  ]

Rx(θ) = [    1       0      0  ]
        [    0     cosθ  -sinθ  ]
        [    0     sinθ   cosθ  ]

Ry(θ) = [  cosθ      0    sinθ ]
        [    0       1      0   ]
        [ -sinθ      0    cosθ ]
```

三个矩阵长得几乎一样，只有两处不一样：**±sinθ 落在哪两行两列**、**哪个位置是那个孤零零的 1**。
这两件事都由"绕哪根轴"唯一决定，下面把它推出来。

---

## 1. 二维修身版：矩阵的两行就是两个读数

（对应 `图1_二维推导.png`）

### 1.1 只需要一个事实：转完长度不变

一个长度 1 的箭头 V，原来和 x 轴夹角 φ。转 θ 之后变成 V′，夹角变成 φ+θ，**长度还是 1**（图里那条虚线圆弧）。

那么 V′ 的两个分量是什么？按定义就是：

```
V′x = cos(φ+θ)
V′y = sin(φ+θ)
```

### 1.2 只用一步：两角和公式

```
cos(φ+θ) = cosφ·cosθ − sinφ·sinθ
sin(φ+θ) = sinφ·cosθ + cosφ·sinθ
```

而 V 自己的分量是 Vx = cosφ、Vy = sinφ，代回去：

```
V′x = Vx·cosθ − Vy·sinθ
V′y = Vx·sinθ + Vy·cosθ
```

写成矩阵：

```
[ V′x ]   [ cosθ  -sinθ ] [ Vx ]
[ V′y ] = [ sinθ   cosθ ] [ Vy ]
```

**推导到此结束。整个二维旋转矩阵，就是"两角和公式"的矩阵写法。**

### 1.3 两种读法（都很重要）

- **按行读**：第 1 行告诉你"新的 x 分量怎么由旧的 x、y 拼出来"。这就是"坐标怎么变"。
- **按列读**：第 1 列 = 转完之后 x 轴指到了哪儿，第 2 列 = y 轴指到了哪儿。
  代入 θ=90° 一看就懂：第 1 列是 (0, 1)，说明 x 轴转到了 +y；第 2 列是 (−1, 0)，说明 y 轴转到了 −x。

> **记法**：矩阵的列 = "转完后每根轴的新位置"，这是最不容易背错的读法。
> 三维的三个矩阵，用这个读法 30 秒就能自己写出来。

## 2. 从二维到三维：只多了一个"不动的轴"

（对应 `图2_三轴总览.png`）

### 2.1 核心事实

绕 z 轴转的时候，z 坐标**从头到尾没变过**。所以：

```
z′ = z
```

xy 平面里的那两个分量，就是第 1 节算出来的二维结果。把 z 这一行补成 (0, 0, 1)：

```
[ x′ ]   [ cosθ  -sinθ   0 ] [ x ]
[ y′ ] = [ sinθ   cosθ   0 ] [ y ]
[ z′ ]   [   0      0     1 ] [ z ]
```

**Rz 就是这么来的，没有任何新东西。**

### 2.2 换根轴，就是换个"不动的字母"

绕 x 轴转，x 不动；转的是 (y, z) 这一对。把二维结果原样搬进 y、z 两行两列：

```
[ x′ ]   [  1     0      0   ] [ x ]
[ y′ ] = [  0    cosθ  -sinθ ] [ y ]
[ z′ ]   [  0    sinθ   cosθ ] [ z ]
```

绕 y 轴转，y 不动；转的是 (z, x) 这一对。**注意先后顺序是 z 在前、x 在后**：

```
[ x′ ]   [ cosθ    0    sinθ ] [ x ]
[ y′ ] = [   0     1      0  ] [ y ]
[ z′ ]   [ -sinθ   0    cosθ ] [ z ]
```

### 2.3 为什么 Ry 的符号看着"反"？

因为**循环顺序**是 x → y → z → x，三对循环轴分别是：

```
(x, y)   (y, z)   (z, x)
```

在每一对 (u, w) 里，规律是固定的：

```
u′ = c·u − s·w
w′ = s·u + c·w
```

- 绕 Z：(u, w) = (x, y)，所以 x′ 那一行是 (c, −s)，y′ 那一行是 (s, c)。
- 绕 X：(u, w) = (y, z)，所以 y′ 那一行是 (c, −s)，z′ 那一行是 (s, c)。
- 绕 Y：(u, w) = (z, x)，所以 **z′ 那一行是 (c, −s)，x′ 那一行是 (s, c)** ——
  落到矩阵里，x 行就变成 (c, 0, s)，z 行变成 (−s, 0, c)。看上去"反了"，其实完全没反：
  **是 y 轴的循环对 (z, x) 跟别人不一样，不是公式不一样。**

> 记法：三根轴按 x→y→z→x 排成一个圈，每一对都取圈上的"下一根"。
> 谁在前谁拿 −s，谁在后谁拿 +s。

| 绕哪根轴 | 不动的轴 | 平面里的循环对 (u, w) | 小方块摆在 3×3 的哪儿 |
|---|---|---|---|
| Z | z | (x, y) | 左上角 2×2 |
| X | x | (y, z) | 右下角 2×2 |
| Y | y | (z, x) | 四个角（第 1、3 行与列） |

## 3. 沿轴看下去：为什么"正转"是逆时针

（对应 `图3_沿轴俯视.png`）

把眼睛放到 +轴那一端，回头看原点，你会看到那个 2×2 小方块的平面。三张俯视图里，**正转都是逆时针**：

| 从哪儿看 | 看到的平面 | 横轴 | 竖轴 | 正转 |
|---|---|---|---|---|
| +Z 往下看 | (x, y) | x | y | 逆时针 |
| +X 看 | (y, z) | y | z | 逆时针 |
| +Y 看 | (z, x) | z | x | 逆时针（相当于把图转 90° 再看） |

这就是**右手定则**：拇指指向 +轴，四指弯曲 = 正转方向。

两条推论，做题时很管用：

1. **从反方向看，正转就是顺时针。** 所以"顺时针/逆时针"这种说法必须先说清楚站在哪一边，否则没有意义。
2. **2×2 小方块嵌在哪个平面里，就是绕哪根轴转。** 想不起来矩阵长什么样时，先问自己"哪个字母不动"，剩下的自然就位。

## 4. 三个矩阵的"体检"

| 项目 | 绕 Z | 绕 X | 绕 Y | 含义 |
|---|---|---|---|---|
| det | +1 | +1 | +1 | 体积不变、不镜像（手性不变） |
| RᵀR | I | I | I | 每列是单位正交基，长度不变、角度不变 |
| 逆矩阵 | Rz(−θ) = Rzᵀ | Rx(−θ) = Rxᵀ | Ry(−θ) = Ryᵀ | **转回去 = 转置**，不用求逆 |
| 不动的特征向量 | (0,0,1) | (1,0,0) | (0,1,0) | 特征值 +1，就是那根轴 |

**θ = 90° 的特殊值**（最常用的自检）：

```
Rz(90°)： x → +y     y → −x     z → +z
Rx(90°)： x → +x     y → +z     z → −y
Ry(90°)： x → −z     y → +y     z → +x
```

顺序永远是"前一列转到后一列"：x→y→−x→−y→x 是一个四步循环。**记住循环方向，就不会把正负号写反。**

**小角度近似**（做误差分析、雅可比时天天用）：

```
R(a, θ) ≈ I + θ·[a]×          （[a]× 是 a 的反对称矩阵）
误差是 O(θ²)，θ = 1e-4 rad 时实测只有 5e-9。
```

数值校验（脚本 `checks()` 的输出，节选）：

```
Rz(30°) = [ +0.866025  -0.500000  +0.000000 ]
          [ +0.500000  +0.866025  +0.000000 ]
          [ +0.000000  +0.000000  +1.000000 ]
          det = +1.000000000    max|RᵀR − I| = 0.00e+00
```

三个矩阵的 det 都是 +1，`max|RᵀR−I|` 都是 0 —— 正交性在数值上也是精确的。

## 5. 组合：顺序不能交换

（对应 `图4_顺序不可交换.png`）

### 5.1 矩阵乘法 = 依次作用，右边的先干

```
v′ = R2 · (R1 · v) = (R2 · R1) · v
```

所以 `R = Rx·Rz` 的意思是：**先转 Z，再转 X**（写在右边的先作用在向量上）。

### 5.2 换顺序，结果不同

```
Rx(90°)·Rz(90°) = [ 0  -1   0 ]        Rz(90°)·Rx(90°) = [ 0   0   1 ]
                   [ 0   0  -1 ]                          [ 1   0   0 ]
                   [ 1   0   0 ]                          [ 0   1   0 ]
```

两个矩阵差的最大元素是 1 —— 完全不同的姿态。物理上也很好理解：**"先绕 Z 转"和"先绕 X 转"，第二根轴到底在哪儿，根本不是一回事。**

（同样的两个 90°，先 Z 后 X 时 X′ 落在 +z；先 X 后 Z 时 X′ 落在 +y。图 4 里两个三脚架就是这么差开的。）

### 5.3 内旋 / 外旋：同一串乘法的两种说法

```
R = Rz(γ) · Ry(β) · Rx(α)
```

这句话有两种等价读法：

- **外旋（绕固定轴）**：先绕世界 X 转 α，再绕世界 Y 转 β，最后绕世界 Z 转 γ。
- **内旋（绕自身轴）**：先绕自身 Z 转 γ，再绕"转完后的" Y 转 β，最后绕"又转完后的" X 转 α。

这就是航空/机器人里常说的 **ZYX 欧拉角（yaw–pitch–roll）**。两种说法算出来是同一个矩阵，
但跟别人对接时**必须说清楚是哪一种**，否则差一个顺序就是灾难。

## 6. 接到你手头这个二轴腕部

按你文档里的约定（`绳驱二轴腕部_公式讲解_小白版.md`，PDF 原文）：

- **roll 正方向 = +Y，pitch 正方向 = +X，右手定则，向量按列写。**

于是"palm 相对 base"的姿态矩阵就是两个矩阵相乘：

```
R(θr, θp) = Ry(θr) · Rx(θp)

p_base = R · p_palm + t
```

**为什么顺序是 Ry 在左、Rx 在右？** 因为 pitch 轴是**长在 roll 体上**的：

- 作用到向量上时，先做 Rx（绕"当时身上的" x 轴 = pitch 轴），再做 Ry（roll）——所以 Rx 写在右边。
- 反过来说：从左往右读是"先 roll 后 pitch"，从右往左读是"先作用 pitch 再作用 roll"，两种说法指同一件事。

**pitch 轴随 roll 一起转，方向要算：**

```
a_pitch = Ry(θr) · [1, 0, 0]ᵀ = [ cosθr, 0, −sinθr ]ᵀ
```

这正是你文档里那句提醒的矩阵写法：

> 式 (9) 里的 a_j、o_j 必须是**当前姿态**下的值，pitch 轴会随 roll 一起转，
> 不能钉死在世界 X 轴上。

也就是说，`∂p/∂q = a × (p − o)` 里那个 `a`，写代码时必须**每算一个姿态就重算一次**，不能在外面算一次就复用。

反过来，如果哪天改成"pitch 轴固定在 base 上"，姿态矩阵就变成 `Rx(θp)·Ry(θr)`，
和现在的 `Ry(θr)·Rx(θp)` 差一个交换 —— 这就是 5.2 节说的那件事。

## 7. 常见坑清单（每条都真实坑过人）

1. **度 / 弧度**。矩阵里全是弧度。用度直接代进去，sin/cos 会算错，求导还会差 57.3 倍。
2. **行向量 vs 列向量**。上面全是列向量 `v′ = R v`。若你用行向量 `v′ = v R`，矩阵要**转置**，而且乘法顺序要**反过来**。
3. **主动 / 被动**。转物体（主动）和转坐标系（被动）差一个转置：`R_passive(θ) = R_active(−θ) = R_activeᵀ(θ)`。跟别人对数字前先问一句"你转的是物体还是坐标系"。
4. **右手系还是左手系**。左手系里所有 ±sinθ 全部反号。CAD 里偶尔会碰到。
5. **顺序**。不可交换，而且"先转谁"取决于写在左边还是右边。写代码时把顺序写成注释。
6. **Ry 的符号**。它跟 Rx、Rz 长得不一样，是因为循环对是 (z, x)。别硬背，用"z 在前拿 −s"推。
7. **轴是否随动**。轴长在哪个刚体上，就要用哪个刚体的累积姿态去转它（本节的 a_pitch 就是例子）。
8. **90° 时手滑**。矩阵里全是 0 和 ±1，最容易把 −1 写成 1。用第 4 节的循环自检。

## 8. 自己动手验一遍

```python
import numpy as np

def Rz(t):
    c, s = np.cos(t), np.sin(t)
    return np.array([[c, -s, 0], [s, c, 0], [0, 0, 1]])

def Rx(t):
    c, s = np.cos(t), np.sin(t)
    return np.array([[1, 0, 0], [0, c, -s], [0, s, c]])

def Ry(t):
    c, s = np.cos(t), np.sin(t)
    return np.array([[c, 0, s], [0, 1, 0], [-s, 0, c]])

R = Rz(np.pi/2) @ Rx(np.pi/2)        # 先 X 后 Z
print(np.round(R, 6))
print(np.linalg.det(R))              # 应该正好是 1
print(np.allclose(R.T @ R, np.eye(3)))   # True
```

自己加三行检查，比背十遍都管用：

- `det(R) == 1`
- `R.T @ R == I`
- 把 90° 代进去，看 x、y、z 三根轴分别落到哪儿，跟第 4 节的表对一遍。
