## 0. 先看结论（三句话）

1. **论文**：在“关节层”做力控，用 `P⁻ᵀ` 把腱与腱之间的耦合消掉，**解耦最好、理论最完整**；但它原本输出的是电机电压/电流命令，不是位置。
2. **文章**：把力控改写成“位置命令”，用 `Rᵀ`、`Wᵀ` 直接把误差推成位置修正，**最简单、增益最少**；但它用的是 `Pᵀ`，**不是论文的 `P⁻ᵀ`，没有解耦保证**。
3. **你的代码**：TDA 分配 + 内环张力 PI + 外环力矩 PI，**最适合“位置伺服 + 3 根绳 + 张力上下限 + 预紧”的硬件**；但它本质仍是“腱空间”逐根控力，**不是论文的解耦律**，调参也最多。

**没有绝对最好，只有“你现在的目标是什么”。**

## 1. 零基础先懂 10 个词

| 词 | 大白话 |
|---|---|
| 关节 / 自由度 | 手指能弯的方向。R2 食指 3 个；你的腕 2 个（ROLL、PITCH）。 |
| 腱 / 绳 | 拉手指的绳子。R2 4 根；你的腕 3 根。 |
| 张力 `f` | 每根绳拉得多紧，单位 N。绳只能拉，不能推，所以 `f ≥ 0`。 |
| 力矩 `τ` | 关节“拧”的力量，单位 N·m。 |
| `R` | “哪根绳影响哪个关节”的表。`τ=Rf`：把三/四根绳的力，换算成关节力矩。 |
| `W` | “三根绳一起收紧、但关节不动”的方向。`Wf=t`：内部预紧。 |
| 预紧 `t` | 三根绳互相较劲，关节不歪，但绳绷得很紧。 |
| TDA | 张力分配算法：给定目标力矩，算出每根绳该拉多少，并保证不松、不过载。 |
| 内环 / 外环 | 外环管“整体要多少”，内环管“每根绳拉到多少”。 |
| 位置伺服 | 电机只听得懂“走到多少位置”，听不懂“输出多少力矩”。 |

### 1.1 一个生活类比：三个人抬桌子

想象一张桌子，三个人各拉一根绳，要让桌子“往左倾 0.1、往前倾 0.2”。

- **R**：告诉你“拉 C1 绳主要影响左倾，拉 C3 绳主要影响前倾”。
- **W / 预紧**：三个人一起用力，但方向互相抵消，桌子不倾斜，只是绳更紧。
- **TDA（工头）**：老板说“我要左倾 0.1、前倾 0.2”，工头把它分给三个人：“C1 拉 3 N、C2 拉 5 N、C3 拉 7 N”。
- **力控内环（每个工人）**：每个人看自己那根绳的测力计，手往前/往后挪，直到自己的力到目标。
- **关节空间控制（老板直接看桌子）**：老板不看每个人，直接看桌子倾斜，发现不够就喊“再往左”，用一套数学把“桌子倾斜误差”翻译成“三个人各挪多少”。

**论文的贡献，就是发现：“每个人各自调力”会互相干扰；“老板直接看桌子”可以解耦。**

## 2. 论文到底做了什么？

### 2.1 先建模：把手指写成方程

论文假设：

```
τ = R f
```

- `f`：4 根绳的张力；
- `τ`：3 个关节的力矩；
- `R`：3×4 的“腱映射”，元素是滑轮半径（带符号）。

因为 4 根绳控制 3 个关节，**多了一根**，所以同一个 `τ` 有无穷多组 `f`。  
论文引入：

```
P = [R; W]
f = R⁺ τ + Wᵀ t
```

- `R⁺`：伪逆，给出“最小范数”的绳力；
- `W`：零空间（1×4），`R Wᵀ=0`；
- `t`：内部预紧，标量。

**大白话**：

> 先算出“干活最少”的那组绳力 `R⁺τ`，再沿 `Wᵀ` 方向加一个预紧 `t`。  
> 预紧不改变关节力矩，只让绳更紧。

### 2.2 TDA：工头怎么分力

TDA 要满足：

```
f_min ≤ f ≤ f_max
R f = α τ_d
0 ≤ α ≤ 1
```

- 每根绳不能太松（`f_min`），也不能太紧（`f_max`）；
- 如果目标力矩太大，三根绳怎么分都超限，就把力矩按 `α` 缩小；
- 在可行解里，尽量让内部预紧 `t` 小。

论文的 TDA 算法（Algorithm 2）能在有限步内找到 `α`、`t`、`f`。  
你的代码里的 TDA 也是同一类思路。

### 2.3 论文的第一个控制律：腱空间（旧方法）

第一步，TDA 把目标力矩变成目标张力：

```
f_d = P⁻¹ τ_d = R⁺τ_d + Wᵀ t_d
```

第二步，每根绳一个 PD 伺服：

```
u = −k_p (f − f_d) − k_d ẋ
```

- `u`：电机命令（电压/电流）；
- `k_p`：力误差增益；
- `k_d`：阻尼；
- `ẋ`：电机速度。

**大白话**：每根绳各自看自己的力，谁不够就加，谁超了就减。

**问题**：4 根绳通过 `R` 连在一起。你让 C1 加力，关节 1 和关节 2 的力矩都会变。  
论文推导出闭环里有一个：

```
R Rᵀ
```

这就是“瞬态耦合”的数学来源：命令一个关节，另一个关节会先往反方向抖一下。  
**这不是调参能消掉的，是运动学本身。**

### 2.4 论文的第二个控制律：关节空间（新方法）

论文做了一个“搬家家”：

```
ũ = P⁻ᵀ u
```

把电机命令搬到“关节空间”，在那里设计一个解耦 PD：

```
ũ = −K_p (τ − τ_d) − K_d q̇
```

再搬回电机命令：

```
u = −P⁻ᵀ K_p (τ − τ_d) − k_d ẋ
```

**关键：`P⁻¹` 变成了 `P⁻ᵀ`。**

- `P⁻¹`：逆；
- `P⁻ᵀ`：逆的转置。

论文证明：用 `P⁻ᵀ` 后，闭环变成：

```
Q = [I + s K̃⁻¹]⁻¹ Q_d
```

`R Rᵀ` 不见了！每个关节独立响应，没有“先反着抖一下”，稳定时间约快 25%。

**大白话**：

> 腱空间控制是“每个人各自调力”，会互相干扰；  
> 关节空间控制是“老板直接看桌子”，用 `P⁻ᵀ` 把“每个人”翻译成“桌子”，干扰就消了。

### 2.5 论文的优缺点

**优点：**

- 有严格的闭环分析；
- `P⁻ᵀ` 真正解耦；
- TDA 保证张力上下限；
- 有 R2 实验验证（稳定时间 1.3s→0.97s，2.2s→1.7s）。

**缺点：**

- 原始 `u` 是电机命令（电压/电流），不是位置；
- 假设腱是线性弹簧，摩擦/迟滞没建模；
- 需要知道 `R`、`W`、`k_t`；
- 电机动力学 `G(s)` 要比较快，否则解耦假设不成立。

## 3. 文章做了什么？

文章是把论文/专利“翻译成人话”的二次整理。  
它最核心的式(4)是：

```
x_d = x
      − k_v ẋ
      − Rᵀ K_τ (R f − τ_d)
      − Wᵀ k_int (W f − t_d)
```

### 3.1 逐项解释

| 项 | 大白话 |
|---|---|
| `x` | 当前电机位置。 |
| `−k_v ẋ` | 刹车/阻尼：速度越大，往回拉得越多，防止冲过头。 |
| `−RᵀKτ(Rf−τd)` | 实际力矩比目标大，就沿 `Rᵀ` 方向把绳放松一点；小了就收紧。 |
| `−Wᵀkint(Wf−td)` | 内部预紧比目标大，就放松；小了就收紧。 |
| `x_d` | 算出来的“目标位置”，底层位置环去追。 |

**大白话**：

> 看实际力矩和目标的差，看预紧和目标的差，直接推一个“位置修正量” `x_d`。  
> 底层电机位置环负责走到 `x_d`。

### 3.2 它是 `Pᵀ`，不是论文的 `P⁻ᵀ`

把式(4)写成矩阵：

```
x_d = x − k_v ẋ − Pᵀ K (τ − τ_d)
```

因为：

```
Pᵀ = [Rᵀ  Wᵀ]
Pᵀ K (τ−τ_d) = RᵀKτ(Rf−τd) + Wᵀkint(Wf−td)
```

而论文是：

```
u = −P⁻ᵀ K_p (τ − τ_d) − k_d ẋ
```

**一个是 `Pᵀ`，一个是 `P⁻ᵀ`。**

- `Pᵀ`：转置，是“往误差下降方向推”；
- `P⁻ᵀ`：逆的转置，是“坐标变换”，能解耦；
- 只有 P 是正交矩阵时，两者才相等；P 不是正交的。

**所以文章式(4)不是论文式(30)的等价改写。**  
文章第 313 行也承认“式(4)不是论文原始电压公式”，但没强调“它也不是 `P⁻ᵀ`”。

### 3.3 文章的 5/8/1 增益

文章按 R2 的 **3 自由度、4 根腱**数：

| 增益 | 数量 | 作用 |
|---|---:|---|
| `K_τ` 对角 | 3 | 每个关节一个力矩误差增益 |
| `k_int` | 1 | 内部预紧误差增益 |
| `k_v` | 1 | 速度阻尼 |
| **力控内环** | **5** | P/PD，不含积分 |
| `K_q` 对角 | 3 | 位置误差→目标力矩 |
| **完整位置—力** | **8** | 5+3 |
| 纯位置 `k_q` | **1** | 只有位置误差增益 |

**对你的 2 自由度腕：**

```
Kτ 2 + kint 1 + kv 1 = 4
再加 Kq 2 = 6
纯位置 = 1
```

不是 5/8，是 **4/6/1**。

### 3.4 文章的纯位置公式：1 个增益，但会丢预紧

```
x_d = R⁺R x − k_q Rᵀ(q − q_d)
```

`R⁺R` 是到 R 行空间的投影。把腱位置分解：

```
x = Rᵀq + Wᵀθ
R⁺R x = Rᵀq
```

零空间分量 `Wᵀθ` 被丢掉了。  
如果 `x` 是绝对位置、里面已经含预紧，这个投影会**把预紧抹掉**，不是“保持预紧”。

文章第 266 行说“纯位置不能保证预紧”，更准确是：**这个公式会主动丢掉当前零空间分量**。  
要保留预紧，应该投影**增量**，或加 `Wᵀt_d`，或改用增量式位置控制。

### 3.5 文章的问题

1. **式(4) 不是论文的 `P⁻ᵀ`**；
2. **式(4) 不用 TDA 的 `f_d`**：文章前面算 `f_d=R⁺(ατd)+Wᵀtd`，但式(4) 只用 `τd`、`td`；`α<1` 时怎么办没说；
3. **5 个增益不含积分**：稳态误差可能消不掉；论文说可加限幅积分器；
4. **纯位置会丢预紧**；
5. **“不建议纯位置，直接不要控制”是安全策略，不是控制律结论**。

## 4. 你的代码做了什么？

### 4.1 信号流

```
τ_d（目标力矩）
   │
   ▼
τ_meas = R f
   │
e_τ = τ_d − τ_meas
   │
外环 τ PI：u = kp_tau e_τ + ∫ki_tau e_τ
   │
τ_cmd = τ_d + u
   │
TDA：f_d = R⁺τ_cmd + Wᵀ t（含 fmin/fmax、α）
   │
e_f = f_d − f
   │
内环 f 增量 PI：step = _incr_step(e_f, trim_gain, trim_gain)
   │
x += trim_sign · step
   │
底层电机位置环
```

**大白话**：

1. 先算实际力矩（用三根绳的张力乘 R）；
2. 和目标力矩比，外环 PI 算一个“力矩修正”；
3. TDA 把修正后的力矩分给三根绳，得到 `f_d`；
4. 内环看每根绳的实际张力，和 `f_d` 比，算出位置增量；
5. 电机位置环走。

### 4.2 它其实是“腱空间 + 外环”

- TDA 算 `f_d`；
- 内环逐根追 `f_d`；
- 这跟论文 §6 的腱空间控制是同一类；
- 外环 τ PI 是额外加的；
- 它**不是**论文 §7 的 `P⁻ᵀ` 关节空间控制。

所以：

- 它会有 `R Rᵀ` 耦合；
- 内环 f PI 不能消掉运动学耦合，只能抑制摩擦/扰动；
- 代码 docstring 写“关节空间解耦力矩闭环”，这个标签**不准确**。

### 4.3 代码的增益

```
kp_tau    ：外环力矩 P
ki_tau    ：外环力矩 I
trim_gain ：内环 P 和 I 共用一个旋钮
```

再加：

```
max_step_f、max_trim、trim_sign、f_min、fmax_f、preload
```

- `kp_tau/ki_tau` 是**两个轴共用的标量**，不能像论文 `Kτ` 那样按轴独立调；
- `trim_gain` 同时当 P/I，不是标准独立整定；
- 没有显式 `k_v ẋ` 阻尼，靠位置伺服/`max_step`；
- 有 `ki_tau`，所以比文章的 5 增益多一个积分。

### 4.4 代码的优缺点

**优点：**

- 直接适配位置伺服；
- TDA 显式处理 `fmin/fmax`、预紧、α；
- 内环 f PI 能抑制摩擦/迟滞；
- 有 `max_step/max_trim` 限速/限行程；
- 外环积分能消稳态误差。

**缺点：**

- 腱空间逐根闭环，仍有 `R Rᵀ` 耦合；
- 调参多（外环 P/I + 内环 P/I + TDA/限幅）；
- 没有论文的 `P⁻ᵀ` 解耦；
- `kp_tau/ki_tau` 不分轴；
- “关节空间解耦”标签误导。

## 6. 到底哪一种更好？

### 6.1 按目标选

| 你的目标 | 推荐 | 为什么 |
|---|---|---|
| **关节解耦、响应快** | **论文 `P⁻ᵀ`** | 唯一有 `R Rᵀ` 消除和实验验证 |
| **张力上下限、预紧安全** | **代码 / 论文 TDA** | 显式 `fmin/fmax`、`α`、`t` |
| **摩擦/迟滞大、位置伺服** | **代码** | 内环 f PI 主动补 |
| **最少调参、最快上手** | **文章 5 增益 `Pᵀ`** | 4 个增益（你的 2 轴）就能跑 |
| **论文/毕业设计** | **论文 + 代码对比** | 论文有理论，代码有工程 |
| **传感器失效** | **论文/专利** | 三种模式降级 |
| **纯位置、无张力传感器** | 文章/专利 | 1 个增益；但会丢预紧 |

### 6.2 对你的 3 绳 2 轴腕，我的建议

**不要直接说“论文最好”就照抄。**  
论文的 `u` 是电压/电流，你的 P4/舵机只吃位置。  
最接近论文的落地形式是专利的位置命令版：

```
x_d = x − kp P⁻ᵀ Kp(τ − τ_d) − kv ẋ
```

TDA 只负责：

- 选 `t_d`；
- 检查 `fmin/fmax`；
- 不可行时 `α` 缩力矩。

**推荐三条路线，做 A/B/C 对比：**

#### A：当前代码（腱空间 TDA + 内环 f PI + 外环 τ PI）

- 优点：能直接跑；约束/预紧/摩擦都照顾；
- 缺点：不解耦；调参多；
- 用途：**工程基线**。

#### B：论文 `P⁻ᵀ` 位置命令版

```
x_d = x − kp P⁻ᵀ Kp(τ − τ_d) − kv ẋ
```

- TDA 选 `t_d/α`；
- 无内环 f PI；
- 优点：解耦、增益少、理论强；
- 缺点：依赖位置环/张力模型；摩擦大时可能稳态误差；
- 用途：**论文/升级方案**。

#### C：文章 5 增益 `Pᵀ` 版

```
x_d = x − kv ẋ
      − RᵀKτ(Rf−τd)
      − Wᵀkint(Wf−td)
```

- 你的 2 轴：Kτ2 + kint1 + kv1 = 4 个增益；
- 优点：最简单；
- 缺点：不解耦；无积分；TDA 的 `fd/α` 没接进来；
- 用途：**简单对照/快速验证**。

### 6.3 实验怎么做

同一组输入，跑 A/B/C：

1. **τ_roll 阶跃，τ_pitch=0**  
   看 τ_pitch 是否被带起来（cross-coupling）。

## 7. 十个常见误区

### 误区 1：`Pᵀ` 和 `P⁻ᵀ` 差不多

不一样。  
`Pᵀ` 是转置/梯度；`P⁻ᵀ` 是逆的转置/坐标变换。  
只有 P 正交时相等，P 不是。

### 误区 2：文章式(4) 就是论文式(30)

不是。文章自己也说式(4)不是原始电压公式；而且它用的是 `Pᵀ`，不是 `P⁻ᵀ`。

### 误区 3：5 个增益是“万能数量”

5 是 R2 **3 自由度**、`Kτ` 3 个对角、`kint`1、`kv`1 的数法。  
你的 2 轴腕是 **4**；完整位置—力是 **6**；纯位置 **1**。

### 误区 4：5 个增益包含积分

不包含。  
文章 5 个是 P/PD；加积分会变多。论文说稳态误差可用限幅积分器解决。

### 误区 5：纯位置 1 个增益，所以最简单最好

1 个增益是真的，但它没有张力闭环；`R⁺R x` 还会把预紧投影掉。  
纯位置只能保位置，不能保预紧。

### 误区 6：代码叫“关节空间解耦”，所以它解耦

代码实际是 TDA + 内环 f PI，属于腱空间逐根闭环；没有 `P⁻ᵀ`，不会有论文意义的解耦。

### 误区 7：内环 f PI 能消掉耦合

不能。  
内环能抑制摩擦/扰动，但 `R Rᵀ` 是运动学耦合，论文明确说调参消不掉。

### 误区 8：TDA 的 `f_d` 一定进入控制律

文章式(4) 不用 `f_d`，只用 `τd/td`；代码用 `f_d`。  
两种结构不要混。

### 误区 9：外环 PID 必须加

不是。  
`kp_tau=ki_tau=0` 时，代码退化成“TDA + 内环 f PI”的纯前馈；你的理解就对上。

### 误区 10：论文最好，直接照搬

论文 `u` 是电压/电流；你的硬件是位置。  
直接照搬不现实；要按专利改成位置命令，且要处理 `fmin/fmax`。

## 8. 一页总结

### 论文

```
TDA → f_d/t_d/α
腱空间：u = −kp(f−fd) − kd ẋ        → 有 R Rᵀ 耦合
关节空间：u = −P⁻ᵀKp(τ−τd) − kd ẋ   → 解耦
```

**关键词：`P⁻ᵀ`、解耦、理论完整、原始是电机命令。**

### 文章

```
x_d = x − kv ẋ − RᵀKτ(Rf−τd) − Wᵀkint(Wf−td)
```

**关键词：`Pᵀ`、位置命令、5/8/1 增益、简单、没有解耦保证、纯位置丢预紧。**

### 你的代码

```
τ PI → TDA → f_d → 内环 f PI → 位置增量
```

**关键词：TDA、内环 f PI、位置伺服、约束/摩擦好、仍有耦合、调参多。**

### 最终建议

- **现在能跑**：用代码 A；
- **想解耦/写论文**：加论文 B（`P⁻ᵀ` 位置命令版）；
- **想最快验证**：加文章 C（`Pᵀ` 5 增益，你的 2 轴 4 个）；
- **不要**把文章式(4) 当论文复现；
- **不要**在没有 cross-coupling 数据前说代码“解耦”。

**一句话：**

> 论文是“用 `P⁻ᵀ` 把耦合消掉”，文章是“用 `Pᵀ` 把误差推回去”，你的代码是“用 TDA + 内环把每根绳拉住”。  
> 三种都能跑，但解决的问题不一样：**论文管解耦，文章管简单，你的代码管约束和摩擦。**
