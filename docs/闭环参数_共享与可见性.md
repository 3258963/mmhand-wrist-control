# 闭环参数：哪些是共用的、哪些只有单模式能调

> 依据：2026-11-26 在实机窗口上逐模式扫描 `isHidden()` / `isEnabled()` 得到的实测矩阵
> （不是读代码猜的）。相关代码：`mmhand_scope._apply_cl_mode_visibility`

## 2. 2026-11-26 修掉的两个坑

### ① 阻抗的死区：原来改不了

**原因**：`_impedance_params()` 读的是位置模式的 `deadband` 框，而它所在的
「角度参数」行在阻抗模式下**整行隐藏**。

**修法**：阻抗行新增 **「死区°」（`imp_deadband`）**：

| 填法 | 行为 |
|---|---|
| **留空** | 沿用位置模式的 `deadband`（**旧行为逐位不变**） |
| 填数值 | 只用这个值 |
| 填 0 | 无死区 |

### ② 位置模式的过载阈值：原来改不了

**原因**：位置模式每拍都跑 `_tension_guard()`（张力过载 → 停环），阈值是
`f_min` / `fmax_f`，但它们藏在只有力控可见的「边界」行里。

**修法**：把 `fmin` / `fmax` **拆成独立一行**，位置模式与四个力控**都可见**。
「边界」行现在只剩 `tmin/tmax/τr上限/τp上限/τ方向`（仍是力控家族专属）。

### ③ 顺带修的初始化问题

`_build_cl_box()` 结束时现在会按当前模式刷一次可见性。
否则「布局里没有 `cl_mode`」（首次启动 / 存档损坏）时，各行停在构造时的默认隐藏态
—— 表现就是"某个框该显示却不显示"（`fmin` 就因此没显示出来）。

## 3. 仍然存在、但已知的三处耦合

| 项 | 现状 | 影响 |
|---|---|---|
| **`roll_tgt` / `pitch_tgt`** | position 与 impedance **共用同一对框** | 改一个模式的目标角，另一个也跟着变 |
| **`ROLL环` / `PITCH环` 勾选** | 在阻抗模式下**可见但无效** | 只有 `_read_cl_params()`（位置模式）读它们 |
| **`max_step_f`** | position 与四个力控**共用同一个值** | 任一处改了，其余全部跟着变（不提示） |

## 4. 扫掠（2026-11-26 起：只有正弦）

| 项 | 现状 |
|---|---|
| 波形选项 | **三角波已删除** —— 扫掠只有正弦，不再有「波形」下拉 / 「三角速度」框 |
| 频率框 | **永远可编辑**（0.01~5 Hz） |
| 轴 | ROLL / PITCH / 双轴正弦；PITCH 幅值只在双轴时生效 |
| 可用模式 | **位置模式 + 阻抗模式**（阻抗的输入就是 q*，扫掠改的正是它） |
| 控制环频率 | `CL_LOOP_PERIOD_S = 0.010`（100 Hz）是**代码常量**，界面无入口 |

右侧那行「生效：…」会实时显示当前参数：

```text
生效：ROLL · 0.2 Hz · 幅值 10°
生效：双轴正弦 · 0.2 Hz · 幅值 10°/5°
```

> **历史**：2026-11-26 之前是「三角波 / 正弦波」二选一，默认三角波 →
> 频率框被灰掉、只保留上次的值 0.2，反复被误当成"频率锁死改不了"。
> 现在没有波形选择，这个坑从根上去掉了。
> **代价**：原来的"三角波慢速往返录标定"没有了；录标定请直接用正弦
> （幅值给大一点、频率给 0.05~0.1 Hz，慢到准即可）。

## 5. 一句话备忘

> **改阻抗死区 → 阻抗行「死区°」（留空则跟位置模式走）。**
> **改位置模式的过载阈值 → 直接改新出来的 `fmin/fmax` 行。**
> **扫掠没有波形可选（只剩正弦），频率永远能调。**
> **控制环 100 Hz 谁都改不了（代码常量）。**
