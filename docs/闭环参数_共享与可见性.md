## 2. 2026-11-26 修掉的两个坑

### ① 阻抗的死区：原来改不了

**原因**：`_impedance_params()` 读的是位置模式的 `deadband` 框，而它所在的
「角度参数」行在阻抗模式下**整行隐藏**。

**修法**：阻抗行新增 **「死区°」（`imp_deadband`）**：

| 填法 | 行为 |
|---|---|
| **留空** | 沿用位置模式的 `deadband`（**旧行为逐位不变**） |
| 填数值 | 只用这个值 |
| 填 0 | 无死区 |

### ② 位置模式的过载阈值：原来改不了

**原因**：位置模式每拍都跑 `_tension_guard()`（张力过载 → 停环），阈值是
`f_min` / `fmax_f`，但它们藏在只有力控可见的「边界」行里。

**修法**：把 `fmin` / `fmax` **拆成独立一行**，位置模式与四个力控**都可见**。
「边界」行现在只剩 `tmin/tmax/τr上限/τp上限/τ方向`（仍是力控家族专属）。

### ③ 顺带修的初始化问题

`_build_cl_box()` 结束时现在会按当前模式刷一次可见性。
否则「布局里没有 `cl_mode`」（首次启动 / 存档损坏）时，各行停在构造时的默认隐藏态
—— 表现就是"某个框该显示却不显示"（`fmin` 就因此没显示出来）。

## 3. 仍然存在、但已知的三处耦合

| 项 | 现状 | 影响 |
|---|---|---|
| **`roll_tgt` / `pitch_tgt`** | position 与 impedance **共用同一对框** | 改一个模式的目标角，另一个也跟着变 |
| **`ROLL环` / `PITCH环` 勾选** | 在阻抗模式下**可见但无效** | 只有 `_read_cl_params()`（位置模式）读它们 |
| **`max_step_f`** | position 与四个力控**共用同一个值** | 任一处改了，其余全部跟着变（不提示） |

## 4. 找不着的旋钮：位置环的「频率」

| 你以为的 | 实际 |
|---|---|
| **扫掠频率**（带宽测试） | 在「目标角 / 扫掠」行。**波形默认是「三角波」→ 频率框被禁用**（灰掉，只保留上次的值，看起来像"锁死在 0.2"），此时生效的是「速度 °/s」。<br>**把「波形」切到「正弦波」**（或轴选「双轴正弦」）频率框才可用 |
| **控制环频率** | `CL_LOOP_PERIOD_S = 0.010`（100 Hz）是**代码常量**，界面无入口，五个模式共用 |

扫掠控件生效关系：

| 轴 / 波形 | 生效的框 | 右侧提示 |
|---|---|---|
| ROLL 或 PITCH + **三角波** | 速度 `°/s`（频率灰掉） | `生效：速度 0.5 °/s ← 想按频率走，把「波形」切到「正弦波」` |
| ROLL 或 PITCH + **正弦波** | 频率 `Hz`（速度灰掉） | `生效：频率 0.20 Hz` |
| **双轴正弦** | 频率 `Hz`（波形下拉也灰掉） | `生效：频率 0.20 Hz（双轴固定正弦）` |

> **2026-11-26 新增**：频率/速度框右侧现在实时显示「生效：…」，并直接给出
> "想按频率走就把波形切正弦波"的提示。改值、切轴、切波形、切换控制模式都会刷新。
> 起因就是"频率只能固定 0.2 Hz"这个误解 —— 那个 0.2 只是禁用框保留的旧值。

---

## 5. 一句话备忘

> **改阻抗死区 → 阻抗行「死区°」（留空则跟位置模式走）。**
> **改位置模式的过载阈值 → 直接改新出来的 `fmin/fmax` 行。**
> **扫掠频率调不了 → 波形切「正弦波」。**
> **控制环 100 Hz 谁都改不了（代码常量）。**
