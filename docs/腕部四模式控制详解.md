## 1. 总架构：一条流水线 + 四个"控制律插件"

四种模式不是四套系统，而是**一个 100Hz 主循环、四个可替换的控制律函数、两个共享执行器**：

```
              ┌──────────── _cl_tick()  100Hz（10ms QTimer）──────────────────────────────┐
              │ ① dt 实测（perf_counter，钳 1~50ms）→ self._cl_dt —— 掉拍时积分不失真          │
              │ ② 存活检查：armed ∧ connected，否则停环                                       │
              │ ③ 反馈链：J16/J17 →解绕→中值5→EMA(0.10,τ≈76ms)→ ×AXIS_SIGN → 相对基准最短角差      │
              │    （wrist_filter.py；基准 📐 设置、随布局持久化）                              │
              │ ④ 参数节流：字符串→float 只 20Hz（_read_cl_params 快照缓存）                   │
              │ ⑤ 目标框每拍直读（roll_tgt/pitch_tgt——输入路径不节流）                          │
              │ ⑥ ⏺记录 → _record_calib_row（100Hz CSV 行：角度/电机/f/R/n̂/τ/trim/ω/flags）   │
              │ ⑦ 张力守卫 _tension_guard（四模式都过）：过载→停环；过期→标志；松绳→⚠          │
              └─⑧ 模式分发────────────────────────────────────────────────────────────────┘
                   │ position(两种)      │ tension            │ tight              │ force
                   ▼                     ▼                    ▼                    ▼
          wrist_control_step_pid   wrist_tension_step   wrist_tight_step    wrist_force_v2_step
           ├ 前馈+PID（绝对目标）   （张力误差→步长）     （预紧误差×n̂→步长）  （力矩PI→TDA→步长）
           └ 纯PID（实测+步长）                └───────────┬────────┴───────────────────┘
                   │                                     ▼
          执行器A _clamp_per_tick                执行器B _apply_force_step
          + _send_motor_batch                    out = 实测当前位置 + 步长
          （绝对目标，每拍限幅）                   （增量式，累计行程夹紧）
                   └───────────────┬──────────────────────┘
                                   ▼
                    _send_motor_batch → 一帧 0xD3（30路绝对位置）
                    → P4 MotionControl 100Hz → 舵机
```

**两个执行器的汇合点**是固件的硬约束：0xD3 批量帧天然原子；逐电机连发 0xDE 会被固件"代际合并"（同毫秒 3 帧只执行最后 1 帧——"只有一台动"事故的根因）。发送前查下行队列深度（>200 帧丢拍+提示），成功才更新 `targets`（变更抑制：稳态零流量）。

**统一速度缰绳**：`每拍限幅 max_step_f`（默认 5 counts/拍 = 100Hz 下 500 c/s）。位置模式在执行器 A 做，三力控模式在律内部的 `_incr_step` 基元做——四模式对舵机的速度上限天然一致。
注意它是"counts/拍"，折算成角度后两个轴不一样：ROLL ≈9.8°/s、PITCH ≈3.8°/s（§3 末有换算表）。

## 2. 共用底座（先讲清楚，后面四个模式才短）

### 2.1 反馈链（角度从哪来）

```
raw(0..16383) → unwrap_counts（解绕到上一滤波值所在圈，跨 0/16383 连续）
             → 中值5（砍 EMI 尖刺）→ EMA α=0.10（τ≈76ms，压宽带噪声；2026-11-05 由 0.05 上调）
             → × AXIS_SIGN{16:+1, 17:−1} → _angle_delta（最短角差 ±180°）
```
实现：`WristAxisFilter`/`unwrap_counts`（wrist_filter.py，纯函数+C 对照）。滤波值不可用时回退 raw 单帧。**设计依据**：上电保持噪声 std≈1~1.4°，α=0.03 时实测压到 ≈0.13°；现 α=0.10 模型估 0.12~0.17°，仍低于闭环死区 0.3°。

### 2.2 几何引擎（R 和 n̂ 从哪来）

`wrist_eval(roll_rad, pitch_rad)`（wrist_model.py:90）：六段解析几何（每段五个 CAD 投影常数），一次求值给全：
- `s_m[2][3]`：六段绳长（ROLL 段用 θr、PITCH 段用 θp）；
- `r_m[2][3]`：**力臂矩阵 R = −∂l/∂θ**（m/rad）——τ = R·f 的换算基础；
- 标志：`math_valid`（段长退化/非有限）、`angle_in_range`、`low_pitch_zone`。

`positive_null_direction`（wrist_model.py:111）：R 两行归一化叉积→归一化；**三分量全正（或全负翻正）返回 n̂，混号返回 None**。物理：R·n̂=0 ⇒ 沿 n̂ 加张力不产生力矩；n̂ 全正 ⇔ 存在三缆全正的零力矩预紧。实算可用窗（CAD/δ=0）：roll∈[−18.0,+14.75]×pitch∈[−20,+33.75]。

**θ_model 链**：所有几何求值都加标定零偏 δ（`_force_geo:4217` 统一入口，0.1° 网格缓存 1s）；当前 δ=0。

### 2.3 张力守卫（`_tension_guard :3794`）

每拍、四模式都过：阈值取 `_effective_flimits`（`:4243`，**单源**：边界行与观测台守卫框取严）；`tension_evaluate`（wrist_tension.py）给 STALE/SLACK/OVERLOAD 三态；OVERLOAD → 停环；阈值非法且 🛡开 → fail-closed 停环。

### 2.4 增量执行基元 `_incr_step`（wrist_force_law.py:76，三力控模式的灵魂）

```
du   = sat_{±max_step}( kp·e + sat_{±i_lim}( ki·∫e ) )
step = round(resid + du)；resid −= step        ← 小数残差进位
条件积分：未饱和（|raw|<max_step）或误差反向（raw·e<0）才累加 ∫e
```

三个设计点：
1. **P 直接作用在 e 上**（非 Δe）→ ki=0 时恒速 kp·e 逼近，不会"只动一次"；
2. **残差进位**：每拍步长必须整数 counts，不带 resid 会把 <1c/拍 的小误差永久丢掉（积分静差）；
3. **条件积分**：饱和时继续灌 ∫e = windup，解除饱和后猛冲——两条件覆盖"该冻"与"该放"（误差反向时积分帮忙刹车）。

### 2.5 执行器 B 语义（`_apply_force_step :4531`）

```
out = 电机实测位置 + trim_step         ← 基准是实测不是指令（防目标漂移）
out ∈ [base−max_trim, base+max_trim]  ← 相对"进入力控时刻"的累计行程夹紧（堵转不漂）
首拍强制下发 base+0                    ← 按住当前位，防目标跳变
未勾选缆：不下发、trim 显示清零        ← 状态行不骗人
```

## 3. 模式一：位置（角度闭环，两种结构）

**律**：`wrist_control_step_pid`（wrist_control_law.py，纯函数）。2026-11-10 起位置环
拆成两种结构，共用同一套 PID、同一个每拍限幅、同一个出口，只差**基准**：

| | 前馈+PID（绝对式） | 纯PID（增量式） |
|---|---|---|
| 目标 counts | `origin + k·[l(θ*) − l(ref)] + J·δθ` | `实测位置 + J·δθ` |
| 用到模型绳长 l 吗 | 用（前馈） | **不用**（只借雅可比 J） |
| 基准 | 启动瞬间的 origin + ref 位姿 | 每一拍的实测电机 counts |
| 稳态误差 | P 残留，靠 Ki 吃 | P 残留，靠 Ki 吃（增量式本身也带积分性） |
| 典型用途 | 精确到位、走轨迹 | 和力控三模式对照的基线；模型/标定可疑时用 |

### 数学

```
θ_model = θ_rel + δ                        ← δ 全链唯一校正点（δ 不引起零位漂移）
J_i(deg) = −k_i · R_i · (π/180)            ← counts/deg，自带硬件收放方向（不需要 trim_sign）

δθ = Kp·e + Ki·∫e dt + Kd·(−dθ_fb/dt)      ← 关节角域 PID，e = θ* − θ_fb（过死区）
       └ 微分作用在**反馈**上：拖目标框不砸尖峰

前馈+PID：out_i = origin_i + k_i·[l_i(θ*) − l_i(ref)] + J_i·δθ
纯PID  ：out_i = 实测_counts_i + J_i·δθ
两者都钳 origin ± 2,000,000，再由 _clamp_per_tick 做每拍限幅
```

**设计哲学**：复杂性全在模型里（六段几何/Δl/R），反馈侧只留 PID——"反馈的简单是用模型的精确换来的"。
k 的符号由定义决定（`Δcounts = k·Δl`）：**k>0 ⇒ 该路 counts 增大是放绳（绳变长），k<0 ⇒ counts 增大是收绳**。
符号是**逐路独立**的（电机可以反向安装/换线，例如当前 `k=[−130380,+130380,+130380]` = C1 反、C2/C3 正），
由台架**逐缆**点动判定（`+100c` 看该缆张力升/降），代码**不假设**任何一路的符号：
`J = −k·R` 逐路自带方向，两种结构的输出都随该路的 k 翻转，所以只要 k 与硬件一致就不会反。
位置环两种结构都不需要 `trim_sign`（那是给没有雅可比的三个力控模式用的）；
逐路不变量仍成立：`sign(trim_sign_i) = −sign(k_i)`，两者必须由同一次逐缆点动判定。

### 实现要点

- **都需要标定**：前馈+PID 用 `k·Δl`；纯PID 也要 `k` 与 `R` 当"角度→counts"的换算。
  没载入标定时门禁直接拒绝启动（否则输出恒等于基准，看着像"点了启动一动不动"）；
- **结构选择**：「位置环」下拉（前馈+PID / 纯PID），运行中切换会先停环；
  选择随布局持久化（旧布局的 `cl_model_on` 自动迁移：勾过=前馈+PID、没勾=纯PID）；
- **入口钳制**：目标域 = UI 限幅 ∩ 模型行程，pitch 抬底 −24°（低置信区）——置 FLAG 提示不拒绝；
  反馈角只钳入模型行程；
- **硬错误**（输入非有限/几何无效/纯PID 缺基准）→ `out=None` → **保持上一目标不发送**；
- **积分抗饱和**：`|Ki·∫e| ≤ 限幅°`，顶住时状态行显示"⚠积分饱和"；
- **分轴开关**：取消勾选 = 该轴的前馈与 PID 项整体剔除，随耦合自由漂移（两轴都取消时状态行明说"两轴均关"）；
- **扫掠**（本模式专属）：20Hz 三角波/正弦波改写目标框，配合 ⏺记录 = 录标定姿势 / 测带宽。

### 一拍数据流

`_cl_tick` → `wrist_control_step_pid(prm快照, calib, pid_state, roll, pitch, 目标, dt, feedforward=?, base_counts=?)`
→ outputs+flags → `m{m}_tgt` 曲线通道 → 勾选门禁（`_cl_motor_on` 启动快照）→ `_clamp_per_tick`（每拍限幅）
→ `_send_motor_batch` → ~17Hz 状态行（含标志名：目标钳制/低pitch区/反馈越界/几何无效/输入无效/积分饱和）。

### ⚠ 默认配置下 Kp 几乎不起作用（2026-11-10 实测复核）

`每拍限幅` 默认 5 counts/拍。位置环输出是"绝对目标"，所以指令每拍最多挪 5c ≈ 0.1°，
**P 项那点助推追不上限幅**：

| 场景（5° 阶跃，k=130380） | 首拍 | 最大过冲 | 进 ±0.3° |
|---|---|---|---|
| 理想对象（指令一拍到位） | +8.27° | +3.27° | 5 拍（50ms） |
| **交付默认 5c/拍** | +0.10° | **0** | **49 拍（0.49s）** |
| 默认 + Kp=0.3 | +0.10° | 0 | 49 拍 |
| 默认 + Kp=1.5 | +0.10° | 0 | 49 拍 |

⇒ 默认配置下位置环 ≈ "前馈 + 死区 + 速率限制"的一阶逼近，单调不过冲；
P 真正起作用的临界误差 `e_c = Δu_max/(Kp·counts_per_deg) ≈ 0.16°`，**比死区 0.3° 还小**。
想看到"过冲 ×Kp"的经典行为，要把每拍限幅提到 300c/拍以上（或缩小幅值）。

## 4. 模式二：张力（每缆独立闭环）

**律**：`wrist_tension_step`（wrist_force_law.py:295）。论文 §6 腱空间对角方案——最直观，台架起步用。

### 数学（每缆独立）

```
e_i = f_target_i − f_i（死区 0.05N 内归零）
step_i = _incr_step(e_i, ...)          ← §2.4 基元，max_step=每拍限幅
trim_i = trim_sign_i · step_i           ← 出口统一翻方向
```

**样本前置** `_sample_prelude`（:59，三力控共用）：非有限→STALE；**负张力钳 0 继续控**（松绳不是错误态）；龄>300ms→STALE 冻结；任一缆>f_max→OVERLOAD 停环。

**trim_sign 语义**：+1 = counts 增 ⇒ 该缆张力增（逐电机、台架点动判定写入）。**错填 = 正反馈飞车**——这是它没有默认值可瞒的原因，参数类直接拒绝非法格式。

## 5. 模式三：张紧（预紧度闭环，τ 守恒）

**律**：`wrist_tight_step`（wrist_force_law.py:398）。被控量 `t = f·n̂`。

### 数学

```
t_meas = Σ f_i·n̂_i
err = t_target − t_meas（死区内归零）
e_i = err · n̂_i                 ← 误差沿零空间方向分给三缆
step_i = _incr_step(e_i, ...)；trim_i = trim_sign_i·step_i
```

**τ 守恒是结构保证**：步长向量 ∝ n̂ ⇒ R·Δf ≈ 0（整数化偏差 ≤0.5c/缆）。状态行带"守恒监视"（实测 τ=R·f 同屏）。

### 特有防护

- **可行域门禁**（`_tight_params :4382`）：`t ∈ [fmin/min(n̂), fmax/max(n̂)]`——低于下界必有缆够不着 fmin（高位姿 C1 份额塌缩时会撞这条，如 pitch 30° 时 n̂=(4%,44%,90%)、fmin0.5 → t≥12.7N），高于上界必有缆超 fmax；
- **fmin 方向地板**：某缆 ≤fmin 且本步为放绳方向 → 本拍禁放+清该缆 integ/resid（防积分继续泄）；地板不负责抬缆；
- **n̂ 缺失（死区）**：返回 FORCE_NO_NULL → 停环（`_cl_tick_tight :4623`；泛化/准张紧方案已设计存档待批）；
- tmin/tmax 越界只⚠提示不停环（硬安全=逐缆 fmax 过载停环）。

## 6. 模式四：力矩（v2 关节空间解耦律）

**律**：`wrist_force_v2_step`（wrist_force_law.py:166）。论文 §8.3 形态：**外环力矩 PI + TDA 分配 + 内环张力增量**。

### 数学

```
① 观测 τ_meas = R(q)·f                    ← 传感器只给张力，力矩必须经 R 换算
② 外环 u = sat_{±τ_lim}( kp_τ·e + integ_τ )，e=τ_d−τ_meas（死区0.01）
        τ_lim = (f_max−f_min)·Σ|R_ij|     ← 可达力矩上界（防 windup 的钳）
        抗饱和：α<1（目标不可达）时 integ_τ 本拍冻结
③ 分配 f_d, flags, α = TDA(R, n̂, τ_d+u, preload, fmin, fmax)
④ 内环 trim_i = trim_sign_i · _incr_step(f_d,i − f_i, ...)   ← 同一基元，P=I=trim_gain
```

### TDA（wrist_tda.py:66）——灵魂

```
P = [R(2×3); n̂ᵀ]（3×3 可逆）；f_full = P⁻¹·[τ_r, τ_p, t]
若 f_full 超出 [fmin,fmax]³：
  f(α) = α·f_τ + f_t（f_τ=P⁻¹[τ,0]，f_t=P⁻¹[0,0,t]=t·n̂）
  逐缆解 α 可行区间（f_tau_i>0: [(fmin−f_t)/f_τi, (fmax−f_t)/f_τi]，<0 反向，≈0 查 f_t 自身）
  取交集 → 最大 α∈[0,1]；α<1 = 力矩"优雅降级"（FLAG_ALPHA_CLAMPED）
α=0 仍不可行 ⇔ 预紧自身超界（t·n̂ 出盒）或 n̂ 缺失 → INFEASIBLE → 停环
```

**注意 α=0 的含义**：连纯预紧都放不进盒——典型如高位姿 C1 份额塌到 4%、预紧 5N 时 C1 只有 0.2N < fmin(0.5)。停环消息"该位姿无全正预紧**或超界**"两种原因共用。

### 实操要点（实机踩过的坑）

- **Kp_τ 默认 100 过大**：实测全程饱和 α≈0.065。起步 **1~5**，盯 α 曲线（<0.999 状态行显 `α=x.xx↓`）；
- 外环位置式/内环增量式的理由：u 是给 TDA 的代数校正量，不经过"累加到实测位置"的出口——增量式的定义域在位置出口层；
- τr/τp 上限框钳制目标框本身；preload 沿 n̂ 自动分配。

## 7. 四模式对照表

| | 位置（两种） | 张力 | 张紧 | 力矩 |
|---|---|---|---|---|
| 被控量 | 关节角 ° | f₁/f₂/f₃ (N) | t=f·n̂ (N) | τ_roll/pitch (N·m) |
| 律函数 | `control_step_pid` | `tension_step` | `tight_step` | `force_v2_step` |
| 结构 | 前馈+PID（绝对）/ 纯PID（增量） | 对角增量 PI ×3 | 单 PI×n̂ 分配 | 力矩PI→TDA→增量PI×3 |
| 需要 n̂ | ✗ | ✗ | **✓** | **✓**(TDA) |

# 11. 附录：控制公式完整推导（2026-11-09 增补）

> §2–§6 给的是"公式是什么"，本附录给"公式从哪来"——每个实现公式从力学/几何第一性推出来，全部与代码逐字符对得上。

## 11.0 公共几何基座：三个一切公式之母

### 推导 1：绳段长度 `s = √(d₁² + d₂² + h²)`

每段绳（6 段 = 3 缆 × ROLL/PITCH）是"固定点 U → 随关节转动的滑轮上点 V(θ)"。V 的实际位置 = 安装基姿态 (v₁,v₂) 旋转 θ：

```
v′₁ = v₁cosθ − v₂sinθ
v′₂ = v₁sinθ + v₂cosθ          ← wrist_model._segment_length_and_arm
```

端点位移 `d = v′ − u = (d₁,d₂)`；离面常量 h（滑轮半径/偏距，不随 θ 变，绕弧长并入其中）。绳段长只依赖端点距离：

```
s(θ) = √(d₁(θ)² + d₂(θ)² + h²)
```

### 推导 2：有效力臂 `r = −∂s/∂θ = (d₁v′₂ − d₂v′₁)/s`

链式法则 `∂s/∂θ = (d₁ḋ₁ + d₂ḋ₂)/s`；u 固定故 ḋ = ∂v′/∂θ，对旋转公式求导：

```
∂v′₁/∂θ = −v₁sinθ − v₂cosθ = −v′₂
∂v′₂/∂θ =  v₁cosθ − v₂sinθ = +v′₁     ← 旋转 90°、模长不变
```

代回：`∂s/∂θ = (−d₁v′₂ + d₂v′₁)/s`，即

```
r ≡ −∂s/∂θ = (d₁v′₂ − d₂v′₁)/s        ← 与代码逐字符一致
```

分子 `d₁v′₂ − d₂v′₁` 恰为二维叉积 (d × v′)ᶻ——**力臂 = 位移向量与速度方向叉积 ÷ 段长**，几何含义=单位转角的绳长缩短率。

### 推导 3：力矩换算 `τ = R(q)·f`（虚功原理）

关节虚转角 δθ ⇒ 第 i 缆长变化 `δlᵢ = (∂lᵢ/∂θ)δθ = −rᵢδθ`。张力 fᵢ（只拉）对关节做的虚功：

```
δW = Σᵢ fᵢ·(−δlᵢ) = Σᵢ fᵢ·rᵢ·δθ
与 δW = τ·δθ 比较 ⇒  τ = Σᵢ rᵢfᵢ = R(q)·f，  R := −∂l/∂θ（2×3）
```

腕为串联两级：`lᵢ(θr,θp) = s_ROLL,i(θr) + s_PITCH,i(θp)`，ROLL 段不含 θp、反之亦然 ⇒ 偏导自动解耦，R 两行各由各自段贡献。

**这三条是四模式共享的地基**：位置模式用 l(θ)，张紧/力矩用 R 及其零空间。

### 推导 4：R 矩阵装配（6 个标量推导 → 一张 2×3 表）— 2026-11-10 增补

**目标**：证明 $\boldsymbol R\in\mathbb{R}^{2\times3}$ 的每个元素恰好就是推导 2 的那个标量公式，并展示装配过程。

#### 第一步：元素定义

$$
\big[\boldsymbol R\big]_{ji}=-\frac{\partial l_i}{\partial\theta_j},\qquad j\in\{r,p\},\ i\in\{1,2,3\}
$$

（$j=r$ 表示 ROLL 行，$j=p$ 表示 PITCH 行。）

由串联解耦：$l_i = s^{(r,i)}(\theta_r)+s^{(p,i)}(\theta_p)$，对 $\theta_r$ 求导时 PITCH 段为常数（导数=0）：

$$
\big[\boldsymbol R\big]_{r,i}=-\frac{\partial l_i}{\partial\theta_r}=r^{(r,i)}(\theta_r)
$$

同理 $\big[\boldsymbol R\big]_{p,i}=r^{(p,i)}(\theta_p)$——**每格 = 推导 2 的标量公式**，用该段的 5 个 CAD 常数、代入该轴的角度。

#### 第二步："求导 = 旋转 90°"引理（核心步骤）

对旋转公式 $v'_1=v_1\cos\theta-v_2\sin\theta$、$v'_2=v_1\sin\theta+v_2\cos\theta$ 求导：

$$
\frac{\partial v'_1}{\partial\theta}=-v_1\sin\theta-v_2\cos\theta=-v'_2
\qquad
\frac{\partial v'_2}{\partial\theta}=v_1\cos\theta-v_2\sin\theta=+v'_1
$$

**与 $v'$ 自身对比**：$\partial v'/\partial\theta = J v'$，其中 $J=\begin{bmatrix}0&-1\\1&0\end{bmatrix}$ 是 90° 旋转矩阵。矩阵视角：$v'=\mathrm{Rot}(\theta)v$，而 $\mathrm{Rot}'(\theta)=\mathrm{Rot}(\theta)\cdot J$，旋转矩阵可交换 ⇒ $\dot v'=Jv'$。**微分一次 = 逆时针转 90°，模长不变**。这个引理对六段全部成立（不管常数是什么），是共享的"一次性投资"。

#### 第三步：代回链式法则

由推导 2 的中间结果 $\mathrm{d}s/\mathrm{d}\theta=(d_1\dot d_1+d_2\dot d_2)/s$，代入 $\dot d_1=-v'_2$、$\dot d_2=+v'_1$：

$$
\frac{\mathrm{d}s}{\mathrm{d}\theta}=\frac{-d_1v'_2+d_2v'_1}{s}
\qquad\Longrightarrow\qquad
r\equiv-\frac{\mathrm{d}s}{\mathrm{d}\theta}=\frac{d_1v'_2-d_2v'_1}{s}
$$

与代码 `wrist_model.py:69` 逐字符一致。分子 $d_1v'_2-d_2v'_1=(\boldsymbol d\times\boldsymbol v')^z$。

#### 第四步：物理自检

$$
\frac{\mathrm{d}s}{\mathrm{d}\theta}=\frac{\boldsymbol d\cdot\dot{\boldsymbol d}}{s}=\hat{\boldsymbol u}\cdot\dot{\boldsymbol v}'\ ,\qquad \hat{\boldsymbol u}=\frac{\boldsymbol d}{s}\ (\text{绳方向单位向量})
$$

**= 滑轮点速度在绳方向上的投影**——滑轮点顺着绳方向远离时，绳就变长。直觉完全对上。

#### 第五步：数值验证（差分 vs 公式，C2 的 ROLL 段）

| $\theta$ | 公式 $r$ (mm/rad) | 差分 $-\mathrm{d}s/\mathrm{d}\theta$ | 偏差 |
| --- | --- | --- | --- |
| 0° | −22.04970 | −22.04970 | 5×10⁻⁹ |
| 2° | −23.09640 | −23.09640 | 1×10⁻⁸ |
| 5° | −24.34190 | −24.34190 | 2×10⁻⁹ |
| 20° | −26.99283 | −26.99283 | 1×10⁻⁸ |

全程吻合到浮点尾数级——公式精确等于导数的定义。

#### 第六步：解耦验证

ROLL 行不随 pitch 变（对 $\theta_r$ 求导时 PITCH 段"冻结"）：

| 条件 | ROLL 行 = $[R_{r1}, R_{r2}, R_{r3}]$ |
| --- | --- |
| pitch=0° | [−0.495, −23.096, +15.647] |
| pitch=30° | [−0.495, −23.096, +15.647] |

完全相同 ✓——每段只响应当前轴的角度，互不干扰。

#### 装配结果

$$
\boldsymbol R(\boldsymbol\theta)=\begin{bmatrix}
r^{\text{ROLL}}_1(\theta_r) & r^{\text{ROLL}}_2(\theta_r) & r^{\text{ROLL}}_3(\theta_r)\\
r^{\text{PITCH}}_1(\theta_p) & r^{\text{PITCH}}_2(\theta_p) & r^{\text{PITCH}}_3(\theta_p)
\end{bmatrix}
\qquad\text{（代码 wrist_eval 双重循环填这张表）}
$$

**矩阵没有引入任何新推导——只是记账格式**。多变量函数 $\boldsymbol l:\mathbb R^2\to\mathbb R^3$ 的导数按定义就是一张偏导数表（雅可比矩阵的转置），微积分的"多变量链式法则"=线性代数的"矩阵乘向量"。

## 11.1 位置模式：前馈与校正的来历

**前馈 = 逆模型直接读出**。目标位姿需要的绳长 `lᵢ* = lᵢ(θ*)`（推导 1 正模型求值）；标定给出 counts↔绳长线性关系 `countsᵢ = originᵢ + kᵢ(lᵢ − l_ref)`。两步合并、参考取模型零位 δ：

```
ffᵢ = kᵢ·[lᵢ(θ*) − lᵢ(δ)]
```

参考取 δ 的理由（零位自洽）：θ_rel=0 时 θ_model=δ、Δl=0，前馈输出零增量——**δ 不引起零位漂移**（"θ_model = θ_rel + δ 全链只校正一次"的由来）。

**校正 = R 把角度误差换算成绳长修正**。实测与目标差 e（rad），把 θ 拉回所需绳长修正一阶泰勒 `δlᵢ ≈ (∂lᵢ/∂θ)·(−e)`，换 counts 乘增益：

```
corrᵢ = −kp·kᵢ·(Rᵢ·e_rad)
```

**为什么只有 P**：稳态精度职责已由前馈接管（模型不准靠重标定，不靠积分）；P 只补模型误差与扰动。加 I 会在标定偏差下缓慢推走位置——位置保持场景纯害。kp<1 是刻意欠校正（几何误差留缓冲，实测 1.5 稳）。

## 11.2 张力模式：增量 PI 的三个推导

**P-on-e（非 P-on-Δe）**：要求误差指数收敛 ė=−λe；张力随位置近似线性 f≈K·c ⇒ 需 ċ=(λ/K)e，离散化即 `du = kp·e`——直接正比当前误差。标准增量式 kp·Δe 只在误差**变化**时动作，缓变/恒定误差会停滞；P-on-e 保证 ki=0 也能恒速逼近。

**残差进位**：执行器整数 counts，du 常为小数；直接 round 会把 du<0.5c/拍 的误差永久吞掉（du=0.3 恒定 → 每拍 round=0 → 永不动）。`resid += du; step=round(resid); resid -= step` 把整数化误差整形为零均值——**分辨率不再受单拍 round 限制**。

**条件积分两条件**：饱和时输出被钳、积分照加=windup。加积分 ⇔ ①|raw|<max_step（未饱和）**或** ②raw·e<0（积分方向在刹车）。条件②是精髓：饱和中误差若变号，旧积分恰好用于反向制动，此时应继续积累。

`max_step`（每拍限幅）一身三职：速度上限（5c/拍×100Hz=500c/s）、增量环稳定性保证、三力控统一缰绳。

## 11.3 张紧模式：零空间五步推导

**① 零空间方向 = 两行叉积**：R 满秩 2×3，零空间一维。d = a×b（a,b=R 行）满足 a·(a×b)=0、b·(a×b)=0 ⇒ R·d=0 ⇒ d 张成零空间。归一化得 ±n̂。

**② 全正充要条件（绳的物理）**：f ≥ fmin > 0。∃f>0 使 Rf=0 ⇔ n̂ 全正或全负（翻号取正）。一维零空间元素皆为 n̂ 倍数，倍数取正分量符号全随 n̂；**n̂ 混号 ⇒ 正负倍数都含负分量 ⇒ 无解**。这就是 n̂ 全正判定背后的定理。

**③ t = f·n̂ 分解与唯一性**：行空间⊥零空间（线性代数基本定理），任何 f 唯一分解 `f = f_τ + t·n̂`（f_τ∈行空间，t=f·n̂）。**t = f 中不产生力矩的那部分** = 张紧度；观测台 τ=R·f 与 t=f·n̂ 即此分解两侧。

**④ 控制律 `eᵢ = err·n̂ᵢ` 一步守恒证明**：err = t* − f·n̂，取增量 δf = ε·err·n̂：

```
δt = δf·n̂ = ε·err·(n̂·n̂) = ε·err    ✓ 收敛（‖n̂‖=1）
R·δf = ε·err·R·n̂ = 0                  ✓ 力矩纹丝不动（结构保证）
```

一行同时达成收敛与守恒——**n̂ 既是投影测量基又是零空间执行方向**。整数舍入偏差 ≤0.5c/缆，"守恒监视"（实测 τ）兜底。

**⑤ 可行域**：纯预紧 f = t·n̂ 逐缆约束 fmin ≤ t·n̂ᵢ ≤ fmax ⇒

```
t ∈ [fmin/min(n̂), fmax/max(n̂)]      （最弱缆先触底——pitch 30° 时 C1 份额 4% 即此）
```

fmin 地板的方向性（贴地禁放、不负责抬）：抬缆属"紧方向误差"的事，混入会破坏守恒分配。

## 11.4 力矩模式：TDA 四步推导

**① 欠定与第三条件**：求 f 使 R·f = τ_d（2 方程 3 未知）⇒ 一维自由度=零空间。取 t=f·n̂ 补第三方程：

```
P = [R; n̂ᵀ]，f_d = P⁻¹·[τr, τp, t]ᵀ
```

P 可逆性：若 Rf=0 且 n̂ᵀf=0 ⇒ f 与 n̂ 同在一维零空间且正交 ⇒ f∥n̂ ⇒ n̂ᵀf=‖f‖=0 ⇒ f=0 ⇒ 列满秩 ✓（R 秩亏位姿例外，代码有奇异检查）。

**② 解结构与 α 缩放**：线性拆分 `f(α) = α·f_τ + f_t`，其中 f_τ=P⁻¹[τ,0]，f_t=P⁻¹[0,0,t]=t·n̂（零空间性质）。超界时**缩 τ 不缩 t**：t 是存在性条件（α=0 也须可行），τ 是性能（打折可用）。每缆约束对 α 线性 ⇒ 三条一维区间取交集、[0,1] 内取最大 α——**三维约束退化为区间交集，闭式无迭代，100Hz 可跑的根源**。α<1=力矩优雅降级，α 曲线即"目标离可达域多远"。

**③ 外环限幅 `τ_lim = (fmax−fmin)·Σ|Rᵢⱼ|`**：任何盒内 f,f′ 逐缆差 ≤ span ⇒ |R(f−f′)|ⱼ ≤ Σ|Rⱼᵢ|·span——盒内张力可表达的力矩范围宽度不超过它；u 钳于此，超出部分的积分是纯 windup 燃料。α<1（不可达）冻结 integ_tau 同理。

**④ 内环复用张力基元**：TDA 出 f_d（张力目标），"f_meas→f_d" 正是张力模式的问题——同一 `_incr_step` 原封不动。**三力控共用一个执行内核是分层设计**：外环管"目标张力是什么"，内环管"每拍走几 counts"。

**图读法**：左边走"值"的路线（$l\to$前馈），右边走"导数"的路线（$R\to$校正+力控全家桶），两条线在增量 PI 汇合为力控三模式的统一执行内核。

$$

| 项 | 含义 | 代码 |
| --- | --- | --- |
| $\boldsymbol{o}$ | 锚（启动瞬间的实测位置，2026-11-10 起是"启动时快照"而非"使能时快照"） | `_motor_origin`（`_start_closed_loop` 刷新） |

| $\boldsymbol u_{n-1}\pm\Delta u_{max}$ | 每拍限幅=速度缰绳 | `mmhand_scope.py:_clamp_per_tick` |

### 闭环动态（理想情形：过冲振荡收敛）

$$
\boldsymbol{e}_{\theta,n+1}=-k_p\,\boldsymbol{e}_{\theta,n}\qquad(k_p=0.6\text{，每拍幅度}\times0.6\text{，}k_p<1\text{ 稳定})
$$

**为什么过冲**：校正让指令落在 $\theta^*+k_pe$（越过目标 $k_p e$），下一拍反向修正——交替衰减，进死区 $d=0.3^\circ$ 后精确停靠。

> ⚠ **这个推导假设"被控对象一拍就走到指令位置"**。交付配置里 `每拍限幅=5 counts/拍`
> （≈0.1°）根本走不到，所以实际是"速率限制型一阶逼近"：单调、无过冲、约 49 拍（0.49s）
> 进死区，而且 **Kp 在 0.3~1.5 之间几乎不影响结果**（见 §3 末尾的仿真表）。
> 只有把每拍限幅提到 300c/拍以上，上式与下表才会真的出现。
> 加了 I 以后，理想情形下的极点不再是单个 $-k_p$（多一个积分状态），这里不再展开。

**锚偏差**：ref 与实际 origin 姿态不一致 $\theta_e$ ⇒ 稳态误差 $\boldsymbol{e}_{ss}=-\boldsymbol\theta_e/(1+k_p)\approx-0.63\theta_e$（口诀：启动前📐归零）。
注意方向：P 项把偏差**压小**到 0.625 倍，不是放大（旧版注释里的 `s/(1−kp)` 是错的）。

## 12.1 张力模式推导（逐拍，代码 `wrist_force_law.py:295-327`）

### 数学

**被控量**：三缆张力 $\boldsymbol{f}\in\mathbb{R}^3$（传感器直测，250 Hz）。

**误差**（对角，每缆独立）：

$$
e_{f,i}=f_i^*-f_{meas,i}\qquad(\text{死区}0.05\ \mathrm{N}\ \text{内归零})
$$

**增量 PI 基元**（三力控共用，`wrist_force_law.py:76-94 _incr_step`）：

$$
\Delta u_{n,i}=\operatorname{sat}_{\Delta u_{max}}\big(k_p^{(f)}\,e_{f,i}+\operatorname{sat}_{I}\big(k_i^{(f)}\,I_{f,i}\big)\big),\qquad
\Delta\boldsymbol u_n=\mathrm{round}(\boldsymbol\rho+\Delta\boldsymbol u),\quad \boldsymbol\rho\mathrel{+}=\Delta\boldsymbol u-\mathrm{round}(\boldsymbol\rho+\Delta\boldsymbol u)
$$

**执行**（增量式出口）：

$$
u_{n,i}=\hat x_{n,i}+\operatorname{sgn}_i\cdot\Delta u_{n,i},\qquad |u_{n,i}-o'_i|\le \mathrm{trim}_{max}
$$

（$\hat{\boldsymbol x}$ = 实测当前位置；$o'$ = 进入力控时刻的基准；$\operatorname{sgn}$ = trim_sign 方向符号。）

### 代码对应

```python

```

## 12.2 张紧模式推导（代码 `wrist_force_law.py:398-429`）

### 数学

**被控量**：张紧度 $t=\boldsymbol f\cdot\hat{\boldsymbol n}$（张力在零空间方向的投影分量）。

**核心恒等式**（零空间性质，力矩守恒的根源）：

$$
\boldsymbol R\hat{\boldsymbol n}=\boldsymbol 0\qquad\Longleftrightarrow\qquad \hat{\boldsymbol n}=\pm\frac{\boldsymbol a\times\boldsymbol b}{\|\boldsymbol a\times\boldsymbol b\|}\quad(\boldsymbol a,\boldsymbol b=\boldsymbol R\text{ 的两行})
$$

**误差**（单标量）：

$$
\mathrm{err}=t^*-t_{meas}=t^*-\boldsymbol f\cdot\hat{\boldsymbol n}
$$

**分配律**（沿零空间分发，保证 $\boldsymbol\tau$ 守恒）：

$$
e_{f,i}=\mathrm{err}\cdot\hat n_i
\qquad\Longrightarrow\qquad
\delta\boldsymbol f=\varepsilon\cdot\mathrm{err}\cdot\hat{\boldsymbol n}
\;\Rightarrow\;
\begin{cases}
\delta t=\delta\boldsymbol f\cdot\hat{\boldsymbol n}=\varepsilon\cdot\mathrm{err} & \checkmark\ \text{converge}\
\boldsymbol R\,\delta\boldsymbol f=\varepsilon\cdot\mathrm{err}\cdot(\boldsymbol R\hat{\boldsymbol n})=\boldsymbol 0 & \checkmark\ \tau\text{ conserved}
\end{cases}
$$

**然后进同一个增量基元 `_incr_step` → 执行出口。**

### 代码对应

```python
# wrist_force_law.py:398  wrist_tight_step
if p.null_dir is None: return None, FORCE_NO_NULL          # n̂ 不存在（死区）
t_meas = sum(f_n[i] * n[i] for i in range(3))              # 被控量 t=f·n̂
err = p.t_target - t_meas
for i in range(3):
    e_i = err * n[i]                                        # ← 沿零空间分配！
    ... = _incr_step(e_i, ...)                              # 同一增量基元
```

| 步骤 | 计算 | 结果 |
| --- | --- | --- |
| 误差 | $\mathrm{err}=0.5$ N | |
| 分配 | $e_1=0.5\times0.26=0.13$；$e_2=0.295$；$e_3=0.38$ N | |
| P 步 | $\mathrm{du}_1=50\times0.13=6.5\to$ sat 5 c | 三缆各走 ≤5c |

## 12.3 力矩模式推导（代码 `wrist_force_law.py:166-236` + `wrist_tda.py`）

### 数学（三明治结构：外环→分配→内环）

**外环**（力矩域 PI）：

$$
\hat{\boldsymbol\tau}=\boldsymbol R\boldsymbol f,\qquad
\boldsymbol e_\tau=\boldsymbol\tau_d-\hat{\boldsymbol\tau},\qquad
\boldsymbol u_{\tau,outer}=\operatorname{sat}_{\tau_{lim}}\big(k_p^{(\tau)}\boldsymbol e_\tau+\boldsymbol I_\tau\big)
$$

**分配（TDA，解 P⁻¹）**：

$$
\boldsymbol P=\begin{bmatrix}\boldsymbol R\ (2\times3)\\ \hat{\boldsymbol n}^\top\end{bmatrix}\in\mathbb{R}^{3\times3},\qquad
\boldsymbol f_d=\boldsymbol P^{-1}\begin{bmatrix}\boldsymbol\tau_d+\boldsymbol u_{\tau,outer}\\ t\end{bmatrix}
$$

超界时**缩 τ 不缩 t**：$\boldsymbol f(\alpha)=\alpha\boldsymbol f_\tau+t\hat{\boldsymbol n}$，找最大 $\alpha\in[0,1]$ 使三缆在盒内。

**内环**（同张力模式基元）：

$$
e_{f,i}=f_{d,i}-f_{meas,i}\ \to\ \_incr\_step\ \to\ \Delta u_{n,i}\ \to\ u_{n,i}=\hat x_{n,i}+\operatorname{sgn}_i\cdot\Delta u_{n,i}
$$

### 代码对应

```python
# wrist_force_law.py:166  wrist_force_v2_step
tau_meas_r = sum(R[0][i]*f_n[i])                   # ① 外环：τ=R·f
u_r = sat(lim, kp*errs[0] + state.integ_tau[0])     #    PI → 校正量
f_d, flags, alpha = tda_solver(R, n, tau_d+u, ...)  # ② TDA 分配 → f_d
if alpha < 1: state.integ_tau FREEZE               #    抗饱和：冻结积分
for i in range(3):                                  # ③ 内环：同一基元
    f_err = f_d[i] - f_n[i]
    ... = _incr_step(f_err, ...)                    #    张力误差→步长
```

TDA 核心（`wrist_tda.py:66-141`）：

```python
P = [[R[0]...], [R[1]...], [n[0], n[1], n[2]]]      # 3×3 可逆
P_inv = _inv3(P)                                     # 闭式求逆
f_full = P_inv @ [tau_r, tau_p, t]                   # 完整解
# 超界 → 找最大 α 使 α·f_τ + t·n̂ 在盒内（区间交集，无迭代）
```

| --- | --- | --- |
| 观测 | $\hat\tau=R\cdot f\approx0.02$ N·m | |

## 12.5 为什么力控三模式用增量式 PI（而非位置式 PID）

**核心答案：执行器是"位置型舵机"，但被控量（张力/力矩）到执行量（counts）之间没有可前馈的解析映射。**

| 维度 | 位置式 PID（$u=K_pe+K_i\int e+K_d\dot e+C$） | **增量式 PI**（$\Delta u=K_pe+K_i\int e\cdot\mathrm{d}t$，$u\mathrel{+}=\Delta u$） |
| --- | --- | --- |
| 需要知道 $u$ 的绝对值吗 | **要**（需要基准 $C$=零位/起点对应的目标 counts） | **不要**（只关心"再走几步"） |
| 张力→counts 有基准吗 | **没有**：绳刚度未知且非线性，"f=5N 对应 counts=?"无解析式 | 不需要——每拍看实测，走一步 |
| 堵转/丢帧时 | 目标基于模型计算，可能漂走 | **$u=\hat x+\Delta u$ 基准=实测位置，天然不漂** |
| 积分饱和（windup） | 位置式积分累在输出上，饱和时需外部抗饱和逻辑 | **条件积分内建**（`\|raw\|<Δu_max` 或误差反向才积，§11.2） |
| 换目标时 | 需重算基准 $C$ | **无跳变**（只改步长方向） |
| 执行器语义 | "去绝对位置"（适合有模型的位置环） | **"再走 $\Delta u$ 步"（适合无模型的力环）** |

**一句话**：位置环有解析模型（$\boldsymbol K\Delta\boldsymbol l$），所以用**绝对式**精确到位；力控三模式没有"力→counts"的模型，只能**增量式**每拍试一步、看一步、再走一步——增量式不是选型偏好，是**无模型约束下的必然选择**。

### 为什么 P 直接作用在误差上（P-on-e，非标准式的 P-on-Δe）

标准增量式 PI 的 P 项是 $\Delta e$（误差变化），缓变/恒定误差时 $\Delta e\approx0$ → 输出停滞。本系统 P 直接乘 $e$：

$$
\Delta u=K_p\,e\ (\text{非}\ K_p\,\Delta e)\ \Longrightarrow\ \text{只要误差在，每拍都朝它走}\ K_p e\ \text{counts}
$$

$K_i=0$ 时系统**仍以恒速 $K_p e$ c/拍 逼近目标**（不会"只动一次"），加上残差进位（$\rho$）保证 <1c/拍 的小误差不丢——等效积分效果内建。

### 为什么没有 D 项

反馈已经过 76ms EMA 滤波（压噪声），再微分=放大噪声。位置环 P-only、力控 PI-only，是**刻意的最简设计**。

# 13. 总结：一页收束全部

## 13.1 核心设计哲学（一段话）

一套由 **30 个 CAD 常数 + 勾股定理**构成的解析几何模型（`wrist_model.py`），同时供给四种控制模式所需的"地图"（$l(\theta)$，做前馈）和"斜率"（$\boldsymbol R(\theta)$，做校正/力矩换算/零空间方向）。位置模式走**绝对式**（有模型可前馈，精确到位）；力控三模式走**增量式**（无"力→counts"模型，每拍从实测出发走一步）——不是因为偏好，是因为**有没有可前馈的解析映射**这一根本差异。

## 13.2 四模式一行公式 + 一句话

| 模式 | 公式 | 特征 |
| --- | --- | --- |
| **位置** | $\boldsymbol u_n=\operatorname{clip}(\boldsymbol o+\chi\boldsymbol K\Delta\boldsymbol l-k_p\boldsymbol K\boldsymbol R^{\top}\boldsymbol e_\theta\ ,\ \boldsymbol u_{n-1}\pm\Delta u_{max})$ | 绝对式，前馈+P 校正 |
| **张力** | $\boldsymbol u_n=\hat{\boldsymbol x}_n+\operatorname{sgn}\odot\Delta\boldsymbol u_n$，$\Delta u_{n,i}=\operatorname{sat}(k_p^{(f)}e_{f,i}+k_i^{(f)}I_{f,i})$ | 增量式，三缆各管各 |
| **张紧** | 同上，但 $e_{f,i}=\mathrm{err}\cdot\hat n_i$（沿零空间分配，τ 守恒） | 增量式，零空间分配 |
| **力矩** | 同上，但 $e_{f,i}$ 的目标由 $\boldsymbol f_d=\boldsymbol P^{-1}[\boldsymbol\tau_d+\boldsymbol u_{\tau,outer};\,t]$ 给出 | 三明治：τPI→TDA→增量PI |

> 位置模式的公式中：**前馈** $\chi\boldsymbol K\Delta\boldsymbol l$ = 查地图（模型精确代入），**P 校正** $-k_p\boldsymbol K\boldsymbol R^{\top}\boldsymbol e_\theta$ = 补差距（斜率×误差）。

## 13.3 三个关键架构选择（为什么这么设计）

| 选择 | 原因 | 如果选另一种会怎样 |
| --- | --- | --- |
| **解析模型**（非 LUT/手填） | 精确（非插值/近似）；**可导 → 白送 R → 力控全家桶** | LUT 给不出 R → 力控做不了；手填系数 5° 差 5% |
| **绝对式位置环** + **增量式力控** | 位置有模型可前馈；力没有"力→counts"映射 | 位置用增量式=慢且不准；力控用位置式=需要未知基准 |
| **P-only 位置 / PI-only 力控**（无 D） | 模型承担稳态精度；EMA 已滤噪 | 加 I 会漂；加 D 放大噪声 |

## 13.5 R 矩阵的双重角色（本系统的灵魂）

$$
\mathrm{d}\boldsymbol l=-\boldsymbol R^{\top}\mathrm{d}\boldsymbol\theta
\qquad\Longleftrightarrow\qquad
\boldsymbol\tau=\boldsymbol R\boldsymbol f
$$

左边 = 角度→绳长（位置环校正项用），右边 = 张力→力矩（力控观测/TDA/张紧用）。

虚功定理保证同一个 $\boldsymbol R$ 沿两个方向都成立——**位置环里 R 是辅助工具，力控三模式里 R 升级为主角**。这就是为什么四种模式共享同一个几何模块、同一套 CAD 常数。

> "这个系统用**一套解析几何模型**（30 个 CAD 常数 + 勾股定理）支撑了**四种控制模式**：位置模式用模型做前馈精确到位，三种力控模式用模型的力臂矩阵 R 做力矩换算和张力分配。位置模式走绝对式（有模型可前馈），力控走增量式（无模型只能逐步逼近）——不是因为偏好，是因为**有没有可前馈的映射**这一根本差异。四种模式共享同一个几何模型、同一根速度缰绳、同一套安全网。控制律全部是纯函数模块（无 UI/串口依赖），可以直接翻译成 C 移植到下位机。"
