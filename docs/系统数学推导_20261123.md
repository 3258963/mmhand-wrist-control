# 腕部闭环：完整数学推导（2026-11-23 现状）

> 本文把"一拍里发生的所有事"从第一性原理推一遍，公式与代码一一对应。
> 记号：`τ` 关节力矩 [N·m]，`f` 三缆张力 [N]，`θ` 关节角 [rad]，`n̂` 零空间方向。

---

# 1. 静力学：从绳长到 `τ = R·f`

三根绳的长度是关节角的函数 `l_i(θ)`（`i=1,2,3`，`θ=(θ_r,θ_p)`）。
绳只能拉不能推，所以张力 `f_i ≥ 0`。

**虚功原理**：绳缩短 `δl_i < 0` 时做正功 `−f_i δl_i`，等于关节力矩的功 `τ·δθ`：

$$
\tau\cdot\delta\theta = -\sum_i f_i\,\delta l_i
= -\Big(\sum_i f_i \frac{\partial l_i}{\partial \theta}\Big)\delta\theta
$$

对任意 `δθ` 成立，故

$$
\boxed{\ \tau = R\,f,\qquad R := -\frac{\partial l}{\partial\theta}\in\mathbb{R}^{2\times3}\ }
\tag{1}
$$

`R` 的单位是 **m**（力臂）。本机在 `θ=0`：

$$
R=\begin{bmatrix}
-0.000259 & -0.022050 & +0.017372\\
-0.058105 & +0.011805 & +0.010990
\end{bmatrix}
$$

---

# 2. 冗余：零空间是 1 维

`R` 是 2×3，`rank R = 2` ⟹

$$
\dim \mathcal N(R) = 3 - 2 = 1
\tag{2}
$$

取基向量 `z ≠ 0` 使 `R z = 0`，归一化并选符号使全正：

$$
\hat n = \frac{z}{\|z\|},\qquad R\hat n = 0,\quad \hat n_i > 0,\quad \|\hat n\|=1
\tag{3}
$$

`n̂_i > 0` 就是**力封闭**条件：存在一组"只加张力、不改力矩"的方向。
本机 `θ=0`：`n̂ = [0.2644, 0.5949, 0.7590]`。

**物理含义**：沿 `n̂` 加 `t`（预紧），三缆同时变紧，力矩不变。

---

# 3. 增广矩阵 `P` 与两个恒等式

$$
P=\begin{bmatrix}R\\ \hat n^{\mathsf T}\end{bmatrix}\in\mathbb{R}^{3\times3},
\qquad f = P^{-1}\begin{bmatrix}\tau\\ t\end{bmatrix}
\tag{4}
$$

其中 `t := n̂ᵀ f` 是"预紧量"。

### 恒等式 A：`P⁻¹` 的第三列就是 `n̂`

$$
P\hat n=\begin{bmatrix}R\hat n\\ \hat n^{\mathsf T}\hat n\end{bmatrix}
=\begin{bmatrix}0\\1\end{bmatrix}=e_3
\ \Longrightarrow\
\boxed{\ \hat n = P^{-1}e_3\ }
\tag{5}
$$

### 恒等式 B：零预紧解与 `n̂` 正交

令 `v := P⁻¹[τ; 0]`，则 `P v = [τ;0]`，取其第三行：

$$
\boxed{\ \hat n^{\mathsf T}v = 0\ }
\tag{6}
$$

---

# 4. 通解与"零预紧解"

`R f = τ` 的通解 = 特解 + 零空间：

$$
f = v + t\,\hat n,\qquad v=P^{-1}\begin{bmatrix}\tau\\0\end{bmatrix}
\tag{7}
$$

`v` 是**最小范数解**（因为它与零空间正交，由 (6)），即"只产生力矩、不含预紧"的那组张力。

**注意 `v` 的分量可以为负** —— 绳不能推，所以实际必须靠 `t n̂` 把负数抬起来。

---

# 5. 分配的数学形式：`t` 的可行区间

给定目标方向上的力矩幅值 `m`（后面 `m = α·k`），令 `d` 为单位方向，
`u := P⁻¹[d; 0]`，则

$$
f(m,t) = m\,u + t\,\hat n
\tag{8}
$$

界约束 `f_min ≤ f_i ≤ f_max` 逐缆展开（`n̂_i>0` 可除）：

$$
L_i(m) := \frac{f_{\min}-m u_i}{\hat n_i}\ \le\ t\ \le\ \frac{f_{\max}-m u_i}{\hat n_i} =: U_i(m)
\tag{9}
$$

再加上预紧下限 `t ≥ t_floor`，**存在这样的 `t`** 当且仅当

$$
\max\Big(t_{\text{floor}},\ \max_i L_i(m)\Big)\ \le\ \min_j U_j(m)
\tag{10}
$$

---

# 6. 能力闭式解（`m_max` 的推导）

(10) 拆成两组不等式。

## 6.1 下界 vs 上界：`L_i ≤ U_j`

$$
\frac{f_{\min}-m u_i}{\hat n_i}\le\frac{f_{\max}-m u_j}{\hat n_j}
\quad\Longleftrightarrow\quad
m\,(\hat n_j u_i-\hat n_i u_j)\ \le\ \hat n_j f_{\min}-\hat n_i f_{\max}
\tag{11}
$$

两边同除 `n̂_i n̂_j > 0`，并定义

$$
a_i:=\frac{f_{\min}}{\hat n_i},\quad
b_i:=\frac{u_i}{\hat n_i},\quad
c_i:=\frac{f_{\max}}{\hat n_i}
\tag{12}
$$

得

$$
m\,(b_i-b_j)\ \le\ a_i-c_j
\tag{13}
$$

- `b_j > b_i`：除以负数翻号 ⟹ `m ≤ (c_j − a_i)/(b_j − b_i)` ← **上界**
- `b_j < b_i`：`m ≥ (a_i − c_j)/(b_i − b_j)` ← 下界（对 `m ≥ 0` 通常自动满足）
- `b_j = b_i`：需 `a_i ≤ c_j`（恒成立，因 `f_min<f_max`）

## 6.2 预紧下限：`t_floor ≤ U_j(m)`

$$
t_{\text{floor}}\le\frac{f_{\max}-m u_j}{\hat n_j}
\ \Longleftrightarrow\
m\,b_j\ \le\ c_j-t_{\text{floor}}
\tag{14}
$$

`b_j > 0` 时 `m ≤ (c_j − t_floor)/b_j`；`b_j ≤ 0` 自动满足。

## 6.3 合成

$$
\boxed{\
m_{\max}=\min\Big\{\
\underbrace{\min_{i,j:\ b_j>b_i}\frac{c_j-a_i}{b_j-b_i}}_{\text{上下限撞车}},\
\underbrace{\min_{j:\ b_j>0}\frac{c_j-t_{\text{floor}}}{b_j}}_{\text{预紧下限}},\
\underbrace{m_0}_{\text{零力矩可行性}}\Big\}\ }
\tag{15}
$$

`m_0 = 0` 当 `max(t_floor, max_i a_i) > min_i c_i`（连 `m=0` 都放不进盒子）。

**复杂度**：`m` 根缆 → `m²` 个配对 + `m` 个下限项；本机 3 缆 = **9+3 次比较，O(1)**，无迭代。

---

# 7. `α` 与 `t`：两阶段 LP 的等价形式

论文的问题是（字典序）：

$$
\text{①}\ \max\ \alpha\ \ \text{s.t. } R f=\alpha\tau^*,\ 0\le\alpha\le1,\ f_{\min}\le f\le f_{\max}
\tag{16}
$$
$$
\text{② 若 }\alpha=1:\ \min\ t=\hat n^{\mathsf T}f
\tag{17}
$$

**等价闭式**：

$$
\boxed{\ \alpha=\min\Big(\alpha_{\text{cap}},\ \frac{m_{\max}}{k}\Big),\qquad
t=\max\Big(t_{\text{floor}},\ \max_i L_i(\alpha k)\Big)\ }
\tag{18}
$$

其中 `k = ‖τ*‖`。

### 为什么第 ② 步的最优在左端点

由 (6) `u ⊥ n̂`：

$$
\|f(m,t)\|^2 = m^2\|u\|^2 + t^2
\tag{19}
$$

`t` 的可行区间是 `[max(t_floor, max L), min U]`，`‖f‖²` 对 `t` 单调增 ⟹ **最省力的解必在左端点** `t = max(t_floor, max L)`。
这就是"不用 QP 也能得到 `min‖f‖` 最优解"的原因。

### 论文算法 2 与 (15)(18) 的关系

论文用迭代解 2×2（每轮把"最紧的顶到 `f_max`、最松的踩到 `f_min`"），
(15) 把同一组方程**解析解出**（消去 `t`，只留 `m`）。两者逐位等价（实测 9 工况差 <1e-6）。

# 8. 内环：离散系统与稳定条件

## 8.1 被控对象

电机位置增量 `Δn`（counts）与张力增量近似线性：

$$
f_{k+1} = f_k + S\,\Delta n_k,\qquad S=\frac{K_{\text{rope}}}{|k|}\ \big[\text{N/count}\big]
\tag{20}
$$

本机 `S ≈ 0.046 N/count`（`K_rope=5.5 N/mm`，`|k|≈1.2e5 counts/m`）。

## 8.2 增量式 PI

$$
\begin{aligned}
I_{k+1} &= \operatorname{clamp}\Big(I_k + e_k\,\Delta t,\ \pm\frac{c}{k_i}\Big)\\
u_k &= \operatorname{clamp}\big(k_p e_k + k_i I_{k+1},\ \pm \Delta n_{\max}\big)\\
\Delta n_k &= \operatorname{round}(r_k + u_k),\qquad r_{k+1}=r_k+u_k-\Delta n_k
\end{aligned}
\tag{21}
$$

- `e_k = f_d − f_k`
- 状态上限 `c/k_i` 与贡献上限 `c` 是**同一件事的两种写法**（`k_i I ≤ c ⟺ I ≤ c/k_i`）
- `r` 是**小数残差**：把不足 1 count 的部分留到下一拍，避免小误差被 `round` 吃掉

## 8.3 只有 P 时的极点

$$
e_{k+1}=e_k - S k_p e_k = (1-S k_p)\,e_k
\quad\Longrightarrow\quad
\boxed{\ \text{极点 } p = 1 - S k_p,\quad 0 < S k_p < 2\ }
\tag{22}
$$

- `S k_p = 1` → 一拍到位（无超调）
- `0 < S k_p < 1` → 单调收敛，越大越快
- `1 < S k_p < 2` → 振荡收敛
- `S k_p ≥ 2` → **发散**

本机 `S ≈ 0.046`，`k_p = 15` ⟹ `S k_p = 0.70`（在 (0,1) 内，安全）。

## 8.4 速度饱和约束

舵机可持续速度 `v_max ≈ 3400 counts/s`，控制周期 `ΔT = 10 ms`：

$$
|\Delta n_k| \le v_{\max}\Delta T = 34\ \text{counts/拍}
\tag{23}
$$

若 `k_p` 使 `|\Delta n| > 34`，内环进入**饱和（bang-bang）**：

$$
|\Delta n_k| = 34 \quad\text{当}\quad |e_k| > \frac{34}{k_p}
\tag{24}
$$

本机 `k_p=15` ⟹ **2.3 N 误差就打满舵机**；`k_p=8` ⟹ 4.3 N。

**这就是"张力容易冲到上限"的动力学原因**：误差稍大即饱和，饱和就过冲。

# 9. 坐标共轭：为什么 `τ_model = s·τ_ui`

角度链路定了 `q_model = s_r q_ui`（本机 `s_r = −1`）。
**功必须是不变量**：

$$
\tau_{ui}\,\delta q_{ui} = \tau_{model}\,\delta q_{model}
\ \Longrightarrow\
\tau_{ui} = \tau_{model}\frac{\delta q_{model}}{\delta q_{ui}} = s_r\,\tau_{model}
\tag{25}
$$

即

$$
\boxed{\ \tau_{model}=s_r\,\tau_{ui},\qquad \tau_{ui}=s_r\,\tau_{model}\ (s_r=\pm1)\ }
\tag{26}
$$

**所以**：`R` 在模型系里 ⟹ 进分配前把 `τ_ui` 乘 `s_r`；显示 `τ = R f` 时再乘一次 `s_r` 换回 UI 系。
界面「τ方向」开关就是把 `s_r` 再乘 `±1`（实机方向与模型不符时用）。

# 10. 静差：没有前馈时一定偏

平衡方程（`τ*` 由肌腱提供，重力 `τ_g` 加在同一关节上）：

$$
K\,(q^*-q) + \tau_{ff} - \tau_g(q) = 0
\tag{27}
$$

$$
\boxed{\ q^*-q = \frac{\tau_g(q)-\tau_{ff}}{K}\ }
\tag{28}
$$

本机 `τ_ff=0`、`τ_g = A\sin(q)`（`A=0.3`）⟹ 目标 0° 时 `e_ss = 0.3\sin(q)/K`。
`K=0.01` → `e_ss ≈ 17°`（几乎撑不住）；`K=0.8` → 约 `5°`。

# 11. 预紧的下限：`t ≥ f_min / min(n̂)`

由 (12)，`max_i a_i = max_i f_min/n̂_i = f_min/\min_i n̂_i`。
连 `m=0` 都要满足 `t ≥ max_i a_i`，所以

$$
\boxed{\ t \ \ge\ \frac{f_{\min}}{\min_i \hat n_i}\ }
\tag{29}
$$

`min n̂ → 0`（靠近力封闭边界）时 `t` 爆炸：

| `θ_r`（模型）| `min n̂` | `t` 下限（`f_min=0.2`）|
|---|---|---|
| −12° | 0.275 | 0.73 N |
| −16° | 0.143 | 1.40 N |
| −17° | 0.080 | 2.50 N |
| **−18°** | **0.016** | **12.6 N** |

⟹ **边界位姿下 `t` 十几牛、三缆基线十几牛、离 `f_max` 只剩几牛**，一过冲就停环。

# 12. 单位力矩的张力代价：为什么 pitch 慢

由 (8)，`Δf = Δτ\,u`，所以**每 1 N·m 需要的张力变化是 `‖u‖`**：

| 方向 | `u = P⁻¹[d;0]` | `‖u‖` |
|---|---|---|
| `roll±` | [∓1.43, ∓27.79, ±22.28] | **35.6** |
| `pitch±` | [∓16.00, ±2.83, ±3.36] | **16.6** |

同时，实际起作用的是**差分**（`Δτ_{roll} ≈ 0.022ΔC2 − 0.017ΔC3` 等）：

$$
\Delta(\text{C2}-\text{C3})\approx\frac{\Delta\tau_r}{0.0220+0.0174}
=25.6\,\Delta\tau_r
\tag{30}
$$
$$
\Delta\text{C1}\approx\frac{\Delta\tau_p}{0.0581}=17.2\,\Delta\tau_p
\tag{31}
$$

**结论**：单位力矩下 **roll 更贵（25.6 > 17.2 N/(N·m)）**。
你观察到 `τ_roll` 先到位，是因为命令本身小 6 倍：

$$
\begin{aligned}
\tau_r=0.1 &\Rightarrow \Delta(\text{C2}-\text{C3})=2.56\ \text{N}\\
\tau_p=0.6 &\Rightarrow \Delta\text{C1}=10.3\ \text{N}
\end{aligned}
\tag{32}
$$

同样的缆速下，pitch 要走 **4 倍**行程 ⟹ 慢 4 倍。

# 13. 一个 tick 的完整算式链

$$
\boxed{
\begin{aligned}
&\text{① } q_{model}=s\,q_{ui}+\delta,\qquad \text{② } R=R(q_{model}),\ \hat n=\hat n(q_{model})\\
&\text{③ } \tau_{ui}\ \text{（模式决定）},\qquad \tau_{model}=s_{\tau}\tau_{ui}\\
&\text{④ } k=\|\tau_{model}\|,\ d=\tau_{model}/k,\ u=P^{-1}[d;0]\\
&\text{⑤ } u\perp\hat n,\ (a_i,b_i,c_i)=(f_{\min},u_i,f_{\max})/\hat n_i\\
&\text{⑥ } m_{\max}=\min\Big\{\min_{b_j>b_i}\tfrac{c_j-a_i}{b_j-b_i},\ \min_{b_j>0}\tfrac{c_j-t_{\text{floor}}}{b_j}\Big\}\\
&\text{⑦ } \alpha=\min(\alpha_{\text{cap}},\ m_{\max}/k),\quad m=\alpha k\\
&\text{⑧ } f_\tau=m u,\quad t=\max\big(t_{\text{floor}},\ \max_i \tfrac{f_{\min}-f_{\tau,i}}{\hat n_i}\big),\quad f_d=f_\tau+t\hat n\\
&\text{⑨ } e_i=f_{d,i}-f_i,\quad \Delta n_i=\operatorname{clamp}(k_p e_i+k_i I_i,\pm\Delta n_{\max})\\
&\text{⑩ } n_i^{\text{tgt}}=n_i^{\text{meas}}+\Delta n_i\ \longrightarrow\ \text{0xD3}
\end{aligned}}
$$

**恒等式自检**：`R f_d = α τ_model`（(7)(8) 的直接推论）。
