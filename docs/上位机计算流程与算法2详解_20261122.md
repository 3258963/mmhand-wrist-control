# 论文算法 2 详解 + 上位机完整计算流程（2026-11-22）

> **范围**：只讲**上位机**（PC 侧 100 Hz 环），到"发 0xD3 串口帧"为止，不进固件/舵机。
> **对象**：力矩模式（张力/张紧/阻抗只在第 ③ 步分岔）。
> **依据**：Abdallah, Platt Jr., Wampler, IJRR 32(2):247–258, 2013，§5 与算法 2。

# 第一部分：论文算法 2 再详解

## 1.1 它要解决的矛盾

| 输入 | 个数 | 说明 |
|---|---|---|
| τ*（关节力矩）| **2** | 你想要的 |
| f（每缆张力）| **3** | 未知 |
| 界约束 | 6 | `f_min ≤ f_i ≤ f_max` |

**3 未知 − 2 方程 = 1 个自由度** ⟹ "无数种分法"。

论文把它写成**两阶段**：

```
阶段①  最大化 α      （先保证"力矩尽量不少给"）
        R·f = α·τ*,  0 ≤ α ≤ 1,  f_min ≤ f ≤ f_max
阶段②  若 α = 1，再最小化 t = W·f   （力矩全额实现时，才省预紧）
```

## 1.2 关键代换：把 f 写成 (α, t) 的函数

$$
f(\alpha, t) = \alpha\cdot v + t\cdot w,\qquad
v = R^+\tau^*,\quad w = W^{\mathsf T}
$$

- `v`：**零预紧解**（只产生力矩，不产生内部张力）；满足 `R v = τ*`、`w·v = 0`
- `w`：**零空间方向**（单位化，全正）；满足 `R w = 0`
- **`t` = 内部张力**（预紧）；**`α` = 力矩实现比例**

于是两个决策变量 (α, t) ⟹ 三根缆的张力全部由它们决定。

## 1.3 算法 2（原文伪代码，7 行）

```
1  α = 1;  t = max_i (f_min − v_i)/w_i
2  f = α·v + t·w
3  while f > f_max 或 f < f_min:
4     h = argmax_i f_i;  ℓ = argmin_i f_i
5     解 v_h·α + w_h·t = f_max
        v_ℓ·α + w_ℓ·t = f_min
6     f = α·v + t·w
7  end
```

## 1.4 为什么"第 1 步只用一个自由度"

`α = 1` 固定后，只剩 `t` 一个变量：

$$
f_i = v_i + t\cdot w_i \;\ge\; f_{\min}
\;\Longrightarrow\;
t \ge \frac{f_{\min}-v_i}{w_i}\ \ \forall i
\;\Longrightarrow\;
t = \max_i\frac{f_{\min}-v_i}{w_i}
$$

**这个 t 保证"下界全部满足"，但不管上界。**
上界被破（某根 `f_i > f_max`）时，必须**放开 α** ⟹ 两个未知数 (α, t) ⟹ 两个方程 ⟹ 2×2。

## 1.5 第 5 行的 2×2 在说什么（几何）

```
让"最紧的那根 h"正好顶到 f_max
让"最松的那根 ℓ"正好踩到 f_min
```

$$
\begin{bmatrix} v_h & w_h \\ v_\ell & w_\ell \end{bmatrix}
\begin{bmatrix} \alpha \\ t \end{bmatrix}
=
\begin{bmatrix} f_{\max} \\ f_{\min} \end{bmatrix}
$$

解析解（实测会用到的形式）：

$$
D = v_h w_\ell - v_\ell w_h,\qquad
\alpha = \frac{f_{\max}w_\ell - f_{\min}w_h}{D},\qquad
t = \frac{v_h f_{\min} - v_\ell f_{\max}}{D}
$$

## 1.6 为什么需要"多轮"

解出 (α, t) 后，**α 和 t 一动，三根缆全动** ⟹ 可能把**第三根**挤出界。
所以每轮要重新找当前的 (h, ℓ)，再解一次。

## 1.7 为什么一定停（§5.1 的三步证明）

| 步 | 论证 |
|---|---|
| ① | **α 每轮严格递减**（原解违反约束 ⟹ 新解必须更"里面"）|
| ② | (h, ℓ) 组合**有限**：m 根缆 → 最多 m×m 种（本机 3×3=**9**，R2 4×4=16）|
| ③ | α 严格递减 ⟹ **同一对 (h, ℓ) 不可能重复** |

⟹ **最多 m² 轮，必然终止且停在最优解**。论文实测 ≤3 轮，上限取 3。

## 1.8 实测轨迹（用本机模型，`f ∈ [0.2, 25]`，位姿 (0,0)）

| τ_pitch | 第 0 步（α=1）| 越界 | 轮数 | 结果 |
|---|---|---|---|---|
| −0.5 | t=2.716, f=[8.72, 0.20, 0.38] | 否 | **0** | α=1.0000 |
| −1.0 | t=5.096, f=[17.35, 0.20, 0.51] | 否 | **0** | α=1.0000 |
| **−1.5** | t=7.476, f=[**25.98**, 0.20, 0.64] | **C1 超上限** | **1** | **α=0.9622**, t=7.206, f=[25.0, 0.20, 0.63] |
| −2.5 | t=12.235, f=[**43.24**, 0.20, 0.90] | **C1 超上限** | **1** | **α=0.5773**, t=7.206, f 同上 |

**两个重要观察**：
1. **力矩小 → 0 轮**（第 0 步就行）
2. **τ=−1.5 与 τ=−2.5 收敛到同一组 f** —— 因为 `α·τ` 都等于 **−1.443 N·m = 能力上限**

# 第二部分：上位机完整计算流程（一次 100 Hz tick）

## 2.0 全景

```
[100 Hz 工作线程] _cl_tick()
  ① 时间基准 / 使能检查 / 参数快照
  ② 读编码器 → roll, pitch
  ③ 张力守卫（过载/松绳/过期）
  ④ 按模式分派 ──┬─ 张力 / 张紧 / 力矩 / 阻抗 / 位置
                  ▼
[力矩模式] _cl_tick_force()
  ⑤ 构造参数（含位姿钳制 + 能力钳制）
  ⑥ 张力样本取用 + 年龄检查
  ⑦ 分配 f_d（TDA）
  ⑧ 每缆张力 PI → step（counts/帧）
  ⑨ 目标 = 实测 + step → 夹紧 → 0xD3 下发
  ⑩ 诊断记录 / 状态行
```

## 2.1 第 ① 步：时间与参数快照

| 项 | 内容 | 代码 |
|---|---|---|
| `dt` | 本拍与上拍之差，钳在 [1 ms, 50 ms] | `_cl_tick` |
| 参数 | **只读快照** `_cl_param_cache`（GUI 每 50 ms 刷新一次），**工作线程不碰控件** | `_refresh_cl_param_cache` |
| 使能检查 | `armed and connected` 否则停环 | `_cl_tick` |

## 2.2 第 ② 步：位姿

```
raw16/raw17 = _enc_filt_raw[16/17]        # 磁编滤波后的原始 counts（含解绕）
roll  = _angle_delta(_axis_deg(16, raw16), angle_baseline[16])   # [deg]
pitch = _angle_delta(_axis_deg(17, raw17), angle_baseline[17])
```

- `_axis_deg`：`raw/16384*360` 映射到 ±180°，再乘 `AXIS_SIGN`
- `_angle_delta`：相对零位基准，取最短角差

## 2.3 第 ③ 步：张力守卫

```
tens_ev, tens_txt = _tension_guard(roll, pitch)
```

| 判定 | 动作 |
|---|---|
| 样本过期（>300 ms）| 标注「样本过期」 |
| 过载（`f_i > f_max`）| **停环** |
| 松绳（`f_i < f_min`）| 标注「⚠松绳」 |

## 2.4 第 ④ 步：按模式分派

| 模式 | 函数 | 该步的"任务层"输出 |
|---|---|---|
| 张力 | `_cl_tick_tension` | `f_d[3]` = 你填的三个目标 |
| 张紧 | `_cl_tick_tight` | `f_d[3] = t*·n̂` |
| 力矩 | `_cl_tick_force` | `f_d[3]` = TDA(τ*, t_floor) |
| 阻抗 | `_cl_tick_impedance` → `_cl_tick_force` | `τ* = K(q*−q)+D(q̇*−q̇)+τ_ff` 后同力矩 |
| 位置 | `_cl_tick` 位置分支 | 角度 PID → 直接算 trim |

**从这里开始，三个力控模式走完全相同的 ⑤→⑩。**

## 2.5 第 ⑤ 步：构造参数 `_force_params_v2(roll, pitch)`

```
a) _force_geo(roll, pitch)                → (wrist_eval结果, n̂)
     · UI角 → 模型角（MODEL_AXIS_SIGN[0] 翻 roll、加零位补偿）
     · **钳进力封闭可行域**（roll −15…+10°, pitch −25…+30°），越界告警
     · 0.1° 网格缓存（1 s TTL）
b) 读 τ 输入框 → 钳到 ±tau_*_max
c) _clamp_tau_to_capacity(...)            → 按"能力"钳 τ（含方向！）
     · torque_capacity 二分（s_lo = s_hi）+ 2 s 缓存
     · 被钳时状态行告警 + 安全事件
d) 构造 WristForceV2Params（r_m, n̂, f_min/f_max, preload(=下限), kp_inner, ki_inner, max_step, max_trim, i_term_lim）
```

## 2.6 第 ⑥ 步：张力样本

```
last = _force_tick_prelude(roll, pitch, "力矩控制")
  · 关节越界（|roll|>30 或 pitch∉[−30,50]）→ 停环
  · 无张力样本 → 停环
  · age_ms = (now − last[0])·1000        # 样本年龄
```

> 注意：**越界检查（±30/50）比模型可行域（−15…+10 / −25…+30）宽**，所以先触发的是钳制而不是停环。

## 2.7 第 ⑦ 步：分配 `allocate_torque_priority`

```
P = [R; n̂ᵀ]（3×3） → P_inv
f_τ = P_inv·[τ_r, τ_p, 0]                        # 零预紧解（= 论文的 v）
s_lo = max_i (f_min − f_τ,i)/n̂_i                  # 论文算法2 第1步
s_hi = min_i (f_max − f_τ,i)/n̂_i
if s_lo > s_hi:            → None（该力矩不可行）
s = max(s_lo, t_floor)     # t_floor = 你填的「预紧N」（现在是下限）
if s > s_hi:               → None（预紧下限太大）
f_d = f_τ + s·n̂                                  # = α v + t w（α≡1）
```

**当前实现的 α 恒为 1**（做不到时由第 ⑤c 步在外面钳 τ）；
**论文会在这里迭代出 α<1** —— 这就是"缺的 4 行"。

## 2.8 第 ⑧ 步：每缆张力 PI

```
for i in 0..2:
    e_i = f_d,i − f_meas,i                         # [N]
    integ_i, resid_i, step_i = _incr_step(
        e_i, integ_i, resid_i,
        kp_inner, ki_inner, dt, max_step, i_term_lim)
    trim_i = trim_sign_i · step_i                  # [counts/帧]
```

`_incr_step` 内部（4 行）：

```
integ = clamp(integ + e·dt, ±i_term_lim/ki)        # 状态上限（N·s）
i_term = clamp(ki·integ, ±i_term_lim)              # 贡献上限（counts）
du = clamp(kp·e + i_term, ±max_step)               # 本帧步长（counts/帧）
step = round(resid + du); resid -= step            # 残差进位
```

## 2.9 第 ⑨ 步：目标与下发 `_apply_force_step`

```
for i, m in enumerate(MOTOR_FOR_CABLE):
    n = int(step_i)
    if n == 0 and not need_send: continue          # 稳态零流量
    cur  = _motor_pos_now(m)                       # 实测位置 [counts]
    out  = cur + n                                 # ← 目标 = 实测 + 步长
    out  = clamp(out, base − max_trim, base + max_trim)     # 累计行程
    out  = clamp(out, origin ± MOTOR_SOFT_LIMIT)            # 防溢出
    outs[m] = out
_send_motor_batch(outs) → build_motor_pos_abs_cmd(targets)  # 一帧 0xD3（30×int32）
```

> **这是全系统最关键的一行**：`out = cur + n`（**基准是实测**，不是上一帧目标）。
> 所以 `n` 在物理上是**速度指令**：`v ≈ K·n`。

## 2.10 第 ⑩ 步：诊断与显示

| 项 | 频率 |
|---|---|
| `_record_diag`（写 CSV 缓冲）| **20 Hz**（每 5 拍 1 行）|
| 状态行（τ 实测/目标、t、f、trim）| ~16 Hz（每 6 拍）|
| `force_alpha` / `m*_tgt` 通道 | 每拍 |

# 第四部分：三个力控模式在哪分岔、在哪合流

| 步 | 张力 | 张紧 | 力矩 |
|---|---|---|---|
| 任务层 | `f_d = 你填的 3 个数` | `f_d = t*·n̂` | `f_d = TDA(τ*, t_floor)` |
| **之后 ⑤→⑩** | **完全相同** | **完全相同** | **完全相同** |

**所以"模式"只影响第 ⑦ 步的输入，执行器只有一套。**

# 第五部分：与论文的差异（上位机侧）

| 步 | 论文 | 本机 | 差距 |
|---|---|---|---|
| ⑤ 位姿 | 未讨论（假设有效）| **钳进力封闭域 + 告警** | ➕ 本机补充 |
| ⑤ 力矩钳制 | 无（α 在内部解）| **外部二分钳 τ + 2 s 缓存** | ⚠ 替代方案 |
| ⑦ 分配 | **算法 2（迭代 α,t）** | 闭式第一步 + α≡1 | ❌ **缺 4 行** |
| ⑧ 内环 | **腱空间 PD（电压）** | **张力 PI（增量）** | ➕ 本机多积分 |
| ⑨ 输出 | 电压 `u` | **位置指令 `0xD3`** | 结构不同（舵机内部位置环）|
| `t` | **算出来** | **算出来**（`max(s_lo, floor)`）| ✅ 已对齐 |
| `α` | **算出来** | 恒 1（靠外部钳 τ）| ❌ 未对齐 |
