# 腕部控制架构总览（2026-11-20）

> **一句话**：四层结构 —— **① 传感器 ② 控制律（100 Hz）③ 执行器语义 ④ 固件/舵机**。
> 三个力控模式（张力/张紧/力矩）是**并列的三种"目标→三缆张力目标"的转换方式**，
> 后面**共用同一个"三缆张力 PI + 增量下发"执行器**。
> 位置模式走另一条支路（角度闭环），与前三个并列。

## 二、逐层职责（含公式与代码位置）

### ① 传感器层

| 量 | 频率 | 处理 | 代码 |
|---|---|---|---|
| 三缆张力 | **250 Hz** | 通道映射 × 系数（`TENSION_N_PER_RAW = −0.0098 N/count`）| `_tension_feed` |
| 腕角 | ~130 Hz | 滤波 + 解绕 + 零点 + 方向（`AXIS_SIGN`）| `_encoder_filter_update` / `_axis_deg` |
| 舵机遥测 | 10 ms | ABS/speed/load/current/volt/temp | `RxThread._dispatch` |

**设计要点**：控制律只取"最近一帧"并检查**年龄**（>300 ms 判过期 → 冻结输出）。

### ② 控制律层（100 Hz）

**入口**：`_cl_tick()` → 三道前置检查 → 按 `_cl_mode` 分派。

**前置检查**（任一失败即停环）：

1. 使能/连接
2. 磁编有数据
3. 参数快照就绪

**然后**：张力守卫（过载/松绳/过期）→ 分派到四个模式之一。

| 模式 | 你给的量 | 中间的"翻译" | 输出 |
|---|---|---|---|
| 张力 | `f*[3]` 三缆绝对张力 | **无翻译**（直接用）| `Δ[3]` |
| 张紧 | `t*` 一个标量 | `f_d = t*·n̂`（保零空间，不产生力矩）| `Δ[3]` |
| 力矩 | `τ*` 两个标量 | `f_d = α·f_τ + t*·n̂`（TDA，含降额）| `Δ[3]` |
| 位置 | `θ*` 两个角度 | 角度 PID（不经过张力）| `Δ[3]` |

**三个力控模式共用执行器**：

```
e_i    = f_d,i − f_meas,i
Δ_i    = clamp(Kp·e_i + Ki·∫e_i·dt, ±max_step)     ← 增量 PI（wrist_force_law._incr_step）
目标_i = 实测位置_i + Δ_i                            ← _apply_force_step
钳制   : |目标_i − 起点_i| ≤ max_trim
```

### ③ 执行器语义层（**最该记住的一层**）

```
目标 = 实测 + Δ   ⟺   Δ 是"速度指令"
```

| 事实 | 式子 | 数值 |
|---|---|---|
| 伺服速度 | `v ≈ K·Δ` | K ≈ 7~13 /s |
| 速度上限 | `v ≤ 3400 c/s` | 固件常量 |
| 张力上升率 | `S·v = S·K·Δ` | ≈ 0.46 Δ N/s |
| 每帧张力跳变 | `S·Δ` | Δ=75 时 3.5 N |

**由此推出的三条结论**（踩过的坑）：

1. **限幅 `max_step` 只在 `Kp·e > max_step` 时才起作用** —— 5 N 目标时 `Kp·e = 50~75`，填 340/2000 都是空操作。
2. **想快必须让误差大**（`Kp` 或前馈），不是抬高限幅。
3. **把目标挂远（累加）会快，但会刹不住** —— 存留偏移 = `S·偏移` 的张力冲击。

### ④ 固件 + 舵机

| 项 | 值 |
|---|---|
| 帧格式 | `0xD3`：30 路 int32 位置，**没有速度字段** |
| 速度上限 | `SERVO_TARGET_SPEED_DEFAULT = 3400` steps/s |
| 加速度 | `SERVO_TARGET_ACC_DEFAULT = 254` |
| 舵机内部 | 位置环（增益 ~10 /s），有负载下垂（需积分补）|

## 三、数值走一遍（张力模式，目标 5 N，实测 0）

```
① 传感器：f = 0.00 N（年龄 5 ms ✓）
② 模式：张力，f* = 5 N
   e = 5 − 0 = 5 N
   Δ = clamp(15×5 + 0, ±100) = 75 counts/帧      ← Kp=15, max_step=100
③ 执行器：目标 = 实测 + 75 → 目标领先实测 75 counts
   伺服: v ≈ 10 × 75 = 750 c/s
   张力上升率 = 0.0464 × 750 = 34.8 N/s
④ 下一帧（10 ms 后）：f ≈ 0.35 N → 继续 → 约 0.23 s 到 5 N
```

## 四、五个容易懵的点（澄清）

| # | 疑惑 | 澄清 |
|---|---|---|
| 1 | "我每帧给 +Δ，目标不是一直在动吗？" | 目标**跟着实测平移**：`目标 = 实测 + Δ`，所以领先量恒为 Δ |
| 2 | "限幅调到 2000 为什么不变快？" | `Δ = Kp·e` 只有 50~75，限幅根本没碰到 |
| 3 | "张力是闭环，力矩是开环？" | **两者架构一样**（前馈分配 + 张力闭环）；差别在"做不到时"：张紧**拒**，力矩**降额 α** |
| 4 | "t 是什么？" | 预紧/零空间张力：决定**力矩能力**（大 → 能力强）与**绳伸长**（大 → 精度差） |
| 5 | "α 是什么？" | 力矩的降额系数：`f_d = α·f_τ + t·n̂`，**只缩力矩，不缩预紧** |

## 八、阻抗层（外环，未实现）

> 论文的顶层目标。**你现在没有这一层。**

```
【任务层/阻抗】 q* − q ──K──► τ*          ← 外环（带宽最低）
【分配层】      τ*, t ──► f_d[3]           （TDA，见 张力分配_闭式解）
【张力环】      f_d → Δ                    （内环，100 Hz）
【舵机环】      Δ → 电机转角               （最内，固件）
```

$$
\tau^* = K_\theta(q^*-q) + D_\theta(\dot q^*-\dot q) + \tau_{ff}
$$

| 项 | 作用 | 现状 |
|---|---|---|
| `K(q*−q)` | 弹簧：偏离目标就回中（**这就是刚度**）| ❌ 无 |
| `D(q̇*−q̇)` | 阻尼：抑制回中过冲 | ❌ 无 |
| `τ_ff` | **重力/外载前馈**：抵消腕自重（否则 `q*` 停不住，偏 `τ_g/K`）| ❌ 恒 0（代码注释已标明 deferred）|

### 三个易混淆的概念

| 控制方式 | 控什么 | 关节刚度 | 外力推 10° 时 |
|---|---|---|---|
| **位置模式** | 位置 | **硬**（缆弹性 4.3 / 20 N·m/rad）| 顶住，松手弹回 |
| **张力/张紧/力矩** | 力 | **≈ 0** | **一直漂走，不回中** |
| **阻抗** | 力 = K×位置误差 | **可调 0.05~1.5 N·m/rad** | 按 K 软软回中 |

**⚠ 关键**：纯张力控制下"t = 刚度"**不成立**（张力被调住 → 共收缩不产生刚度）。
`t` 只决定**力矩能力**。刚度必须由阻抗层（位置误差 → 力矩）提供。

### 实现顺序（不要跳级）

1. **`τ_ff` 重力前馈**：起环静止时锁一次 `τ_ff = R(q0)·f_meas0`（不用知道腕质量）
2. **能力检查 + 反解 t**：见 [张力分配_闭式解_20261120.md](张力分配_闭式解_20261120.md)
3. **阻抗层**：`τ* = K(q*−q) + D(q̇*−q̇) + τ_ff` → 走 TDA
4. （可选）变刚度：`t` 与 `K` 联动（腱驱动的真正卖点）

### 重力前馈 `τ_ff`（2026-11-23 定案：**串列式正弦模型**）

**界面**：阻抗行两个框 `τff@90°`（`tau_ff_r` / `tau_ff_p`）[N·m] —— 填 **90° 处的重力力矩幅值 A**。

**模型**（roll 是外轴、pitch 是内轴 → **roll 转动会影响 pitch**）：

$$
\begin{aligned}
\tau_{g,\text{roll}}  &= A_r\,\sin(\text{roll}) \\
\tau_{g,\text{pitch}} &= A_p\,\sin(\text{pitch})\cdot\cos(\text{roll}) \\
\tau_{ff} &= -\,\tau_g \quad\text{（重力要取反）}
\end{aligned}
$$

**`cos(roll)` 的物理意义**：`roll = ±90°` 时 pitch 轴被转到与重力平行 → pitch 重力矩为 0；
而 pitch 不影响 roll（外轴不感受内轴转角）。

**实测**（A=0.3/0.3）：

| roll | pitch | τ_ff_roll | τ_ff_pitch | 说明 |
|---|---|---|---|---|
| 0 | 0 | 0.0000 | 0.0000 | 都不掉 |
| 0 | 90 | 0.0000 | **−0.3000** | pitch 最大 |
| 90 | 0 | **−0.3000** | 0.0000 | roll 最大 |
| **90** | **90** | −0.3000 | **0.0000** | pitch 被 cos90 归零 |
| 60 | 90 | −0.2598 | **−0.1500** | pitch 剩一半 |
| 45 | −60 | −0.2121 | **+0.1837** | 反号 |

**为什么要它**（K=0.5、A=0.3）：无前馈时静差 **−14°~−34°**，有前馈时 **0.00°**。

**局限**：`A` 是"90° 处"的单一幅值，隐含"力臂长度不随角度变"；若机构有偏心/变力臂，
高角度会有偏差（可把 A 按实测微调）。


**阻抗模式的行为**：`q* − q → K → τ*` → 之后**完全复用②**（能力钳制 → 分配 → 张力 PI）。
所以阻抗是"外环"，力矩是"内环"，代码上是**同一函数链**（`_cl_tick_impedance` 算完 τ 就调 `_cl_tick_force`）。

**没有 `τ_ff` 时**：目标点会被自重压偏 `τ_g/K`（K=0.5、重力 0.05 N·m → 偏 5.7°）。
**这就是为什么 §六 建议先补 ①。**
