# MMHand 腕部直控上位机使用说明（mmhand_scope.py）

> 适用软件：仓库根目录 `mmhand_scope.py`（示波器 + 腕部三舵机直控 + 四模式力控）
> 整理日期：2026-11-04（依据当日源码逐行核对）
> 全手 27 舵机官方上位机（`python -m desktop ui`）请看 [上位机使用说明](上位机使用说明.md)——两者是不同软件。

---

## 0. 这个软件是干什么的

`mmhand_scope.py` 是**腕部（ROLL/PITCH 两轴、C1/C2/C3 三缆、M27-M29 三舵机）专用**的调试上位机，一台电脑同时做四件事：

| 功能块 | 说明 |
| --- | --- |
| 示波器 | 实时绘制 P4 上传的全部磁编码器 J00-J20、M27-29 位置/速度/负载/电流/电压/温度、三缆张力、力控目标/实测/α 等约 50 条曲线 |
| 腕部直控 | M27-29 逐绳使能、点动、相对目标、限速斜坡、急停、零位存储/回零、一键松绳/紧绳 |
| 闭环控制 | 100Hz 软闭环，四种模式：**位置（模型前馈）/ 张力 / 张紧 / 力矩**，共用每拍限幅与张力守卫 |
| 张力·R 观测台 | 直连 ZNSV 张力变送器，看 R(θ) 力臂矩阵、三缆张力、τ=R·f、张紧 t、绳长，导出 CSV |

通信链路：

```
P4 控制板 ──COM13 @921600──┐
                            ├─→ mmhand_scope.py（Qt 主线程 + 串口收发线程）
ZNSV 张力变送器 ─COM23 @600000─┘   （默认口，均可在界面改）
```

### 启动

```powershell
# 仓库根目录，用仓库自带虚拟环境
.venv\Scripts\python.exe mmhand_scope.py            # 默认 COM13，启动 0.3s 后自动连接
.venv\Scripts\python.exe mmhand_scope.py --port COM5
.venv\Scripts\python.exe mmhand_scope.py --no-auto-connect
```

窗口固定 1600×900 居中（16:9），控制面板在右侧滚动区内。

### 退出

直接关主窗即可：会自动关闭两个子窗、写一行 `APP_CLOSE` 安全日志、断开张力串口、若在使能态先发急停、断开 P4（并把上行流掩码恢复全开）、保存布局。

## 2. 第 1 步：连接 P4

1. 工具栏**串口**下拉选 P4 所在口（默认 COM13；列表实时枚举，过滤蓝牙口，可手输）。
2. 点**连接**（或靠启动时的自动连接）。打开成功后：
   - 按钮变"断开"，状态栏显示 `已连接 COM13 @ 921600`；
   - 自动下发**上行流掩码**只保留示波器需要的 5 类流（映射角/ABS/单圈/遥测/磁编 raw），状态栏"带宽"变 `精简(+遥测+单圈)`——这是为了给闭环腾带宽；
   - 曲线缓冲清空，新会话从 0s 开始计时。
3. 断开时自动把掩码恢复全开，不影响官方上位机再连。

心跳：连接期间每 500ms 发一帧主机心跳维持链路。

> 连接失败/超时（2s）会在状态栏给原因；串口中途拔掉会以 `串口错误` 提示并自动断开、停闭环。

## 3. 第 2 步：看曲线（示波器）

**每次会话的常规打法：**

1. 左上**预设**下拉选 `腕部调试`（一步勾上 20 条腕部相关通道：J16/J17、M27-29 位置与目标、三缆张力、张紧 t、τ 目标/实测、α、trim）。其它预设：`全磁编raw`、`M27-29遥测`、`全清`。也可以在通道树手动勾选（组节点三态勾选=整组）。
2. 通道树顶部**搜索框**输入文字即时过滤通道名/组名。
3. **双击**通道项弹取色器换曲线颜色（随布局记住）。
4. 工具栏调显示：
   - **窗口**：10/30/60/120s 时间窗；
   - **X跟随**：勾=示波器式滚动跟随最新数据；取消后可左键拖动/滚轮缩放；
   - **Y自适应 / Y限**：Y 自适应或手动给上下限（手填 Y 限会自动关掉自适应）；
   - **归一化**：每条曲线按窗口内自身 min/max 归一到 0-1，量纲混画时用；
   - **绝对时间**：X 轴刻度换成 wall-clock HH:MM:SS。
5. 鼠标在曲线区移动出现**十字游标+读数框**（最多列前 5 条曲线在游标 X 处的值）。
6. **暂停曲线**冻结画面（数据仍全量入缓冲），覆盖提示"⏸ 已暂停"。
7. **清空**清所有曲线缓冲。

**性能相关（状态栏右侧）**：`🖥60fps/3.2ms/2.00px·软` = 主图实际帧率 / 一帧 paint 耗时 / 每像素点数 / 软件光栅。曲线点数按 paint 实测自适应（0.25~3 点/px），帧率钉在 60FPS（`MMHAND_PLOT_HZ` 可调）。闭环运行且勾了🔒运行优先时主图自动降到 30FPS 让路控制环。

> 张力/τ/t 曲线与编码器曲线共用同一会话时间零点（2026-11-04 修复：此前张力类通道用开机绝对秒，连 P4 时在主图跑出视野）。

## 4. 第 3 步：建立角度基准（📐 归零）

ROLL=J16、PITCH=J17 磁编码器。所有"当前角"都是**相对基准零点**的角度。

1. 连接后等磁编表 J16/J17 行变 `● 在线`，ROLL/PITCH 大字显示绝对角（提示"未设基准"）。
2. 把腕摆到想要的零位姿态，点 **📐 ROLL / 📐 PITCH / 📐 双轴**——当前滤波角记为 0 点，Δ 立即归零，并**落盘**（重启自动恢复，不用重标）。
3. 显示链：raw counts →（跨 0/16383 绕回点解绕）→ 中值 5 → EMA(α=0.10，τ≈76ms) → ×轴方向符号（J17 取反）→ 相对基准的 Δ 角。闭环、观测台、参数窗用的都是这条滤波链（2026-11-05 α 由 0.05 上调，反馈滞后减半）。
4. 使能/闭环启动时若基准缺失会自动零一次并保存；已有基准（📐 设置或布局恢复）**不会**被覆盖。

## 5. 第 4 步：逐绳勾选 + 使能直控

### 5.1 逐绳使能开关

右列每台电机行首有勾选框 `M27·C1 / M28·C2 / M29·C3`（缆名按当前电机-缆映射自动标注）：

- 勾选 = 该绳参与使能、归零、在线检查，可接收点动/Go/斜坡/回零/闭环命令；
- 取消 = **一切命令不下发**（0xDE 单电机命令固件不查活动域，所以门禁做在上位机每条发送路径上）；使能状态下取消会**自动解除武装**并提示重新使能（P4 活动域是使能时快照，必须重建）；
- 闭环运行中改勾选会先停闭环；
- 一根都没勾 → 使能直接拒绝；
- 勾选状态随布局持久化。

### 5.2 使能流程（点「使能直控（自动归零+保持）」）

上位机自动执行（约 0.5~1s）：

1. 预检：已连接、勾选电机全部在线、路由扫描不在进行中、有 ABS 快照；
2. 若多圈未知 → 自动发归零命令并轮询（最多 6s）；
3. 发 `STOP` + `RESET`（清 owner/E-STOP 锁存，这是活动域能写入的前提）；
4. 写**活动域** = 勾选电机的掩码；
5. 150ms 后发 `START` + 一帧 30 路批量目标 = **各电机当前实测位置**（即"使能即保持"，不会跳）；
6. 200ms 轮询直到固件进入 RUN_DIRECT → 灯变 `● 已使能 直控中`，记录各电机起点（累计行程的基准）；
7. 期间会核对固件活动域是否真含勾选电机，缺则自动重写重试（最多 2 次）——防"点动能动、批量只有一台动"。

未确认的原因会显示在控制面板状态行：E-STOP 锁存（先复位）/ 状态拒绝 / 硬件不可控 / 多圈未知 / 舵机离线 等。

**使能后能做什么**：点动、Go、斜坡、回零、闭环、一键松/紧绳。每次运动命令都写入安全取证日志。

## 6. 第 5 步：手动驱动电机

### 点动（jog）
每台电机行 `−步长 / ＋步长` 按钮（按住自动重复：280ms 起步、90ms 间隔）。步长由**下拉框**或快捷档按钮（100/500/1000/2000）设定。目标 = 上次指令位置 ± 步长。

### 相对目标输入框 + Go
输入框填**整数 = 相对当前位置的位移**（如 `500` 或 `-300`，回车=发送）。语义要点：

- 走 `_send_motor_target`：**无软件限位**，只受"限速斜坡"约束（直控定案：直控不做张力检测）；
- 未使能时发送 → 自动走使能流程，完成后按记录的起点换算绝对目标再发（并提示换算结果）；
- 位移范围守卫 ±2,000,000（int32 安全域）。

### 限速斜坡
勾选**限速斜坡** + 最大速率（默认 3000 c/s）：大位移按 50ms 一拍分步逼近，避免舵机全速冲。小位移（≤2×步长）直发。斜坡是多电机**一拍一帧批量**下发。

### 电机状态行
每台下方一行：`起点 +xxx 实际 +xxx 目标 +xxx 累计 +xxx`（累计=相对使能起点）；未勾选的显示 `☐ 未勾选，不下发命令`。

## 7. 急停 · 复位 · 保持

| 按钮 | 行为 |
| --- | --- |
| ⛔ 急停 STOP | **抢占式**：先丢弃队列里所有待发运动帧，再走优先通道立刻发 STOP（不等 FIFO 排队）。固件收到后**关闭舵机力矩**——腕部会松开/下垂、张力释放。同时停闭环/斜坡/使能轮询，UI 进入 `⛔ E-STOP 锁存`，**只有「复位」能解锁** |
| 复位 | 发 CMD_RESET 清 E-STOP 锁存与可恢复故障（舵机断扭），之后可重新使能 |
| 停止闭环（自动"刹住"） | 停 100Hz 定时器 + 丢队列 + 优先发一帧"保持当前实测位置"（0xD3），力矩不断——用于正常停环，区别于急停 |

## 8. 零位管理

- **💾 存储零位**：把当前 M27-29 实测位置 + J16/J17 raw 记入 `run_data/scope_exports/wrist_zero.json`（带时间戳）。
- **🎯 回到零位**：读存档，目标经 **±2,000,000 counts 软限位**（相对使能起点）钳制后**一帧批量**回零；超钳制会提示哪些电机被压。未使能时自动先使能。闭环运行中拒绝。

> 软限位说明：`MOTOR_SOFT_LIMIT=2000000`（≈int32 安全域），等效解除旧的 ±5000，仅防溢出；闭环律内部另有自己的 ±soft_limit。

## 9. 一键松绳 / 一键紧绳

### 🪢 一键松绳
全部勾选电机按 **trim 方向** 放绳：每台共 2500 counts，**拆 5 步 × 500c**、步间隔 200ms，每步一帧 0xD3 批量。门禁：已使能 ∧ 非闭环 ∧ trim 方向合法 ∧ 活动域齐 ∧ 有指令基准。方向 = `-2500 × trim_sign`（trim_sign=+1 → counts 减 = 放）。
中途急停（targets 被清）会自动中止并提示。松绳不做张力检测（定案：张力保护只在闭环）。

### 🪢 一键紧绳（事务化 TDA 恢复）
把三缆恢复到**标准张力分布 f = t·n̂**（当前位姿几何唯一分法，τ≈0）。内部是一个事务：

1. **门禁七查**：已使能 ∧ 非闭环 ∧ 张力新鲜(≤0.5s) ∧ 当前不过载/非法 ∧ 三缆全勾 ∧ 位姿有效且 n̂ 全正 ∧ 在模型行程内；
2. **t_use 计算**：`张紧N` 目标经 tmin/tmax 钳制、上限 100N、并须落在当前位姿可行域 `[fmin/min(n̂), fmax/max(n̂)]`——低于下界会被拒（例：fmin=1 时地板约 3.78N，t 目标 3.0 会被正确拒绝，解法：fmin 降 0.5 或 t≥3.8）；
3. **按真实位姿预校验**力控参数，再**备份**当前模式与参数框 → 切**力矩模式、τd=0、preload=t_use** → 启动闭环；
4. 成功 → 状态徽章"🟡 恢复中"，三缆进界稳定 300ms 后自动转正常；
5. 任何一步失败 → 停环 + 模式/参数框全回滚并提示原因。

紧绳期间腕会"沉降找平衡"——分布决定力矩，τd=0 时腕回到力矩平衡位，属正常现象。

## 10. 闭环控制（100Hz，四模式）

闭环面板在直控面板底部。**启动前必须已使能**（未使能点启动会自动使能后接续启动）。

### 10.1 模式选择与通用规则

模式下拉四选一（运行中切换会先停环；选择随布局记住）：

| 模式 | 被控量 | 适用 |
| --- | --- | --- |
| 位置模式（角度闭环） | ROLL/PITCH 关节角 | 走轨迹、录标定 |
| 张力控制 | 每缆张力 f_i (N) | 台架起步，最直观 |
| 张紧控制 | 预紧度 t=f·n̂ (N) | 整体紧/松而不产生力矩 |
| 力矩控制 | 关节力矩 τ (N·m) | 进阶：柔顺/交互 |

- 力控三模式启动前置：**张力串口已连且样本 ≤0.5s 新鲜** + 参数合法（含 trim 方向 3 个 ±1）+ 位置基准=电机**实测**位置（防首拍跳变）；
- 三力控模式统一**增量式**执行：每拍步长经 `每拍限幅` 限制，出口 `out = 实测当前位置 + 步长`，相对进入点累计行程被 `trim限幅` 夹住（堵转不漂）；
- 位置模式与力控共用同一个**每拍限幅**（默认 5 counts/拍 = 100Hz 下 500 c/s）；
- 张力守卫（闭环内每拍）：过载→停环；样本过期→冻结不发送；**🛡安全保护**关掉时阈值非法也不再 fail-closed（风险自负，状态栏常显 ⚠）；
- 越界停环：力控模式下 ROLL>±30° 或 PITCH 出 [-30°,50°] 停；
- 停环默认"刹住"（保持当前位）；急停/断开路径 hold=False 直接断力矩。

### 10.2 位置模式（两种结构：前馈+PID / 纯PID）

1. **📥 载入标定**：读 `run_data/scope_exports/wrist_calib.json`（由识别脚本 `python -m tools.identify_wrist_calib <csv> --write` 生成），显示 k 系数与 δ 偏移。**两种结构都必须载入**——k 与 R 是"角度→counts"的唯一换算来源；
2. **选位置环结构**（下拉框，2026-11-10）：
   - **前馈+PID**（绝对式）：`目标 counts = origin + k·[l(θ*) − l(启动位姿)] + J·δθ`。模型算绳长前馈，PID 只补模型误差；到位最快、稳态靠积分吃掉模型偏差。
   - **纯PID**（增量式）：`目标 counts = 实测位置 + J·δθ`。不做前馈、不用模型绳长，只借当前雅可比 `J = −k·R`（counts/deg）把角度误差折算成 counts——和三个力控模式同一个"每拍从实测走一步"语义。
   两种结构共用同一组 PID 参数与同一个 `δθ`；运行中切换会**先停环**，选择随布局持久化（取代旧的「模型前馈」勾选框，旧布局的 `cl_model_on` 会自动迁移）。
3. 参数：目标°（ROLL/PITCH，实时生效）、**Kp（0.6）/ Ki（0，1/s）/ Kd（0，s）**、死区°（0.3）、限幅°（25）、分轴闭环开关（ROLL环/PITCH环）。
   - `δθ = Kp·e + Ki·∫e·dt + Kd·(−dθ_fb/dt)`，微分**作用在反馈角速度**上，所以拖目标框不会砸出尖峰；
   - 积分项被钳在"限幅°×1"以内（状态行"⚠积分饱和"），防 windup；
   - 反馈过了 76ms EMA，Kd 一般 0~0.05 就够，再大只是放大噪声。
4. **扫掠**（波形可选）：闭环运行中让所选轴自动走目标波形（目标框被自动改写）——**三角波**=录标定数据（勾「⏺记录标定数据」+ 慢速 0.2~0.5°/s）；**正弦波**=跟随/带宽测试（目标=幅值×sin(2π·频率·t)，频率 0.05~2Hz；峰值速度需求=幅值×2πf，超过每拍限幅速度就削顶=带宽已到）。
   ⚠ 默认「每拍限幅 5c/拍」≈ 500 c/s，折算成角度只有 ROLL ≈9.8°/s、PITCH ≈3.8°/s（ROLL 每度 C2 约 51 counts、PITCH 每度 C1 约 132 counts）。要跑 ±25°@0.2Hz 的正弦（峰值约 31°/s），必须先把每拍限幅提到 ≥16（ROLL）/ ≥42（PITCH），否则曲线一定是被削顶的。
5. 状态行解读：`前馈+PID 跟踪中/保持(硬错误) ROLL +1.20→+5.00° PITCH… ⚠目标钳制/低pitch区/反馈越界/积分饱和`；纯PID 时前缀是 `纯PID`。
   ⚠ **在该配置下 Kp 的作用很有限**：每拍限幅 5c 时，指令每拍只能动 0.1° 左右，P 项那点助推追不上限幅，Kp 0.3~1.5 的阶跃曲线几乎重合（实测 5° 阶跃 49 拍≈0.49s 进死区，单调不过冲）；把每拍限幅提到 300c 以上，文档里"过冲 ×Kp"的行为才会出现。

### 10.3 张力控制（每缆独立 PI）

参数行：`f目标N`（C1/C2/C3 三个框，默认 2N）、`Kp_f`（10 counts/N）、`Ki_f`（10，0=纯P）。
每缆独立增量 PI：`du=Kp·e+Ki·∫e`（饱和冻结），死区 0.05N，步长×trim_sign 下发。P 直接作用在误差上——Ki=0 也会持续逼近，不会"只动一次"。

### 10.4 张紧控制（零空间预紧，τ 守恒）

参数行：`张紧N`（t 目标，默认 5）、`Kp_t`（50）、`Ki_t`（10）。
t 目标必须落在当前位姿可行域（启动与逐拍都会查，越界直接拒/停并提示界值）。修正步长沿 n̂ 分配，R·n̂=0 保证力矩不变。**fmin 方向地板**：某缆 ≤fmin 且本步是放绳方向 → 该缆本拍禁放并清积分。tmin/tmax 越界只在状态行⚠提示，不停环（硬安全由逐缆 fmax 过载停环负责）。

### 10.5 力矩控制（v2 解耦力矩律）

参数行：`τd(N·m)`（ROLL/PITCH 期望力矩）、`预紧N`（沿零空间，TDA 自动分配）、`Kp_τ`、`Ki_τ`（0=纯P）、`trim增益`（counts/N）。

一拍链路：τ_meas=R(q)·f → PI 校正 u（钳 ±可达力矩）→ TDA 分配 f_d（超界时 α<1 优雅降级）→ 三缆张力误差 → 增量步长。

- **Kp_τ 起步建议 1~5**：默认 100 实测过大会全程饱和（α≈0.065，状态行/α 曲线可见）；
- α<0.999 时状态行显示 `α=0.xx↓`，α 曲线通道 `force_alpha` 常看；
- 抗饱和：α<1 时外环积分本拍冻结；
- τr/τp 上限框（边界行）留空=不启用，填了则目标框自动压回界内。

### 10.6 力控公共行（三模式共享）

- **trim方向**：`1,1,1`（+1 = counts 增 ⇒ 该缆张力增）。**错填=正反馈飞车，上电前务必核对**；换接线后点动 ±100c 看该缆张力升/降来复核。三模式共用，一键松绳方向也由它决定；
  ⚠ **必须与标定 k 反号**：不变量 `sign(trim_sign_i) = −sign(k_i)`——位置环靠 k 定方向（`J=−k·R`），力控三模式与一键松绳靠 trim_sign 定方向，同号说明其中一处写反了（位置环正反馈，或松绳/力控反着走）。载入标定时标定行会红字提示，启动闭环时控制日志也会再提示一次；两者一致的唯一办法是**做一次 +100c 点动**；
- **trim限幅**：3000 counts，相对力控进入点的最大累计行程；
- **边界行六框**：`fmin`（TDA 下界，默认 0.5）｜`fmax`（**力控过载停环唯一来源**，默认 30）｜`tmin/tmax`（张紧预警+目标钳制，留空不启用）｜`τr/τp上限`（目标钳制，留空不启用）。有效 f 界 = 边界行与观测台守卫框**取严**（见 12.3）。

### 10.7 🔒运行优先（默认不勾）

勾上后闭环运行期间主图 60→30FPS、表格/观测台 60→30Hz，停环自动恢复。数据链不受影响。点数自适应通常已够用，这是保守保险档。

### 12.3 零点 / 去皮 / 清零（三个不同层次，别混）

## 16. 故障排查 FAQ

| 现象 | 原因与处理 |
| --- | --- |
| 连接失败/超时 | 口被占（官方上位机/ZNSV 开着？）、线缆；换 --port |
| 使能被拒：E-STOP 锁存 | 点「复位」后重新使能 |
| 使能被拒：缺 Manual / 状态拒绝 | 看状态行 reject 名（状态不允许/硬件不可控/多圈未知…），多圈未知会自动归零重试 |

| 力控启动失败：参数非法 | trim方向须 3 个 ±1（逗号分隔）；检查边界框数值 |

| ACK 刷屏 | 正常：OK 与拒绝均 1s 最多 1 条（高频命令节流） |

## 18. 典型工作流速查

**台架起步（首次上电）**：连接 → 📐双轴归零 → 逐绳勾选 → 使能 → 小步长点动核对三缆收/放方向（trim方向=1,1,1 的依据）→ 观测台连张力 → 一键松绳（松垂）→ 一键紧绳（预紧到位）。

**录标定**：位置模式 → 载入标定（或先用草稿）→ 勾模型前馈 → 勾⏺记录 + 扫掠（0.2~0.5°/s）→ 启动闭环录数 → 停环自动落盘 → `python -m tools.identify_wrist_calib … --write` → 重新载入标定。

**力控首跑**：观测台连张力、设 fmin/fmax（守卫框或边界行）→ 张力模式小目标（2N）验证方向 → 张紧模式验证 τ 守恒 → 力矩模式 Kp_τ 从 1~5 起步，盯 α 曲线与 trim。

**日常开机**：启动（自动连接）→ 基准自动恢复 → 使能 → 干活 → 关窗（自动急停/断链/存布局）。
