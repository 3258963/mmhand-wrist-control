# 力矩控制：完整流程（最终版，2026-11-22）

> **本文是"实现规格"** —— 上位机 100 Hz 一环从读传感器到发 `0xD3` 的全部步骤，
> 含 α 内生于分配、预紧 t 反解、闭式能力、失败分支。
> **与论文（Abdallah 2013 算法 2）逐位等价**（已数值验证）。

## 0. 输入 / 输出总表

| 类 | 量 | 单位 | 来源 |
|---|---|---|---|
| **输入** | `roll, pitch` | deg | 磁编（滤波+解绕+零点）|
| | `f_meas[3]` | N | ZNSV 250 Hz |
| | `τ* = (τ_roll, τ_pitch)` | N·m | 界面 |
| | `f_min, f_max` | N | 界面 |
| | `t_floor`（预紧下限）| N | 界面（可 0 = 不设）|
| | `α_cap`（安全系数）| — | 界面（1.0 = 对齐论文）|
| | `kp_inner, ki_inner, max_step, i_term_lim, max_trim` | — | 界面 |
| **中间** | `R(2×3), n̂(3)` | — | 模型（位姿钳制后）|
| | `k, d, u` | N·m, —, — | 由 `τ*` 与 `P⁻¹` 得 |
| | `m_max`（该方向能力）| N·m | **闭式 9 项取最小** |
| | `α`（力矩实现比例）| — | `min(α_cap, m_max/k)` |
| | `f_τ`（零预紧解）| N | `P⁻¹[ατ*;0]` |
| | `t`（实际预紧）| N | `max(s_lo, t_floor)` |
| **输出** | `f_d[3]` | N | `f_τ + t·n̂` |
| | `trim[3]` | counts/帧 | 每缆张力 PI |
| | `目标[3]` | counts | `实测 + trim` → `0xD3` |

**恒等式（自检用）**：`R·f_d = α·τ*`（**注意不是 `τ*`**，力矩已被 α 缩放）

## 1. 十步流程

```
① 时间基准 / 使能检查 / 参数快照（不碰控件）
② 读位姿 roll, pitch（磁编 → 角度）
③ 张力守卫：样本过期 / 过载 / 松绳
④ 模式分派 → 力矩模式
⑤ 几何：_force_geo → 位姿钳进力封闭域 → R, n̂
⑥ 读参数：τ*, f_min, f_max, t_floor, α_cap
⑦ 归一化：k = ‖τ*‖；d = τ*/k；u = P⁻¹[d;0]
⑧ 能力：a_i = f_min/n̂_i，b_i = u_i/n̂_i，c_i = f_max/n̂_i
        m_max = min{ 9 个配对项, 3 个下限项 }
⑨ α = min(α_cap, m_max / k)     ← **α 在这里算出来**
⑩ 预紧：f_τ = α·k·u；s_lo = max_i (f_min − f_τ,i)/n̂_i
        t = max(s_lo, t_floor)；f_d = f_τ + t·n̂
⑪ 每缆 PI：e_i = f_d,i − f_meas,i → (integ, resid, step_i)
⑫ 目标：target_i = 实测_i + trim_sign_i·step_i（夹 max_trim / 软限位）
⑬ 下发：一帧 0xD3（30×int32）
⑭ 诊断（20 Hz） + 状态行（~16 Hz）
```

## 2. 第 ⑧ 步：能力的闭式公式（核心）

$$
m_{\max} = \min\left\{
\min_{\substack{i,j\\ b_j>b_i}} \frac{c_j-a_i}{b_j-b_i},
\ \min_{\substack{j\\ b_j>0}} \frac{c_j-t_{\text{floor}}}{b_j}
\right\}
$$

- **第一项**：缆 i 踩 `f_min`、缆 j 顶 `f_max` 的"撞车力矩"，共 9 个候选
- **第二项**：`t_floor` 把缆顶过 `f_max` 的力矩，共 3 个候选
- **没有 `t_floor` 时删掉第二项**（或设 `t_floor = −∞`）

**推导见** [张力能力闭式推导_20261122.md](张力能力闭式推导_20261122.md)。

## 3. 三个数值实例（位姿 (0,0)，`f∈[0.2,25]`，`t_floor=1`，`α_cap=1`）

### 例 1：`τ* = (0, −1.5)`（超能力一点）

```
k = 1.5000   d = (0, −1)
u = [16.0005, −2.8315, −3.3550]
b = u/n̂ = [+60.508, −4.760, −4.420]
候选：pair(C2→min, C1→max) = 1.4434  ← 最小
      pair(C3→min, C1→max) = 1.4520
      floor(C1)            = 1.5459
m_max = 1.4434
α = min(1, 1.4434/1.5) = 0.9622
f_τ = α·k·u = [23.094, −4.087, −4.843]
s_lo = 7.2060   t = max(7.206, 1) = 7.2060
f_d = [25.000, 0.200, 0.627]
校验 R·f_d = (0.000000, −1.443361) = α·τ* ✓
```

### 例 2：`τ* = (0.2, −2.0)`（双轴 + 超能力）

```
k = 2.0100   d = (+0.0995, −0.9950)
u = [15.7786, −5.5822, −1.1219]
b = [+59.669, −9.383, −1.478]
候选：pair(C2→min, C1→max) = 1.3643  ← 最小
      pair(C3→min, C1→max) = 1.5418
      floor(C1)            = 1.5677
m_max = 1.3643
α = min(1, 1.3643/2.01) = 0.6787
f_τ = [21.526, −7.616, −1.530]

f_d = [25.000, 0.200, 8.441]
校验 R·f_d = (+0.135748, −1.357480) = 0.6787×(0.2, −2.0) ✓
```

> **这就是"双轴不再误判"的证据**：旧实现会在这里停环，新流程给出 `α=0.6787` 并继续跑。

### 例 3：`τ* = (0, −0.5)`（能力内）

```

α = min(1, 1.4434/0.5) = 1.0000     ← 不缩放
f_τ = k·u = [8.000, −1.416, −1.678]

```

## 4. 失败与降级分支（按优先级）

| # | 条件 | 动作 |
|---|---|---|
| 1 | 未使能 / 未连接 | 停环 |
| 2 | 磁编无数据 | 停环 |
| 3 | 张力样本过期（>300 ms）| **冻结**（保持目标，不更新）|
| 4 | 任一 `f_meas > f_max` | **停环**（过载）|
| 5 | 关节越界（`|roll|>30` 或 `pitch∉[−30,50]`）| 停环 |
| 6 | `n̂` 不可用（钳制后仍失败）| 停环（几何无效）|
| 7 | `m_max ≤ 0`（零力矩都不可行）| 停环（预紧下限太大 / 几何异常）|
| 8 | **`α < α_min`（如 0.2）** | **按策略：拒启 或 只告警继续** |
| 9 | `|t_floor| > min_i c_i` | 停环（预紧下限超过上界）|
| 10 | 单缆测试（只 1 根使能）| ⚠ 本流程不适用（需 3 缆）|

**建议**：`α_min = 0.5`（只做到一半以下就说明"目标填得离谱"→ 拒启）。

## 5. 状态行格式（新增）

```
力矩控  τ*=[+0.200,-2.000] → ατ*=[+0.136,-1.357] → 实测=[+0.135,-1.351]N·m
        α=0.679  m_max=1.364  t=13.14N  f=[25.00/0.20/8.44]N  trim=[-40/-72/-82]c
```

| 字段 | 含义 |
|---|---|
| `τ*` | **你填的**（不钳制、不改写）|
| `ατ*` | **实际目标**（分配器用这个）|
| `实测` | `R·f_meas` |
| `α` / `m_max` | 力矩实现比例 / 该方向能力 |
| `t` | 实际预紧（`↑` 表示被 `s_lo` 抬高、超过了 `t_floor`）|

## 11. 三根绳到底贴着哪条界？（情形 A/B/C）

**结论：不是"永远一顶上限一踩下限"。分三种情形，取决于 `t_floor` 和力矩大小。**

实测（`f∈[0.2,25]`，`t_floor=1`，纯 −pitch）：

| τ* | α | t | f_d [N] | 贴下限 | 贴上限 | 情形 |
|---|---|---|---|---|---|---|
| 0.00 | 1.0000 | 1.00 | [0.26, 0.59, 0.76] | — | — | **A** |
| −0.05 | 1.0000 | 1.00 | [1.06, 0.45, 0.59] | — | — | **A** |
| −0.10 | 1.0000 | 1.00 | [1.86, 0.31, 0.42] | — | — | **A** |
| −0.30 | 1.0000 | 1.76 | [5.27, **0.20**, 0.33] | C2 | — | **B** |
| −0.50 | 1.0000 | 2.72 | [8.72, **0.20**, 0.38] | C2 | — | **B** |
| −1.00 | 1.0000 | 5.10 | [17.35, **0.20**, 0.51] | C2 | — | **B** |
| −1.40 | 1.0000 | 7.00 | [24.25, **0.20**, 0.62] | C2 | （快到） | **B** |
| **−1.50** | **0.9622** | 7.21 | [**25.00**, **0.20**, 0.63] | C2 | **C1** | **C** |
| −3.00 | 0.4811 | 7.21 | [**25.00**, **0.20**, 0.63] | C2 | **C1** | **C** |

| 情形 | 条件 | 谁贴界 | 原因 |
|---|---|---|---|
| **A 都不贴** | `t_floor > s_lo`（力矩很小）| **都不贴** | `t` 由你的下限决定，不是由力矩需求决定 |
| **B 只贴下限** | `t_floor ≤ s_lo` 且 α=1 | **下限贴**，上限富余 | `t` 取"最小可行值" ⟹ 最松那根必等于 `f_min` |
| **C 上下都贴** | 力矩到能力上限（α<1）| **上下都贴** | `m_max` 的定义就是 `L_i` 与 `U_j` 相交 |

**为什么"上限贴、下限富余"不可能**：
`t = max_i L_i`（取最小可行预紧）⟹ 总有一根绳的 `L_i` 最大 ⟹ **它必然等于 `f_min`**。
所以**下限永远被顶住**，除非你用 `t_floor` 把它顶上去（情形 A）。

**`t_floor` 的影响（能力 vs 保底）**

| `t_floor` | 1.4434 方向的能力 | 说明 |
|---|---|---|
| 0 | 1.4434 | 下限永远贴 `f_min` |
| **1** | **1.4434（零影响）** | ✅ 小力矩时变情形 A，能力不变 |
| 3 / 5 | 1.4434（零影响） | 同上 |
| **7.21** | **1.4434（临界）** | = 能力处所需的预紧 |
| 10 | 1.3972（−3.2%） | 开始压低能力 |
| 20 | 1.2319（−14.7%） | 明显压低 |

**门槛规律**：`t_floor ≤ 能力处所需预紧` ⟹ 零影响。
（纯 −pitch 的该值为 **7.21 N**；纯 +pitch 很小，所以 `t_floor=20` 也不影响它。）

**`f_min` 的影响（很小）**

| 方向 | `f_min=0.2` | `f_min=0` | 差 |
|---|---|---|---|
| 纯 +pitch | 0.4956 | 0.5073 | +2.4% |
| 纯 −pitch | 1.4434 | 1.4485 | +0.4% |
| 纯 +roll | 0.4287 | 0.4331 | +1.0% |
| 纯 −roll | 0.5491 | 0.5526 | +0.6% |

**⟹ `f_min` 的职责是"防松绳"，不是"限能力"；想省预紧应该调 `t_floor`，不是调 `f_min`。**
