# 张力分配：闭式解（2026-11-20）

> **一句话**：3 根缆、2 个力矩方程 ⟹ 可行解是**一条线段** `f(s) = f_τ + s·n̂`。
> **整个"如何分配张力"只需要定 1 个标量 `s`（就是预紧 `t`）。**
> 而且有闭式解：**`s = max(s_lo, t_user)`，`α ≡ 1`（力矩精确实现）。**
> 不用 QP，不用求解器，8 行代码。

---

## 1. 问题

给定：

| 输入 | 符号 | 来源 |
|---|---|---|
| 期望力矩 | `τ* = (τ_roll, τ_pitch)` | 界面 |
| 每缆上下限 | `f_min, f_max` | 界面 |
| 期望预紧下限 | `t_user` | 界面（`preload`）|
| 几何 | `R(q)`, `n̂(q)` | 模型（位姿已钳进可行域）|

求：三缆张力 `f = (f1, f2, f3)` 使 `R·f = τ*` 且 `f_min ≤ f_i ≤ f_max`。

---

## 2. 解集是一条线段

构造 `P = [R; n̂ᵀ]`（3×3），`P⁻¹` 的**第三列恰好是 `n̂`**（可证：`P·n̂ = [0;0;1]`）。

$$
f = P^{-1}\begin{bmatrix}\tau\\0\end{bmatrix} + s\cdot\hat n
  = \underbrace{f_\tau}_{\text{零预紧解}} + \underbrace{s\cdot\hat n}_{\text{零空间}}
$$

- `f_τ` 满足 `R·f_τ = τ`、`n̂·f_τ = 0`（**与 n̂ 正交**）
- `s` 取任意实数都满足 `R·f = τ`（因为 `R·n̂ = 0`）
- **所以 s 是唯一的自由度，也就是预紧 `t`**（`‖n̂‖=1`）

---

## 3. s 的可行区间（就是你记得的那个公式）

对每根缆 `f_min ≤ f_τ,i + s·n̂_i ≤ f_max`，因 `n̂_i > 0`：

$$
s \in \left[\ \max_i \frac{f_{\min}-f_{\tau,i}}{\hat n_i},\ \ \min_i \frac{f_{\max}-f_{\tau,i}}{\hat n_i}\ \right] = [s_{lo}, s_{hi}]
$$

- `s_lo > s_hi` ⟹ **该力矩在本位姿、本界限下不可行**（应明确拒绝/钳制 τ，而不是静默降额）
- `s_lo` 的物理含义：**"这个力矩最少需要多少预紧"**

---

## 4. 选哪个 s：三种策略

| 策略 | 取 s | 效果 | 适用 |
|---|---|---|---|
| **① 固定预紧**（现状） | `s = t_user`，若越界就缩 τ（α）| 预紧/刚度固定，**力矩打折** | 要固定刚度 |
| **② 力矩优先**（推荐）| `s = max(s_lo, t_user)` | **力矩精确**，预紧按需抬到最小值 | 要精确出力矩 |
| **③ 最小张力** | `s = s_lo` | 张力最省、伸长最小 | t_user=0 时的 ② |

### 一个关键结论：**最小范数解就是 `s_lo`**

`min ‖f‖²` 的解析解是 `s* = −f_τ·n̂`，而 **`f_τ` 与 `n̂` 严格正交** ⟹ `s* ≡ 0`。
`0 < s_lo` 恒成立（力封闭需要正预紧）⟹ **最优解永远落在下界 `s_lo` 上**。

> 所以"`min ‖f‖²` 的 QP"在这个问题上**不需要求解器** —— 答案就是 `s_lo`。

---

**读法**：
- τ ≤ 0.3 时，`t_user=2 N` 就够 → 预紧取 2，力矩精确
- τ 增大 → `s_lo` 自动抬升（预紧跟着涨，为保证所有缆 ≥ f_min）
- τ = 1.5 时 `s_lo > s_hi` → **该位姿做不到 1.5 N·m**（能力上限 ~1.43）

## 6. 实现（8 行，替换现有 `tda_solve`

```python
def allocate(R, nhat, tau_r, tau_p, f_min, f_max, t_user):
    """返回 (f[3] | None, s_used, 是否被预紧下限抬升)。None = 该力矩不可行。"""
    P = [[R[0][0], R[0][1], R[0][2]],
         [R[1][0], R[1][1], R[1][2]],
         [nhat[0], nhat[1], nhat[2]]]
    P_inv = inv3(P)
    if P_inv is None:
        return None, 0.0, False
    f_tau = mat_vec(P_inv, [tau_r, tau_p, 0.0])

    s_lo = max((f_min - f_tau[i]) / nhat[i] for i in range(3))
    s_hi = min((f_max - f_tau[i]) / nhat[i] for i in range(3))
    if s_lo > s_hi:                      # 该 tau 不可行 → 由调用方钳制或拒绝
        return None, s_lo, False

    s = max(s_lo, t_user)
    raised = s > t_user
    s = min(s, s_hi)
    return [f_tau[i] + s * nhat[i] for i in range(3)], s, raised
```

**与现有实现的差别**：

| 项 | 现在（`α·f_τ + t·n̂`）| 新（`f_τ + s·n̂`）|
|---|---|---|
| `t` | 固定 = 用户值 | **`max(s_lo, 用户值)`**，按需自动抬 |
| `α` | 可能 <1（力矩打折）| **恒 = 1**（力矩精确）|
| 不可行 | 静默降额 | **返回 None**（调用方决定钳制或拒绝）|
| 最优性 | 启发式 | **等价于 `min‖f‖²` 的解析解**（见 §4）|

---

## 7. 调用方要做的三个决定

| 情况 | 建议 |
|---|---|
| `s_lo ≤ s_hi` | 直接下发，状态行显示 `s`（预紧实际用了多少）|
| `s_lo > s_hi`（力矩超能力）| **钳制 τ 到能力边界** + 状态行报"目标 X 被钳到 Y（能力）"；或按配置**拒绝启动** |
| `s > t_user`（预紧被自动抬）| 状态行提示"预紧 2→4.1 N（为满足力矩）" |

**能力边界怎么算**：对当前位姿做一次二分（§5 的做法）或解析求 `s_lo(τ) = s_hi(τ)` 的根。

## 8. 为什么这比 QP 更适合你

| | QP（**其它领域**常用；**R2 论文不用**，见附录 C）| 本闭式解 |
|---|---|---|
| 需要求解器 | 是（或手写迭代）| **否**（8 行）|
| 最优性 | 全局最优 | **等价**（因为 `s* = s_lo`，见 §4）|
| 可解释性 | 黑箱 | **s = 预紧，物理意义明确**|
| 实时性 | 需保证收敛 | **O(1)** |
| 适用条件 | 一般 | **2 方程/3 缆/1 自由度的腱驱动腕**（正是你的情况）|

---

## 9. 一句话

> **3 缆 2 方程 ⟹ 分配只需定一个标量：预紧 `s`。**
> **`s_lo = max_i (f_min − f_τ,i)/n̂_i` 就是"这个力矩最少要多少预紧"。**
> **取 `s = max(s_lo, t_user)` ⟹ α 恒 1、力矩精确、张力最省。**
> **`s_lo > s_hi` ⟹ 该力矩做不到，应明确拒绝而不是静默打折。**

# 附录 A：QP 是什么，为什么这里不用它

> ⚠ **本节是"通用科普"，与 R2 论文无关。**
> 实测（对论文全文做字符串统计）：**`QP` 出现 0 次**，`二次规划`/`quadratic` 也是 **0 次**；
> 论文只用 **LP**（`线性规划` 7 次、`LP` 9 次、`单纯形` 16 次），
> 且单纯形法只是附录 B 的**对照组**，主方法是**算法 2**（见附录 C）。
> 本节保留只为说明"为什么本机不需要求解器"，**不代表论文做法**。

## A.1 定义

**QP = Quadratic Programming（二次规划）**：**目标二次、约束线性**的凸优化。

$$
\min_x\ \tfrac12 x^{\mathsf T}Qx + c^{\mathsf T}x
\quad\text{s.t.}\quad
A_{eq}x=b_{eq},\ \ Ax\le b,\ \ l\le x\le u
$$

- `Q` 半正定 ⟹ **凸** ⟹ **唯一全局最优**
- `Q = 0` → 退化成 **LP（线性规划）**；无约束 → **最小二乘**

## A.2 张力分配就是一个 QP

```python
x = f                       # 三缆张力
min  ½‖f‖²                  # Q = 2I, c = 0（张力平方和最小 = 弹性能最省）
s.t. R·f = τ                # 2 个等式
     f_min ≤ f_i ≤ f_max    # 6 个界约束
```

## A.3 几何图像

| 对象 | 3 维空间里的形状 |
|---|---|
| `R·f = τ`（2 方程）| **一条直线**（剩 1 维 = 零空间 n̂）|
| `f_min ≤ f ≤ f_max` | **一个长方体盒子** |
| `min‖f‖²` 等高线 | 以原点为心的**球面族** |

**QP 做的事 = 在"直线 ∩ 盒子"这条线段上，找离原点最近的点。**

## A.4 用实测数看（τ = −0.3 N·m，f ∈ [0.2, 25]）

`f(s) = f_τ + s·n̂`，`f_τ = [4.80, −0.85, −1.01]`，`n̂ = [0.264, 0.595, 0.759]`

| s | f1 | f2 | f3 | ‖f‖² | 可行 |
|---|---|---|---|---|---|
| **0.000** | 4.80 | −0.85 | −1.01 | **24.78** | ✗ ← 无约束最优（但 C2/C3 为负）|
| 1.000 | 5.07 | −0.26 | −0.25 | 25.78 | ✗ |
| **1.764** | 5.27 | **0.200** | 0.33 | **27.89** | **边界** ← 约束最优 |
| 2.000 | 5.33 | 0.34 | 0.51 | 28.78 | ✓ |
| 3.000 | 5.59 | 0.94 | 1.27 | 33.78 | ✓ |

**结论**：
1. 目标函数沿这条线是**抛物线**（对 s 二次）
2. 抛物线最低点在 `s = 0`，但那里 **f2/f3 为负（物理不可能）**
3. 加上界约束后，最低可行点被推到 **`s = 1.764`** —— 正好让 C2 压在 `f_min` 上
4. 这个"贴在边界上"就是 **active constraint（有效约束）** 的含义

## A.5 为什么这里不需要 QP

- 可行集是**线段**（1 维），线段上离原点最近的点**必是端点**
- 端点有闭式公式：`s_lo = max_i (f_min − f_τ,i)/n̂_i`
- ⟹ "优化"退化成"取端点"，**QP 的解析解就是 s_lo**
- 数值验证（4001 点扫描）：`s_QP` 与 `s_闭式` 差 **0.0000**

**必须真 QP 的场合**：

| 情况 | 原因 |
|---|---|
| 缆数 ≥ 4 | 零空间 ≥ 2 维 → 可行集是多边形 → 最优点可能在**内部** |
| 目标换成"最大化最小余量" | 最优点在区间内部 |
| 加张力变化率限制 | 前后帧耦合 → 多步规划 |
| 加非线性约束（摩擦/回差）| 连 QP 都不够，要 NLP |

## A.6 QP 在机器人里的五个典型用途

| # | 用途 | 说明 |
|---|---|---|
| 1 | **冗余驱动/张力分配** | 本例 |
| 2 | **全身控制（WBC）** | 任务优先级 + 力矩分配，QP 是标准工具 |
| 3 | **逆运动学** | `min‖q̇‖² s.t. J·q̇ = ẋ` |
| 4 | **MPC** | 每个控制周期解一个 QP |
| 5 | **多接触点力分配** | 摩擦锥 = 线性约束 |

## A.7 解法与库

| 方法 | 适用 | 特点 |
|---|---|---|
| **闭式解** | 零空间 1 维（本例）| O(1)，无迭代，最可靠 |
| **Active Set** | 小规模（<50 变量）| 精确 |
| **Interior Point** | 大规模 | 快，迭代次数不定 |

常见库：`OSQP`、`qpOASES`（实时）、`quadprog`、`scipy.optimize.minimize(SLSQP)`

## A.8 QP 的四个坑

| 坑 | 后果 |
|---|---|
| **不可行** | 求解器失败 → 仍要写钳制/拒绝逻辑 |
| **迭代时间不定** | 100 Hz 硬实时下抖动 |
| **数值非确定性** | 不同版本/初值结果有微小差异 |
| **权重难定** | `min‖f‖²` 均匀分配 vs `minΣf` 集中分配，影响发热与蠕变 |

## A.9 文献用不用 QP？—— 分规模看，不能说"都用 QP"

> **先说 R2 论文（本机参照的那篇）**：**没有 QP**。它用 **算法 2**（自研迭代，主方法）
> 和 **附录 B 的单纯形法（LP，对照组）**。下面这张表是**其它领域**的一般情况，
> **不是 R2 论文**，写论文时请勿混用。

| 问题规模 | 文献主流做法 | 备注 |
|---|---|---|
| **2~3 自由度、3~4 缆**（本例）| **解析/几何法**、最小范数伪逆、闭式区间 | 零空间 ≤1 维，**不需要 QP** |
| **多缆冗余（≥4 缆 / ≥3 轴）** | **LP**（最小总张力）或 **QP**（最小二乘张力）| 最经典的两类 |

| **要最优刚度/鲁棒余量** | **NLP / 迭代** | 目标非线性 |

# 附录 C：论文原文（R2，IJRR 2013）到底怎么做

**论文**：M. E. Abdallah, R. Platt Jr., C. W. Wampler,
*"Decoupled torque control of tendon-driven fingers with tension management"*,
IJRR 32(2):247–258, 2013。（精读材料：
`Robonaut2灵巧手_论文专利精读与译文（含附录A-B）.pdf`）

**系统**：3 关节 / **4 腱**（零空间 1 维，与本文 3 缆 2 轴同构）。

## C.1 论文的分配 = **两阶段 LP（Problem 1）**

```
最大化 α
约束  R f = α τ*,  0 ≤ α ≤ 1,  f_min ≤ f ≤ f_max
若 α = 1 则
      最小化 t = W f
      约束  R f = τ*,  f_min ≤ f ≤ f_max
```

**目标顺序：先保力矩（α 尽量大），再省张力（t 尽量小）。**

## C.2 算法 2（原文伪代码，7 行）

```
1  α = 1;  t = max_i (f_min − v_i)/w_i
2  f = α·v + t·w
3  while f > f_max 或 f < f_min:
4     h = argmax_i f_i;  ℓ = argmin_i f_i
5     解 v_h·α + w_h·t = f_max
        v_ℓ·α + w_ℓ·t = f_min
6     f = α·v + t·w
7  end
```

- `v = R⁺τ*`（伪逆，零预紧解）；`w = Wᵀ`（零空间方向）
- 第 5 行是 2×2 联立：**同时**让最紧的顶到 `f_max`、最松的踩到 `f_min`，一次解出 (α, t)
- 有限终止性有证明（α 严格递减 + (h,ℓ) 组合有限）；实测 **3 轮内收敛**，故迭代上限取 3
- 可行点存在的条件（式 15）：`f_max/f_min ≥ max_{i,j}(w_i/w_j)`
  —— 本机 25/0.2 = 125 ≫ 0.759/0.264 = 2.87 ✓ 满足

## C.3 附录 B 的单纯形法 = **对照，不是主方法**

论文附录 B 把同一问题写成标准 LP 用单纯形法求解，结论：
**两者迭代次数相当，但算法 2 快约 4 倍**（不需要转标准形）。**论文没有用 QP。**

| 论文 | 本文 | 数值验证 |
|---|---|---|
| `v = R⁺τ*` | `f_τ = P⁻¹[τ;0]` | **逐位相同**（`[4.800142, −0.849460, −1.006505]`）|
| `w = Wᵀ` | `n̂` | 同 |
| `t`（内部张力）| `s` | 同 |
| 算法 2 第 1 步 `t = max_i(f_min−v_i)/w_i` | `s_lo` | **同式**（f_min=0.2 → 1.7641）|

## C.5 本文实现 vs 论文

| 项 | 论文 | 本文现状 |
|---|---|---|
| 第 1 步（α=1, t=s_lo）| ✅ | ✅ **已实现**（`allocate_torque_priority`）|
| 越界后迭代解 (α, t) | ✅ **算法 2 第 3–7 行** | ❌ **未实现**（直接返回 None，靠外部钳制 τ）|
| `t_floor`（用户预紧下限）| 无此概念（`f_min` 承担）| ✅ 本文新增 |
| QP | ❌ 没用 | ❌ 没用 ✓ 一致 |

**结论**：本文的闭式解 = 论文算法 2 的**第一步**；
**要完全对齐论文，只需补第 3–7 行**（越界时迭代解 (α,t)，输出 α 与 f，而不是返回 None）。
