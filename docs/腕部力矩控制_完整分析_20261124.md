# 1. 你的系统：硬件事实

| 项 | 事实 | 影响 |
|---|---|---|
| 自由度 / 缆数 | 2 轴（roll, pitch）/ 3 缆 | `n+1` 布局，冗余 1 维 |
| 执行器 | 飞特舵机，**位置指令型**（`0xD3`，内部已闭位置环） | 你的 `u` 是 counts，不是电压；`G(s)≈1` |
| 张力传感器 | ZNSV 6-F8，装在**电机侧** | 关节侧摩擦看不见 |
| 力矩传感器 | **没有** | `τ` 只能用 `R·f` 重构 |
| 编码器 | J16/J17 磁编 | 给出位姿 `q`，决定 `R` 和 `n̂` |

## 三个关键矩阵（θ = 0°/0°）

$$
R=\begin{bmatrix}-0.000259&-0.022050&+0.017372\\-0.058105&+0.011805&+0.010990\end{bmatrix}\ \text{(m)}
\qquad
\hat n=[0.2644,\,0.5949,\,0.7590]
$$

$$
P=\begin{bmatrix}R\\ \hat n^{\mathsf T}\end{bmatrix}\in\mathbb{R}^{3\times3},
\qquad
P^{-1}=\begin{bmatrix}-1.4314&-16.0006&0.2645\\-27.7848&2.8313&0.5949\\22.2762&3.3547&0.7591\end{bmatrix}
$$

**`P⁻¹` 怎么读**：第 1 列 = 「1 N·m 的 roll 需要三根绳各出多少 N」，第 3 列 = `n̂` = 「只加预紧、不产生力矩」。

**最重要的恒等式**：

$$
R\,P^{-1}=[\,I_2\ \ 0\,],\qquad \hat n^{\mathsf T}P^{-1}=[\,0\ \ 0\ \ 1\,]
$$

# 2. 一拍里发生什么（完整信号链）

```
你填 τ*  ──①TDA──►  f_d  ──②张力PI──►  u(counts)  ──③舵机──►  x  ──④弹性──►  f  ──►  τ
                        ▲                                                        │
                        └──────────────── ⑤ 读 f，算误差 ◄──────────────────────────┘
```

| 步 | 公式 | 代码 | 单位 |
|---|---|---|---|
| ① 分配 | `f_d = P⁻¹[ατ*; t]` | `wrist_tda.allocation_step` | N |
| ② 张力 PI | `e_i = f_{d,i} − f_i`；`step_i = clamp(k_p e_i + k_i I_i, ±max_step)` | `wrist_force_law._incr_step` | counts/拍 |
| ③ 下发 | `target_i = 实测_i + trim_sign_i·step_i` | `_apply_force_step` → `0xD3` | counts |
| ④ 弹性 | `f = k_t(x − Rᵀ q)` | 物理 | N |
| ⑤ 反馈 | 直接读 `f` | ZNSV 250 Hz | N |

**注意 ①里的 `α` 和 `t`**：
- `α ∈ (0,1]` 是**力矩打折系数**——目标超出能力时自动缩小，保证解存在；
- `t` 是**内部预紧**——不改变力矩，只改变三根绳整体绷多紧。

# 3. 力矩误差的完整分解（核心）

## 3.1 解析式

控制器算出的目标张力是

$$
f_d = P_m^{-1}\begin{bmatrix}\alpha\tau^*\\ t\end{bmatrix} = \alpha\,u_m + t\,\hat n_m,
\qquad u_m := P_m^{-1}\begin{bmatrix}\tau^*\\0\end{bmatrix}
$$

而真实力矩由真实几何决定：

$$
\boxed{\ \tau_{\text{true}} = R_t\,f_d = \alpha\underbrace{(R_t u_m)}_{\text{比例项}} + t\underbrace{(R_t \hat n_m)}_{\text{寄生项}}\ }
$$

若 `R_t = R_m`，则 `R_m u_m = τ*`、`R_m n̂_m = 0`，于是 `τ_true = α τ*`（干净）。

**误差就是这两项被破坏的结果。**

## 3.2 两类误差，性质完全不同

### A 类：比例误差（力矩按比例缩水）

来源：`α < 1`（目标不可达）、或 `R` 整体缩放。

$$
\tau_{\text{true}} = \alpha \cdot k_R \cdot \tau^*
$$

本机实测（`τ* = (0.1, 0.2)`）：

| 位姿（模型角） | `min n̂` | **α** | 实际能得到 |
|---|---|---|---|
| (0°, 0°) | 0.264 | **1.000** | (0.100, 0.200) ✓ |
| (+8°, +9.5°) | 0.202 | 1.000 | (0.100, 0.200) ✓ |
| (+11°, +9.5°) | 0.186 | 1.000 | (0.100, 0.200) ✓ |
| **(+13.9°, +9.5°)** | **0.052** | **0.349** | **(0.035, 0.070)** ✗ |

> **界面上显示的「实测 τ」会等于 `ατ*`，不是 `τ*`。**
> 你看到的"误差很大"，这一半就是 α 打折——**系统已经告诉你"做不到"，只是你可能没读那一行**。

### B 类：结构误差（预紧变成寄生力矩）

只有当 `R_t n̂_m ≠ 0` 时出现。**单根绳的力臂错了就会破坏它**：

| 模型误差 | `R_t n̂` | `t = 10 N` 时的寄生力矩 |
|---|---|---|
| 无 | 0 | 0 |
| 整体放大 5% | 0 | 0（只缩放，不寄生） |
| **只 C2 力臂 +10%** | (0.00131, −0.0007) | **(−0.0131, +0.0070) N·m** |
| pitch 行整体 +10% | 0 | 0 |

> ⚠️ **这意味着：`R` 有单缆误差时，把 `f_min` / `preload`（= `t`）抬高，会同时抬高寄生力矩。**
> 所以"提高预紧"不是无脑收益——先确认 `R` 的单缆力臂准。

## 3.3 还有一个不可见的误差：导管摩擦

传感器在**电机侧**。即使 `f_电机侧 = f_d` 完全到位，关节侧张力可能差一截（绳在导管里摩擦/迟滞）。

$$
\tau_{\text{关节侧}} = R\,f_{\text{关节侧}} \ne R\,f_{\text{电机侧}}
$$

**这部分在 `R·f` 反馈里完全不存在。** 加任何基于 `R·f` 的环都看不见它。

# 4. 哪些误差能被闭环修掉？

| 误差源 | 腱空间纯 P | **腱空间 + 积分** | 关节空间闭环 | 真·力矩传感器闭环 |
|---|---|---|---|---|
| f 动态没跟上 f_d | ❌ | ✅ | ✅ | ✅ |
| 张力环饱和 / 行程限位 | ❌ | ⚠️ 部分 | ⚠️ 部分 | ✅ |
| **α < 1（目标不可达）** | ❌ | ❌ | ❌ | ❌ |
| **R 误差（比例）** | ❌ | ❌ | ❌ | ✅ |
| **R 误差（单缆 → 寄生）** | ❌ | ❌ | ❌ | ✅ |
| **导管摩擦** | ❌ | ❌ | ❌ | ✅ |
| 响应快慢 / 轴间串扰 | ❌ | ❌ | ✅ | ✅ |

## 为什么 `R` 误差对任何 `R·f` 反馈都是"失明"的

设真实几何比模型大 5%，张力环完美（`f = f_d`）：

```
控制器算： τ_meas = R_model · f_d = (0.100, 0)   ← 和 τ* 误差 = 0
真实力矩： τ_true = R_true  · f_d = (0.105, 0)   ← 和 τ* 误差 = 5%
```

**环路看到的误差永远是 0，真实误差 5%。** 这是代数恒等式，不是调参问题。

# 5. 为什么「关节空间」帮不上你（最终结论）

## 5.1 你的执行器没有论文那层动态

论文的执行器是 **电压 `u` → 电机 + 减速器 + 丝杠 `G(s)`**（二阶）。他们声称的解耦，对付的是 `G(s)` 这层动力学带来的 `(RRᵀ)` 滤波。

**你的舵机内部已经闭了位置环** —— 那一层被固件吃掉了。你看到的是「给多少 counts，绳走多少」，静态线性。

## 5.2 在你的架构里，腱空间**本来就是解耦的**

静态增量关系：`Δf = S·Δu`，`Δτ = R·Δf = S·R·Δu`。
腱空间控制器追溯回增广误差就是 `u = K_p P⁻¹ e`，代入：

$$
\Delta\tau = S\,K_p\,\underbrace{R P^{-1}}_{=\,[I_2\ 0]}\,e = S\,K_p\,e_\tau
$$

**`Δτ_roll` 只响应 `e_roll`，`Δτ_pitch` 只响应 `e_pitch`。完全解耦。**

数值对比（同一误差 `e = (0.01, 0, 0)`，`S = 0.0061 N/count/拍`）：

| 映射 | `Δτ_roll` | `Δτ_pitch`（应为 0） | 判定 |
|---|---|---|---|
| **`P⁻¹`（腱空间）** | **6.1e−5** | **0** | ✅ 满幅、干净 |
| `P⁻ᵀ`（关节空间写法） | 2.2e−5 | −6.3e−6 | ❌ 只有 36%，还串轴 |

## 5.3 结论

> **不要实现关节空间模式。**
> ① 你的架构下它的核心优势（消 `G(s)` 带来的耦合）不存在；
> ② 它的代价（失去逐缆诊断、必须重新整定 `k_pi`）正好戳在你当前的痛点上；
> ③ 你要的"稳定力矩"，腱空间 + 修好那三个设置就能给。

# 7. `max_step` 到底是什么：领先量 → 力矩权限

因为力控输出是增量式 `target = 实测 + step`，伺服只看到 `step` 这么大的位置误差。固件实测：

$$
K_{\text{servo}} = \frac{267\ \text{c/s}}{20\ \text{c}} = 13.35\ \text{/s}
\quad\Longrightarrow\quad \text{每拍走 } 0.1335\times \text{step counts}
$$

所以 **每拍实际张力变化 = 0.0061 × step [N]**（不是 0.046 × step）。

# 11. 速度阻尼（D 项）—— 「又快又稳」的唯一手段

> 2026-11-24 实现：界面 **`Kd_f`** 框（力控四个模式共用，默认 **0 = 关闭**）。

## 11.1 为什么单靠 Kp 调不出「又快又稳」

舵机对「位置领先量」的速度响应有 **≈75 ms** 滞后（固件实测「领先 20c ≈ 267 c/s」
→ `K = 13.35 /s`）。于是张力闭环是**二阶**：

$$
\omega_n = K\sqrt{S\,k_p},\qquad \zeta=\frac{1}{2\sqrt{S\,k_p}}
$$

`Kp` 同时决定「快」和「阻尼」，所以只调它是二选一：

| `Kp_f` | ζ | 稳定时间 | 过冲 |
|---|---|---|---|
| **15（旧默认）** | 0.60 | 0.44 s | 8% |
| 25 | 0.47 | 0.35 s | 18% |
| 40 | 0.37 | 0.42 s | 25% |
| 60 | 0.30 | 0.37 s | 27% |

**Kp 从 15 提到 60：稳定时间只降 16%，过冲涨到 27%。收益到此为止。**

## 11.2 加 D 之后

$$
kd = \frac{2\zeta\,T_A K\sqrt{S\,k_p}-1}{K},\qquad \text{取 }\zeta\approx0.7
$$

| `Kp_f` | `Kd_f` | ζ | 稳定时间 | 过冲 |
|---|---|---|---|---|
| 15 | 0 | 0.60 | 0.44 s | 8% |
| **15** | **0.02** | 0.76 | **0.28 s** | **2%** |
| **25** | **0.04** | ~0.7 | **0.22 s** | **1%** |
| **40** | **0.07** | 0.71 | **0.17 s** | **2%** |
| 60 | 0.10 | 0.70 | 0.18 s | 1% |

**快 2.4 倍、过冲小 4 倍，两个指标同时改善。**

## 11.3 实现要点（防坑）

| 项 | 做法 | 为什么 |
|---|---|---|
| 原料 | 舵机 `Present Speed`（`m*_speed`，100 Hz） | 比编码器差分干净；也是论文 `k_d ẋ` 的做法 |
| **符号** | 先乘 `SERVO_SPEED_SIGN`（**默认 (1,1,1)**）翻到「位置增大方向」，再乘 `trim_sign` 翻到「张力增大方向」 | 若某台舵机装反（点动 +counts 时读负），把该元素改 −1；**逐缆**给值。符号错了会变成正反馈放大 |
| 位置 | D **减在限幅之前**（标准 PID） | 限幅前减才能真正"刹车"；反号（`+kd·v`）在 `kd>1/K≈0.075 s` 时闭环时间常数变负 → 发散 |
| 单位 | `SERVO_SPEED_UNIT_TO_COUNTS_PER_S`（默认 1.0） | 飞特 STS 多为 steps/s；0.1rpm 型号改 6.83 |
| 硬限幅 | `\|kd·v\| ≤ 0.8×max_step`（`D_TERM_MAX_FRAC`） | **单位/符号猜错也不会把输出顶反** |
| 滤波 | 速度 EMA，τ≈30 ms | 压单帧跳变 |
| 缺数据 | `speed_n=None` → 自动不启用 D | fail-safe，行为与旧版逐位一致 |
