# 张力环逐缆调参 · 正弦跟随测试 · 张力目标曲线（2026-11-24）

> 本文覆盖三件同一天加的东西：**逐缆增益**、**正弦跟随测试**、**目标/实测同图曲线**，
> 并给出一套根据模型与历史数据推出来的推荐参数。
> 记号：`f` 张力 [N]，`S` 张力-计数换算 [N/count]，`Kp/Ki` 增量 PI 增益。

---

# 1. 为什么需要逐缆

三根绳的**摩擦、绳长、导管弯折、预紧、绳径公差**都不同，
一套增益不可能同时最优。现场症状就是这个的典型证据：

| 缆 | 现象 | 说明 |
|---|---|---|
| C1 | 在 1.2~6.8 N 之间大幅摆动 | 摩擦小 ⇒ 同样 `Kp` 就**过快**（过冲/极限环） |
| C2 | 目标 3 N 时长期停在 0.3 N | 摩擦大 / 绳松 / 符号反 / 传感器 ⇒ **迟钝或无效** |
| C3 | 0.00 N | 该缆**未使能**（`cable_enable` 里 M29=false） |

**逐缆调参解决"一根过冲一根迟钝"；解决不了"完全收不上来"**（那是硬件/符号问题）。

# 2. 逐缆参数怎么填

**同一个框支持 1 个或 3 个数**（不新增输入框，布局不用改）：

| 填法 | 解析结果 |
|---|---|
| `15` | `[15, 15, 15]` —— 三缆共用（**旧行为，逐位兼容**）|
| `15,15,8` | `[15, 15, 8]` —— C1=15, C2=15, **C3=8** |
| `1, 2 ，3` | 空格、中文逗号、全角逗号都认 |

**支持逐缆的 4 个框**：

| 框 | 物理含义 | 单位 |
|---|---|---|
| `Kp_f` | `1 N` 误差 → 走多少 counts/拍 | counts/N |
| `Ki_f` | 积分速率；`Ti = Kp/Ki` 是积分时间 | counts/(N·s) |
| `积分上限` | 积分**输出**上限 `c`；能补的最大稳态差 `= c/Kp` | counts |
| `每拍限幅` | 每拍最大步长；命令速率 `= 本值 × 100 Hz` | counts/拍 |

**另外 `trim方向`（`1,1,1`）本来就是逐缆的**（`+1` = counts 增 ⇒ 张力增）。

## 2.1 填错的处理：**拒绝开环**

| 填法 | 结果 |
|---|---|
| `15,8`（2 个）| ❌ 拒绝，状态行报"参数非法" |
| `15,abc,8` | ❌ 拒绝 |
| `15,-1,8` | ❌ 拒绝（负） |
| `15,15,1e9` | ❌ 拒绝（超上限） |

设计原则：**宁可不开环，也不静默用错的增益去驱动电机。**

## 2.2 生效范围

| 模式 | 逐缆生效 |
|---|---|
| 张力控制 | ✅ |
| 力矩控制（内环追 `f_d`）| ✅ 同一内环 |
| 张紧控制 | ✅ 走张力环 |
| 阻抗 | ✅ 走力矩内环 |

# 3. 增益与极点：怎么算出来的

## 3.1 被控对象

$$
f_{k+1} = f_k + S\,\Delta n_k,\qquad S \approx 0.046\ \text{N/count}
$$

`S = K_rope / (counts per unit rope)`；本机 `K_rope ≈ 5.5 N/mm`、约 `118.5 counts/mm`
⟹ `S ≈ 0.046 N/count`。

## 3.2 只有 P 时

$$
e_{k+1} = (1 - S\,K_p)\,e_k
\quad\Longrightarrow\quad
p = 1 - S\,K_p
$$

| `Kp` | `S·Kp` | 极点 | 每拍残余 | 评价 |
|---|---|---|---|---|
| 8 | 0.37 | 0.63 | 63% | 偏慢、很稳 |
| **10** | **0.46** | **0.54** | **54%** | **推荐**（≈22 ms 时间常数）|
| 15 | 0.69 | 0.31 | 31% | 快，但对延时敏感 |
| 22 | 1.00 | 0.00 | 0% | 一拍到位（deadbeat，不能有延时）|
| >22 | >1 | 负 | — | 振荡 |

**实际还有约 26 ms 延时**（张力样本 16 ms + 一拍），所以 `S·Kp` 应留在 `0.4~0.6`
⟹ **`Kp ≈ 9~13`，取 10。**

## 3.3 积分

$$
T_i = \frac{K_p}{K_i}
$$

- `Ti` 太短（< 0.15 s）→ 与 26 ms 延时打架，抖
- `Ti` 太长（> 1 s）→ 反向回不来、斜坡跟随有滞后
- 推荐 `Ti ≈ 0.4 s` ⟹ `Ki = Kp/Ti = 10/0.4 = 25`

## 3.4 积分上限要**压得住摩擦**

稳态 `u→0` 时 `Kp·e = -K_i I`，故积分能补的最大稳态差：

$$
\boxed{\ |e|_{\max} = \frac{c}{K_p}\ }
$$

| 摩擦 | 需要 `c ≥ Kp·f_fric`（`Kp=10`）|
|---|---|
| 1 N | 10 |
| 2 N | 20 |
| 3 N | 30 |
| 4 N | **40** |

**历史教训**：`c=20, Kp=15` → 只能补 `20/15 = 1.33 N`。
仿真（库仑摩擦 2 N）显示 `c=20` 时**反向永远回不到目标**（停在 3.47 N 而目标是 2 N）；
`c=40` 才收敛到 2.19，`c=60` 精确到 2.00。
⟹ **`c` 至少 40。**

## 3.5 每拍限幅是**领先量**，不是速度上限（2026-11-24 修正）

输出是增量式 `target = 实测 + step`，实测每拍刷新 ⟹ 舵机看到的**位置误差恒等于 `step`**。
舵机内部按误差给速度（实测标定 `K_servo ≈ 13.35 /s`）：

$$
v \approx 13.35\times \texttt{max\_step}\ \ [\text{c/s}],
\qquad
v_{\max}=3400 \Rightarrow \texttt{max\_step}_{\text{饱和}} \approx \frac{3400}{13.35}\approx 255
$$

| `max_step` | 舵机速度 | 张力斜率 `≈0.61×step` |
|---|---|---|
| **34** | **454 c/s**（只有 13%）| 20.9 N/s |
| 120 | **1600 c/s** | 74 N/s |
| 255 | **3400 c/s**（打满）| 156 N/s |

**⟹ 要舵机跑满 3400，`max_step` 要给到「比较大的值」（≈255），给 34 只有 454 c/s。**
**代价是过冲 `≈ ḟ·26 ms`（延时 16 ms 采样 + 10 ms 一拍）**：

| `max_step` | 过冲估计 |
|---|---|
| 25 | 0.40 N |
| 34 | 0.54 N |
| 120 | 1.9 N |
| 200 | 3.2 N |

**所以它是"快 ↔ 过冲"的单旋钮；压过冲要靠 `Kp`/延时/速度前馈，不是靠把 `max_step` 压小。**

> ⚠ 更正：此前本文件写的"`max_step × 频率 ≤ 3400` ⟹ 最大 34"是**错的** —— 那是把
> 领先量当速度。详见 [`每拍限幅_领先量与舵机速度_20261124.md`](每拍限幅_领先量与舵机速度_20261124.md)。

# 4. 正弦跟随测试

## 4.1 目标

$$
f_{\text{target},i}(t)=\operatorname{clamp}\Big(\text{基值}_i+\text{sign}_i\,A\,\sin(2\pi f t+\varphi),\ f_{\min},\ f_{\max}-1\Big)
$$

| 框 | 含义 | 建议 |
|---|---|---|
| 基值（三个 `C目标N`）| 直流分量 | 3/3/3 |
| `幅度N` | `A` | 1.0 |
| `频率Hz` | `f` | 0.2 → 0.5 → 1 → 2 |
| `相位°` | `φ` | 0 |
| `符号` | `1,1,1` 共模；`1,-1,-1` 差动 | 先共模 |
| ☐ `正弦跟随` | 勾上才生效 | — |

**关键设计**：
- `t` 从**勾上那一刻**算起 ⟹ `sin(0)=0` ⟹ **起点严格等于基值，没有阶跃**
  （阶跃会把饱和/非线性混进辨识结果）
- 幅度过大 **削顶**而不撞界（过载闸门留给真故障）

## 4.2 数据自动落盘

`run_data/sine/sine_YYYYmmdd_HHMMSS.csv`，100 Hz：

```
# 幅度A=1N 频率f=0.2Hz 相位=0deg 符号=1,1,1 基值=[3.0,3.0,3.0]
# kp_f=10 ki_f=25 i_term_lim=40 max_step_f=60 f_min=0.2 fmax_f=25
t_s,roll_deg,pitch_deg,f1_tgt,f2_tgt,f3_tgt,f1,f2,f3,trim1,trim2,trim3
```

| 事件 | 行为 |
|---|---|
| 勾选 / 起环 | 开新文件，相位归零 |
| 按「■ 停止闭环」/ 急停 / 过载自动停 / 关窗口 | **自动关闭并 flush** |
| 每 10 行（100 ms）| flush 一次 → 崩溃最多丢 0.1 s |

## 4.3 怎么判读

算每档的：

$$
\text{幅值比}=\frac{\text{实测峰峰值}}{\text{目标峰峰值}},\qquad
\varphi = 360^\circ\cdot f\cdot\Delta t_{\text{滞后}}
$$

| 现象 | 结论 |
|---|---|
| 0.2 Hz 幅值比 <0.5 | 内环带宽严重不足（或该缆根本没动）|
| 0.2 Hz 好、1 Hz 开始衰减 | 正常（延时/速度限制）|
| 实测削平（目标不平）| 撞 `f_max` 或饱和 |
| 实测锯齿/台阶 | `每拍限幅` 太小 或 舵机跟不上 |
| 目标摆、实测纹丝不动 | 该缆无效（硬件/符号/未使能）|

# 6. 推荐参数（含依据）

## 6.1 推荐值

| 参数 | 推荐 | 依据 |
|---|---|---|
| **`Kp_f`** | **10** | `S·Kp=0.46` ⟹ 极点 0.54，留 26 ms 延时余量 |
| **`Ki_f`** | **25** | `Ti = Kp/Ki = 0.4 s`（延时 26 ms 的 15 倍，稳） |
| **`积分上限`** | **40** | `c/Kp = 4 N` 摩擦补偿（旧 20 只有 1.33 N）|
| **`每拍限幅`** | **60~120**（原 200 也可）| 它是**领先量**：`v≈13.35×step` c/s，`34` 只有 454 c/s。60→800 c/s，120→1600 c/s，255 才打满 3400 |
| **`f_min`** | **0.2** | 预紧下限 `t ≥ f_min/min n̂`；0.5 是 0.2 的 2.5 倍代价 |
| **`fmax_f`** | **25** | 留 5 N 余量给超调；改 30 可 +20% 能力 |
| **`预紧N`** | **2** | `t` 的**下限**；配合 `f_min=0.2` 足够防松绳 |
| **`αcap`** | **1.0** | 全额用能力 |
| **`K_roll/K_pitch`** | **1.0 / 1.0** | roll 饱和点 24.6°（2.0 只有 12.3°）；静差 ~4~5° |
| **`死区`** | 0.2° | |
| **`max_trim`** | 3000 | 累计行程 |
| **`τ修正 tau_ki`** | **0**（关）| 除非确认是"内环到不了"再用 |
| **`τ方向`** | **1** | 拉 C2 看 `τ_roll` 正负再定 |

## 6.2 逐缆（若 C1 过冲、C2 迟钝）

```
Kp_f    = 8,12,10        ← C1 压慢（过冲）、C2 提快、C3 居中
Ki_f    = 25,25,25
积分上限 = 40,60,40       ← 给迟钝的那根更大积分权限
每拍限幅 = 80,120,100     ← C1 降领先量（减过冲），C2 加领先量（推得动）
```

**判据**：
- 过冲/振荡 → 该缆 `Kp` 降 30~50%（主手段）；`每拍限幅` 降是次要手段（会同时变慢）
- 到不了目标 → 该缆 `积分上限` 加大（`≥ Kp×摩擦N`）
- 三根完全独立，改一根不影响别的

## 6.3 这套参数下的预期

| 指标 | 值 |
|---|---|
| 内环极点 | 0.54（每拍残余 54%，时间常数 ≈22 ms）|
| 积分可补最大稳态差 | `40/10 = 4 N` |
| 舵机速度（`max_step=60`）| `13.35×60 ≈ 800 c/s`；`max_step=120` → 1600 c/s；**255 才打满 3400** |
| 张力斜率（`max_step=60`）| `≈0.61×60 = 37 N/s` |
| 过冲估计（`max_step=60`）| `≈37×26 ms = 0.95 N` |
| `t` 下限（零位）| `0.2/0.264 = 0.76 N` |
| `t` 下限（模型 −18° / UI +18°）| `0.2/0.016 = 12.5 N` |
| 力矩能力（`f_max=25`）| roll +0.43/−0.55；pitch +0.50/−1.44 |
| `c=40` 下摩擦容忍 | 4 N（旧 `c=20` 只有 1.33 N）|

# 7. 上机顺序（一次跑完）

1. **勾上 M28、M29**（`cable_enable` 三根都要 true）
2. 参数按 §6.1 填
3. **单缆验符号**：张力模式 `3/8/3` → C2 应升到 8；若掉 → `trim方向` 第二项改 −1
4. **正弦共模**：基值 3/3/3、`A=1`、`f=0.2`、`1,1,1` → 30 s → 停（自动存盘）
5. 依次 `0.5 / 1 / 2 Hz`，每次重新勾选（新文件）
6. 把 `run_data/sine/` 下的文件交回来做幅频/相频分析

# 8. 一句话

> **逐缆：同一个框填 `10` 或 `8,12,10`；填错就拒绝开环。**
> **增益不是拍脑袋：`Kp=10` 来自 `S·Kp=0.46`，`Ki=25` 来自 `Ti=0.4 s`，`c=40` 来自 `c≥Kp·f_fric`。**
> **`每拍限幅` 是「喂给舵机的位置领先量」而不是速度上限：`v≈13.35×step`，34 只有 454 c/s，≈255 才打满 3400 —— 见 [`每拍限幅_领先量与舵机速度_20261124.md`](每拍限幅_领先量与舵机速度_20261124.md)。**
> **正弦测试起点无阶跃、数据自动落盘、停环自动收口。**
