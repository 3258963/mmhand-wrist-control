# 松绳收绳慢 —— 问题分析、公式与方案（存档 2026-11-20）

> **一句话**：张力模式下绳子松、张力 0、目标 5 N 时，电机收绳只有 **267~670 c/s**，
> 远达不到"一路全速收到绳紧"的预期。根因**不是**频率、不是固件速度、也不是某个上限，
> 而是输出语义 —— **`目标值 = 实测 + 步长`，目标值永远只比实测多 20~50 counts**，
> 而舵机速度正比于这个差值。
>
> 本文把所有已确认的事实、推导出的公式、仍属猜测的部分、以及下一步选项记录在此，
> **下次直接从 §9 恢复**。

## 2. 结论：问题是一条链，不是一个点

| 层 | 事实 | 影响 |
|---|---|---|
| ① 现象 | 收绳 267~670 c/s | 慢 |
| ② 频率 | 100 Hz（诊断 CSV 反推 100.1 Hz）| **不是瓶颈** |
| ③ 固件 | `SERVO_TARGET_SPEED_DEFAULT` 1000 → **3400**（11-20 已烧录）| 天花板抬高，但闭环用不到 |
| ④ 上限 | `max_step` 20→50→2000 都试过 | **不是上限锁住** |
| ⑤ 根因 | `out = 实测 + n`，目标值只比实测多 `n` | **关键** |
| ⑥ 机理 | 舵机 `v = min(K·L, v_max)`，L = 目标值 − 实测 | 差小则慢 |
| ⑦ 矛盾 | 目标值挂远 → 快，但存留偏移大 → 接触时刹不住 → 振荡（11-19 事故）| 必须折中 |
| ⑧ 出路 | 分两阶段：松绳挂远（前馈），接触收回（PI）| 见 §7 |
| ⑨ 依据 | `Δ_max ≈ δ/S`、`F_max ≈ (f* − f_on)/S` | 见 §5 |

## 4. 公式

### ① 绳索增益

```
S = K_rope / (|k| / 1000)
```

1 count = 1/118527 m = 8.44 µm；× 5.5 N/mm = **0.0464 N/count**（≈ 4.6 克力）。

### ② 被控对象是积分器

```
f(k+1) = f(k) + S · Δ_k
```

前提：腕不动、绳不蠕变。若腕让位，`S_eff < S`（更稳、更慢）。

### ③ P 控制的稳定边界

```
Δ_k = K_p · e_k        ⟹        p = 1 − S·K_p
稳定：0 < S·K_p < 2    ⟹        K_p < 43
```

| `S·K_p` | 极点 p | 行为 |
|---|---|---|
| 0.5 | +0.5 | 良好阻尼 |
| **0.70** | **+0.30** | **好（当前 K_p=15）** |
| 1.0 | 0 | 死拍 ⚠（有延迟会振）|
| 2.0 | −1 | 等幅振荡（边界）|

### ④ 伺服速度模型（本次讨论核心）

```
v = min(K · L, v_max),     L = 目标值 − 实测,     τ = 1/K
```

### ⑤ 为什么"每帧步长"就是"速度指令"

```
目标值 = 实测 + Δ_k   ⟹   L = Δ_k   ⟹   v = min(K·Δ_k, v_max)
```

**因为目标每帧都重新钉在实测上，"目标值 − 实测"永远等于本帧步长。**

### ⑥ 过冲公式（定 `Δ_max` 的依据）

```
δ ≈ S · Δ_max          ⟹          Δ_max ≈ δ / S
```

推导：把偏移清零时，伺服多走 `v·τ = K·L·τ`，取 `τ = 1/K` ⟹ 多走 `L` counts ⟹ 过冲 `S·L`。

| 允许过冲 δ | 占 5 N | `Δ_max` |
|---|---|---|
| 0.25 N | 5% | 5 counts |
| 0.50 N | 10% | 11 counts |
| 1.00 N | 20% | 22 counts（当前 20 ≈ 18.6%）|
| 2.32 N | 46% | 50 counts |

### ⑦ 前馈偏移上限（定 `F_max` 的依据）

```
F_max = (f* − f_on) / S
```

| 量 | 值 |
|---|---|
| `f*` | 5 N |
| `f_on` | 0.5 N |
| `F_max` | **97 counts**（0.82 mm）|
| 对应速度 | `K·F_max` = **680 ~ 1260 c/s** |

物理含义：偏移 97 counts 意味着绷紧后最多多收 0.82 mm，正好消耗掉 4.5 N 余量。

### ⑧ 前馈必须门控

若令 `F = K_ff·e`，等于加大比例增益：

```
S·(K_p + K_ff) < 2
```

要在 `e=4.5 N` 时达到 `F=97`，需 `K_ff=21.6` ⟹ `S·(15+21.6)=1.70` ⟹ `p=−0.70`（剧烈打摆）。
**结论：前馈只能在"确认松绳"时输出常数偏移，接触后立即归零。**

### ⑨ 积分段

```
|K_i·Σe·T_s| ≤ i_term_lim = 5 counts  ⟹  最多 0.23 N 等效偏置
积分状态上限 = i_term_lim / K_i = 5/15 = 0.33 N·s
误差 5 N 时 0.067 s 就攒满 ⟹ K_i 实际很难起大作用
```

## 7. 方案（未实施）

### 阶段 A：松绳（开环，允许快）

```
f_meas < f_on（0.5 N）
  → 目标值 = 实测 + F_k，F 每帧 +Δ_max 涨到 F_max(≈90~97)
  → 速度 ~680~1260 c/s

理论依据：绳子松时植物增益 `S_eff = 0`，闭环不存在，稳定性约束失效。

```
f_meas ≥ f_on
  → F 立即归零（同一帧）
  → 目标值 = 实测 + Δ_PI，Δ_max 取 10~15（过冲 10%）

## 11. 第二个发现：负载致稳态误差（2026-11-20 用户提出）

> **用户原话**：随着绳子的缩短，当张力一直增加的时候，要增加一样的张力，虽然电机依旧需要转这么多，
> 但是负载不一样了；如果电机内部没有积分去跑，那么误差会随着目标的增大而增加。

**结论：这个分析成立**（前提是舵机内环无积分），且是标准现象
—— **负载致稳态误差（load-induced steady-state error / droop）**。

### 11.1 机理链

| 步 | 内容 | 公式 |
|---|---|---|
| 1 | 张力升 ⟹ 负载力矩升 | `τ_load = f · r_spool` |
| 2 | 张力每升 1 N，电机仍要转固定量 | `Δu = Δf/S`（`S` 恒定）|
| 3 | 位置环靠"误差"产生力矩（无 I 时）| `τ_m = K_t·K_p^pos·e_pos` |
| 4 | 稳态必须保留误差 | `e_hold = τ_load/(K_t·K_p^pos)` |
| 5 | **误差随目标张力线性增大** | `e_hold = c·f`，`c = r_spool/(K_t·K_p^pos)` |

### 11.2 对张力环的影响

目标是 `实测 + Δ`，而舵机要拿 `e_hold` 去换力矩：

```
f_meas = S·(Δ − e_hold) = S·Δ − S·c·f
```

要让张力停在 `f*`，PI 的稳态输出必须随目标增大：

```
Δ_eq(f*) = c · f*
```

### 11.3 与现有实现的冲突点

| 项 | 值 |
|---|---|
| `i_term_lim` | **5 counts**（0.23 N 等效）|
| 积分状态上限 | 0.33 N·s |
| 推论 | **若 `c·f* > 5 counts`，积分补不满 → 稳态误差出现且随张力增大** |

按 `r_spool ≈ 5.5 mm` 估算负载力矩：5 N → 27.5 mN·m；15 N → 82.5；25 N → **137 mN·m**。
**高张力（15~25 N）时最可能成立。**

### 11.4 关键前提：舵机内环**有没有 I**

| 情况 | `e_hold` | 用户判断 |
|---|---|---|
| 内环纯 P | `c·f > 0`，随负载增大 | ✅ 成立 |
| 内环有 I（飞特常见）| `→ 0` | ❌ 不成立 |

飞特 STS/SCS 的位置环通常带 P/D/I 三项；**只有读到 EEPROM 才能确认**（见 §12 的 E1）。

### 11.5 验证实验（可与 §9 的 v(L) 测试合并）

```
同一位姿、同一根绳，依次设 f* = 5 / 10 / 15 / 20 N
每个稳定 3 s，记录：f_meas、Δ（PI 输出）、目标值与实测位置之差
① 画 Δ_eq vs f*        → 斜率 = c
② 画 (f* − f_meas) vs f* → 若随 f* 增大 ⟹ 判断成立
```

| 结果 | 结论 | 对策 |
|---|---|---|
| `f* − f_meas` ≈ 常数 0 | 内环有 I | 无需处理 |
| 随 `f*` 线性增大 | ✅ 内环无 I / I 太小 | 加负载前馈（11.6）|
| `Δ_eq > 5 counts` 才稳 | 积分钳制不够 | 放大 `i_term_lim` |

### 11.6 对策：负载前馈（扰动前馈）

```
目标值 = 实测 + F_收绳 + c·f_meas + Δ_PI
```

**为什么安全**：`c·f_meas` 是**扰动前馈**，只补稳态、不改变闭环极点（不是 `F ∝ e`，
不会像 §4⑧ 那样破坏 `S·K_p < 2`）。`c` 由 11.5 的斜率实测得到，不需要电机参数。
