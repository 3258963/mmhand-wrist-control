# 力矩容量、工作区与「能控多大力矩」

> **一句话**：三根绳只能拉不能推，所以"能拧出多大力矩"有一个**硬上限**；
> 这个上限 **= f(预紧, 位姿)**，而且**位姿的影响常常比预紧更大**。
> 想控力矩，先算清楚"这个位姿能给出多少"，再决定 τ 给多少。
>
> 图：`figs/capacity_vs_pose.png`（roll / pitch 两个方向的容量曲面，预紧 5 N vs 15 N）

---

## 0. 三个问题的答案

| 问题 | 答案 |
|---|---|
| **容量是什么** | 在给定的 `(预紧, 位姿)` 下，**三根绳都还拉得住（≥ f_min）**时能给出的最大力矩 |
| **由什么决定** | 预紧（整体抬高）+ 位姿（改变力臂和零空间方向）+ `f_min/f_max`（边界） |
| **运动时会怎样** | 预紧固定时，容量**仍会随位姿剧烈变化**（同一预紧 15 N，±10° 差 6 倍） |

## 1.1 行向量还是列向量？（先读这节，后面全按这个约定）

### 总原则

> **本文档里所有向量都是列向量**，除非显式写了转置 `ᵀ`。
> 为了排版，括号里横着写的 `(1.32, 2.97, 3.80)` 是**列向量的行内写法**，
> 它等于
> $$
> \begin{bmatrix}1.32\\2.97\\3.80\end{bmatrix}
> $$
> **不是行向量。** 行向量必须写成 `(1.32, 2.97, 3.80)ᵀ` 或 `[1.32\ 2.97\ 3.80]`。

### 逐个量的形状

| 量 | 形状 | 是行还是列 | 说明 |
|---|---|---|---|
| `f` | 3×1 | **列** | 三根绳的张力 |
| `τ` | 2×1 | **列** | `(τ_roll, τ_pitch)` |
| `n̂` | 3×1 | **列**（且 `‖n̂‖=1`） | 零空间方向 |
| `θ` | 2×1 | **列** | `(θ_r, θ_p)` |
| `c` | 3×1 | **列** | `P⁻¹` 的某一列（roll 或 pitch） |
| `R` | 2×3 | 矩阵 | **行 = 轴，列 = 缆** |
| `r_j` | 1×3 | **行** | `R` 的第 j 行（j=1 roll、j=2 pitch） |
| `P` | 3×3 | 矩阵 | `P = [R; n̂ᵀ]`，第三行是 **`n̂` 的转置** |
| `p` | 标量 | — | 预紧 |

**`P = [R; n̂ᵀ]` 这一步容易写错**：`R` 是 2×3，`n̂ᵀ` 是 1×3，堆起来才是 3×3。
如果写成 `[R; n̂]`（3×1）就拼不上。

### 维度自检（每一步都能对）

| 式子 | 维度演算 | 结果 |
|---|---|---|
| `τ = R f` | (2×3)(3×1) | 2×1 ✓ |
| `p = n̂ᵀ f` | (1×3)(3×1) | 标量 ✓ |
| `P f = [τ; p]` | (3×3)(3×1) = (3×1) | ✓ |
| `f = P⁻¹[τ; p]` | (3×3)(3×1) | 3×1 ✓ |
| `f = c τ + p n̂` | (3×1)·标量 + 标量·(3×1) | 3×1 ✓ |
| `n̂ = (r₁×r₂)/‖r₁×r₂‖` | 两个 1×3 **行**向量的叉积 | 3×1（按列存） |

`n̂ᵀf`（标量）和 `n̂fᵀ`（3×3 矩阵）差一个转置位置，**本文档只出现前者**。

### 代码里的对应（Python 没有行列概念，全靠约定）

| 数学 | 代码 | 形状 | 索引含义 |
|---|---|---|---|
| `R` | `r_m` | `list[2][3]` | `r_m[轴][缆]` |
| `r_j`（第 j 行） | `r_m[j]` | `list[3]` | 一个轴对三根缆的力臂 |
| `f` | `f_n` / `f_target` | `tuple(3)` | `f[i]` = 第 i 根缆 |
| `τ` | `tau_d` / `tau_meas` | `tuple(2)` | `[0]`=roll、`[1]`=pitch |
| `n̂` | `null_dir` | `tuple(3)` | 与 `f` 同序 |
| `P` | `[[…],[…],[…]]` | `list[3][3]` | **第三行就是 `null_dir`（即 n̂ᵀ）** |
| `p` | `preload_n` / `t_target` | `float` | — |

代码里 `τ = R f` 写成逐行点乘（`wrist_force_law.py`）：

```python
tau_meas_r = sum(p.r_m[0][i] * f_n[i] for i in range(3))   # 第 0 行 · f
tau_meas_p = sum(p.r_m[1][i] * f_n[i] for i in range(3))   # 第 1 行 · f
```

`wrist_tda.py` 里拼 `P`：

```python
P = [r_m[0],          # 1×3 行
     r_m[1],          # 1×3 行
     [null_dir[0], null_dir[1], null_dir[2]]]   # ← n̂ᵀ（转置成行）
```

### 五个最容易错的地方

1. **`R` 是 2×3，不是 3×2** —— 行是轴、列是缆。写成 3×2 会让 `R f` 维度不对。
2. **`R_{ji}` 第一个下标是轴（j），第二个是缆（i）** —— 与"第 j 行、第 i 列"一致。
3. **`c_i` 是第 i 根绳的分量**，不是第 i 个轴。
4. **`n̂ᵀf` 是标量**，`n̂fᵀ` 是 3×3 —— 别混。
5. **横写的 `(a,b,c)` 是列向量**（见上）。

### ⚠ 符号约定：代码的 `r_m` = `−∂s/∂θ`

这一点必须写清楚，否则和教科书推导对不上。**有限差分验证**（`θ=0`，`h=1e-6`）：

| 轴 | 缆 | `r_m` | `∂s/∂θ` | 关系 |
|---|---|---|---|---|
| roll | C1 | −0.000259 | +0.000259 | `r_m = −∂s/∂θ` |
| roll | C2 | −0.022050 | +0.022050 | 同 |
| roll | C3 | +0.017372 | −0.017372 | 同 |
| pitch | C1 | −0.058105 | +0.058105 | 同 |
| pitch | C2 | +0.011805 | −0.011805 | 同 |
| pitch | C3 | +0.010990 | −0.010990 | 同 |

**所以**：

- 本文档后面所有公式用的 `R` 都**指代码的 `r_m`**（即 `R ≡ r_m`），
  这样和程序完全一致，算式不会错位；
- 如果要和"虚功原理 `τ = +(∂l/∂θ)ᵀ f`"对照，两者**差一个负号**：
  `τ_code = r_m f = −τ_虚功`；
- **不影响的部分**：`n̂`（零空间是齐次的）、`P` 的可解性、容量公式的形式
  —— 因为这些只依赖 `R` 的零空间和线性结构；
- **需要台架确认的部分**：`τ_d > 0` 时腕往哪个方向转。
  给一个 `τ_d = +0.02 N·m`（roll），观察实际转向，就能定下符号
  （`trim_sign` 已经处理了每根缆的方向，但 `τ` 的整体符号要单独确认一次）。

## 2. 推导一：力臂矩阵从哪里来

绳长是两段之和（串联解耦模型）：

$$
l_i(\theta_r,\theta_p) = s_i^{(r)}(\theta_r) + s_i^{(p)}(\theta_p)
$$

虚功原理：关节做的功等于各绳张力做的功，

$$
\tau^{\top}\delta\theta = \sum_i f_i\,\delta l_i
$$

而 `δl_i = (∂l_i/∂θ)ᵀ δθ`，所以

$$
\boxed{\ \tau = R f\ },\qquad R_{ji} = \frac{\partial l_i}{\partial \theta_j}
$$

> **符号提醒**（详见 §1.1）：本文档的 `R` **就是代码里的 `r_m`**，
> 而 `r_m = −∂s/∂θ`（有限差分验证过）。
> 所以严格说 `R = −∂l/∂θ`，这里的 `∂l/∂θ` 是"教科书口径"；
> 全文统一用代码口径 `R ≡ r_m`，因此下面所有代数式与程序一一对应。

**要点**

- `R` 只跟几何有关，**不依赖 f**（所以是线性的）；
- 本模型里 `∂²l/∂θ_r∂θ_p ≡ 0`（两段独立）→ `R_roll` 只随 θ_r 变、`R_pitch` 只随 θ_p 变；
- 但 `l` 本身是两段之和 → 动一个轴也改所有绳长（**运动耦合**）。

## 3. 推导二：零空间方向 n̂ 与「力封闭」

### 3.1 为什么会有零空间

3 根绳 → `f ∈ ℝ³`；2 个自由度 → `τ ∈ ℝ²`。`R` 是 **2×3**，秩 2，所以

$$
\dim \ker R = 3 - 2 = 1
$$

即存在**一个方向的张力组合不产生任何力矩**：

$$
R\,\hat n = 0
$$

### 3.2 怎么算

设 `r₁, r₂` 是 `R` 的两行（单位化后为 `a, b`），则

$$
\hat n = \frac{a \times b}{\lVert a \times b\rVert}
$$

**验证**：`a·(a×b) = 0`、`b·(a×b) = 0` → 它跟两行都正交 → `R n̂ = 0` ∎

### 3.3 力封闭（force closure）条件

> **存在** `f ≻ 0` 使 `R f = 0`
> ⟺ **`n̂` 的三个分量同号**（取全正方向）

因为零空间里的任何向量都是 `λ n̂`：要三根都 > 0，必须 `λ > 0` 且 `n̂ ≻ 0`（或 `λ<0, n̂≺0`，翻转即可）。

**这就是代码 `positive_null_direction()` 的判据**，也是"张紧/力矩能否工作"的**第一条**硬条件。

本机：`n̂ ≻ 0` 只在一个**子区域**成立（roll ∈ [−18.4°, +15.1°]、pitch ≤ 33.8°），
面积约占 UI 范围的 **53%**。

## 4. 推导三：给定 `(τ, p)`，三根绳的张力**唯一**确定

### 4.1 为什么要第三个方程

只有力矩方程时：

$$
R f = \tau \quad\Longleftrightarrow\quad
\begin{cases}
R_{r1}f_1 + R_{r2}f_2 + R_{r3}f_3 = \tau_r\\
R_{p1}f_1 + R_{p2}f_2 + R_{p3}f_3 = \tau_p
\end{cases}
$$

**2 个方程、3 个未知数** → 解不唯一。

设 `f*` 是一个特解，`n̂` 是 `R` 的零空间向量（`R n̂ = 0`），那么

$$
f = f^{*} + \sigma\,\hat n,\qquad \sigma \in \mathbb R
$$

**也满足 `R f = τ`**。也就是说：**满足力矩的张力解是一整条直线**（沿 `n̂` 方向），
方向是 `n̂`，**在线上选哪一点，完全由 `σ` 决定**。

> 这条直线就是上一张 3D 图里那些**平行的彩线**。
> `τ` 决定"线平移到哪"，`σ` 决定"在线上的位置"。

于是必须再补一个约束来"钉住"这个 `σ`。物理上最自然的那个量就是**预紧**：

$$
\boxed{\ \hat n^{\top} f = p\ }
$$

它衡量的正是"三根绳整体绷多紧"——因为沿 `n̂` 移动不产生力矩，只改变绷紧程度。

### 4.2 三个方程、三个未知数 → 唯一解

$$
P = \begin{bmatrix} R \\ \hat n^{\top}\end{bmatrix}
=\begin{bmatrix}
R_{r1} & R_{r2} & R_{r3}\\
R_{p1} & R_{p2} & R_{p3}\\
\hat n_1 & \hat n_2 & \hat n_3
\end{bmatrix},\qquad
P f = \begin{bmatrix}\tau_r\\ \tau_p\\ p\end{bmatrix}
$$

`P` 是 3×3。**只要 `det P ≠ 0`，解就唯一**：

$$
\boxed{\ f = P^{-1}\begin{bmatrix}\tau_r\\ \tau_p\\ p\end{bmatrix}\ }
$$

### 4.3 `det P` 到底等于什么（几何意义）

用行列式的"混积"性质：三个行向量组成的矩阵，其行列式等于**混合积**：

$$
\det P = \hat n\cdot(r_1\times r_2)
$$

其中 `r₁, r₂` 是 `R` 的两行。而 `n̂ = (r₁×r₂)/‖r₁×r₂‖`（推导二），所以

$$
\det P = \frac{(r_1\times r_2)\cdot(r_1\times r_2)}{\lVert r_1\times r_2\rVert}
= \lVert r_1\times r_2\rVert
$$

**结论**：

$$
\det P \ne 0 \iff r_1 \times r_2 \ne 0
\iff \text{两行力臂不平行}
\iff \hat n \text{ 存在}
$$

**所以"能不能解"和"n̂ 是否存在"是同一个条件**——这也解释了为什么代码里
`positive_null_direction()` 返回 `None` 时，TDA 直接报 `NO_NULL`。

### 4.4 本机的真实数字（`(0,0)`，可直接核对）

$$
R=\begin{bmatrix}
-0.00025944 & -0.02204970 & +0.01737198\\
-0.05810462 & +0.01180488 & +0.01099035
\end{bmatrix},\quad
\hat n=\begin{bmatrix}+0.26443774\\ +0.59490962\\ +0.75904890\end{bmatrix}
$$

$$
P=\begin{bmatrix}
-0.00025944 & -0.02204970 & +0.01737198\\
-0.05810462 & +0.01180488 & +0.01099035\\
+0.26443774 & +0.59490962 & +0.75904890
\end{bmatrix}
$$

$$
\det P = -1.6919227\times10^{-3},\qquad
\lVert r_1\times r_2\rVert = 1.6919227\times10^{-3}\ \checkmark
$$

（符号为负是因为 `n̂` 取了"全正"方向，与 `r₁×r₂` 反向；**绝对值相等**，这是关键。）

$$
P^{-1}=\begin{bmatrix}
-1.43163680 & -16.00047182 & +0.26443774\\
-27.78525839 & +2.83153209 & +0.59490962\\
+22.27563496 & +3.35501820 & +0.75904890
\end{bmatrix}
$$

**注意最后一列正好是 `n̂`** —— 这不是巧合，§5 会给证明。

### 4.5 不用矩阵，怎么手算（消元法）

以 `(0,0)`、`τ_p = 0.1`、`p = 5` 为例，三条方程是：

$$
\begin{cases}
-0.00025944f_1 -0.02204970f_2 +0.01737198f_3 = 0\\
-0.05810462f_1 +0.01180488f_2 +0.01099035f_3 = 0.1\\
+0.26443774f_1 +0.59490962f_2 +0.75904890f_3 = 5
\end{cases}
$$

**第 1 步**：用第三式把 `f₃` 表示出来：

$$
f_3 = \frac{5 - 0.26443774f_1 - 0.59490962f_2}{0.75904890}
= 6.5872 - 0.34837f_1 - 0.78377f_2
$$

**第 2 步**：代回前两式，得到 2×2：

$$
\begin{cases}
-0.006310f_1 - 0.035666f_2 = -0.11446\\
-0.061934f_1 + 0.003190f_2 = +0.02760
\end{cases}
$$

**第 3 步**：解 2×2（`det = -2.2287×10^{-3}`）：

$$
f_1 = \frac{(-0.11446)(0.003190) - (-0.035666)(0.02760)}{\det} = \mathbf{-0.2779}
$$

$$
f_2 = \frac{(-0.006310)(0.02760) - (-0.11446)(-0.061934)}{\det} = \mathbf{+3.258}
$$

**第 4 步**：回代求 `f₃`：

$$
f_3 = 6.5872 - 0.34837\times(-0.2779) - 0.78377\times3.258 = \mathbf{+4.130}
$$

**校验**：

$$
R f = \begin{bmatrix}0\\ 0.1\end{bmatrix}\ \checkmark,\qquad
\hat n^{\top}f = 5.000\ \checkmark
$$

**结果与矩阵法完全一致**：`f = (−0.278, 3.258, 4.130)`。

![矩阵法与消元法对照](../../../figs/derivation_card.png)

> 图说明：上半部分左=矩阵法（`P`、`det P`、`P⁻¹`、`b` 全部给定），右=消元法 4 步；
> 下半部分把两种算法的结果画成并排柱状图，**逐位一致（最大差 1.5×10⁻¹⁵ N）**，
> C1 柱子在 0 以下 → 绳只能拉不能推 → 这个 τ 不可实现。

### 4.6 这个例子说明了什么

**C1 需要 −0.278 N。** 绳只能拉，不能推 → 这个"张力分布"**物理上不存在** →
**τ_p = 0.1 N·m 在这个预紧下做不出来**。

这就是"容量"的由来（§6 会把它写成闭式解）。

### 4.7 什么时候解不出来

| 情况 | 数学表现 | 代码表现 |
|---|---|---|
| 两行力臂平行（位姿退化） | `det P = 0` | `n̂ = None` → 停环 |
| `n̂` 有正有负（不可力封闭） | 解存在，但 `f ≻ 0` 做不到 | `positive_null_direction` 返回 `None` |
| 解出来的 `f` 越界 | 解存在，但不在 `[f_min, f_max]` | TDA 打折 `α < 1` |

## 5. 推导四：为什么 `f` 能写成 `c·τ + p·n̂`

### 5.1 第一步：`P⁻¹` 是线性算子（`p` 为什么能提到外面）

#### 5.1.1 只用了两个基本性质

**性质 A：矩阵乘法对输入的加法是线性的**

$$
M(x+y) = Mx + My
$$

**性质 B：输入向量里的标量因子可以提出来**

$$
M(\alpha x) = \alpha\,(Mx)
$$

> **证明 B**：矩阵乘法的第 i 个分量是
> `(Mv)_i = Σ_j M_ij v_j`。把 `v` 换成 `αv`，右边每个 `v_j` 都乘了 `α`，
> 所以整个和也乘 `α`。∎

#### 5.1.2 用它来拆 `[τ; p]`

先拆向量（性质 A）：

$$
f = P^{-1}\begin{bmatrix}\tau\\ p\end{bmatrix}
= P^{-1}\left(\begin{bmatrix}\tau\\ 0\end{bmatrix} + \begin{bmatrix}0\\ p\end{bmatrix}\right)
= P^{-1}\begin{bmatrix}\tau\\ 0\end{bmatrix}
+ P^{-1}\begin{bmatrix}0\\ p\end{bmatrix}
$$

再处理第二项 —— **把 `p` 写成"标量 × 向量"**（这就是你问的那一步）：

$$
\begin{bmatrix}0\\ p\end{bmatrix} = p\cdot\begin{bmatrix}0\\ 1\end{bmatrix}
\;\Longrightarrow\;
P^{-1}\begin{bmatrix}0\\ p\end{bmatrix}
= P^{-1}\left(p\begin{bmatrix}0\\1\end{bmatrix}\right)
= p\left(P^{-1}\begin{bmatrix}0\\1\end{bmatrix}\right)
$$

$$
\boxed{\ f = \underbrace{P^{-1}\begin{bmatrix}\tau\\ 0\end{bmatrix}}_{\text{只跟 }\tau\text{ 有关}}
\;+\;\underbrace{p\,P^{-1}\begin{bmatrix}0\\ 1\end{bmatrix}}_{\text{只跟 }p\text{ 有关}}\ }
$$

#### 5.1.3 一个 2×2 的玩具例子（先看清机制）

$$
M=\begin{bmatrix}1&2\\3&4\end{bmatrix},\qquad v=\begin{bmatrix}0\\5\end{bmatrix}
$$

直接乘：

$$
Mv=\begin{bmatrix}1&2\\3&4\end{bmatrix}\begin{bmatrix}0\\5\end{bmatrix}=\begin{bmatrix}10\\20\end{bmatrix}
$$

提出来再乘：

$$
5\cdot M\begin{bmatrix}0\\1\end{bmatrix}
=5\cdot\begin{bmatrix}2\\4\end{bmatrix}=\begin{bmatrix}10\\20\end{bmatrix}\ \checkmark
$$

#### 5.1.4 本机的真实数值验证

| 算法 | 结果（`p=5`） |
|---|---|
| 直接算 `P⁻¹·[0,0,5]` | `(1.32218868, 2.97454808, 3.7952445)` |
| 提出来：`5 × (P⁻¹ 第三列)` | `(1.32218868, 2.97454808, 3.7952445)` |
| `5 × n̂` | `(1.32218868, 2.97454808, 3.7952445)` |

**三者相同** —— 说明"提出来"和"直接算"没有差别。

#### 5.1.5 关键技巧：乘单位向量 = 取一列

$$
P^{-1}\begin{bmatrix}0\\0\\1\end{bmatrix} = P^{-1}\ \text{的第 3 列}
$$

因为 `[0;0;1] = e₃` 只"选中"矩阵的第 3 列。同理：

$$
P^{-1}\begin{bmatrix}1\\0\\0\end{bmatrix}=c_{\text{roll}}\ (\text{第 1 列}),\qquad
P^{-1}\begin{bmatrix}0\\1\\0\end{bmatrix}=c_{\text{pitch}}\ (\text{第 2 列}),\qquad
P^{-1}\begin{bmatrix}0\\0\\1\end{bmatrix}=\hat n\ (\text{第 3 列})
$$

最后那个等式就是 §5.2 要证明的结论；§4.4 打印出的 `P⁻¹` 第三列正是 `n̂`，可以先当**数值证据**看。

#### 5.1.6 一个必须区分的写法

| 写法 | 是什么 | 形状 | 能否当 `f` |
|---|---|---|---|
| `P⁻¹·(p·e₃)` 或 `p·(P⁻¹e₃)` | 矩阵 × 向量 | **3×1** | ✅ 等于 `p·n̂` |
| `p·P⁻¹` | 标量 × **矩阵** | **3×3** | ❌ 类型不对 |

**`p` 是从"右边输入的向量"里提出来的，不是乘在矩阵上。**

#### 5.1.7 一句话

> `[0;p] = p·e₃` →（齐次性）→ `P⁻¹(p e₃) = p(P⁻¹e₃)` →（取列）→ `P⁻¹e₃ = n̂`
> ⟹ **`P⁻¹[0;p] = p·n̂`**，即"预紧项 = 预紧值 × 零空间方向"。

这就是**叠加原理**：预紧和力矩各自贡献一部分，可以直接相加
（因为 `f` 对 `(τ, p)` 是**仿射**的 —— 线性部分 + 常数项）。

### 5.2 第二步：第二项为什么正好是 `n̂`

令 `x = P⁻¹[0; 1]`，则 `x` 必须满足 `P x = [0; 1]`，也就是

$$
\begin{cases}
R x = 0 & \text{（力矩为零）}\\
\hat n^{\top} x = 1 & \text{（预紧为 1）}
\end{cases}
$$

第一式说 `x` 在 `R` 的零空间里 → `x = λn̂`；
第二式说 `λ (n̂ᵀ n̂) = 1`，而 `‖n̂‖ = 1` → `λ = 1`。

$$
\boxed{\ P^{-1}\begin{bmatrix}0\\1\end{bmatrix} = \hat n\ }
$$

**数值核对**（§4.4 的 `P⁻¹` 第三列）：

$$
P^{-1}\begin{bmatrix}0\\0\\1\end{bmatrix}
=\begin{bmatrix}+0.26443774\\ +0.59490962\\ +0.75904890\end{bmatrix}
=\hat n\ \checkmark
$$

**物理含义**：`p·n̂` 这一项**一点力矩都不产生**，它只是把三根绳"整体拉紧"。

### 5.3 第三步：第一项 `c` 是什么

设 `c = P⁻¹[1; 0; 0]`（roll 方向）。它满足

$$
\begin{cases}
R c = \begin{bmatrix}1\\0\end{bmatrix} & \text{（单位 roll 力矩）}\\
\hat n^{\top} c = 0 & \text{（预紧为 0）}
\end{cases}
$$

第二式很关键：**`c` 与零空间正交**。这意味着 `c` 是"产生单位力矩所需要的**最小张力分布**"：

> 任意满足 `R f = e₁` 的解都可以写成 `f = c + λn̂`。
> 因为 `c ⊥ n̂`，所以 `‖f‖² = ‖c‖² + λ²`，
> 在 `λ = 0` 时取最小 → **`c` 就是最小范数解**（`f = R⁺e₁`）。

本机数值：

$$
c_{\text{roll}} = P^{-1}\begin{bmatrix}1\\0\\0\end{bmatrix}
=\begin{bmatrix}-1.4316\\ -27.7853\\ +22.2756\end{bmatrix}
\qquad
c_{\text{pitch}} = P^{-1}\begin{bmatrix}0\\1\\0\end{bmatrix}
=\begin{bmatrix}-16.0005\\ +2.8315\\ +3.3550\end{bmatrix}
$$

**读法**（`c_pitch`）：

- 想要 **+1 N·m 的 pitch 力矩**（只靠力矩、不加预紧），需要
  C1 **−16.0 N**、C2 **+2.83 N**、C3 **+3.36 N**；
- `C1` 是负的 → **单靠力矩方向，光靠绳拉不出来** → 必须靠预紧 `p·n̂` 把 C1 抬上去。

这就是"为什么必须有预紧"的量化答案：

$$
\underbrace{-16.0\tau}_{c_1\tau\ (\text{把 C1 往下拉})}
+\underbrace{0.264p}_{p\hat n_1\ (\text{把 C1 抬上去})}
\ge 0.5
\;\Longrightarrow\;
p \ge \frac{0.5 + 16.0\tau}{0.264}
$$

代入 `τ=0.1`：`p ≥ (0.5 + 1.6)/0.264 = 7.95 N`。

> **这就是"想控 0.1 N·m 的 pitch，预紧至少要 7.95 N"的来源**
> —— 和我之前给你的表格（pitch 需 7.9 N）完全对上。

### 5.4 完整的手算例子：`τ_p = 0.1`、`p = 5`

**第一项**（力矩部分）：

$$
c_{\text{pitch}}\times 0.1
=\begin{bmatrix}-16.0005\times0.1\\ +2.8315\times0.1\\ +3.3550\times0.1\end{bmatrix}
=\begin{bmatrix}-1.6000\\ +0.2832\\ +0.3355\end{bmatrix}
$$

**第二项**（预紧部分）：

$$
\hat n\times 5
=\begin{bmatrix}0.26443774\times5\\ 0.59490962\times5\\ 0.75904890\times5\end{bmatrix}
=\begin{bmatrix}+1.3222\\ +2.9745\\ +3.7952\end{bmatrix}
$$

**相加**：

$$
f = \begin{bmatrix}-1.6000\\ +0.2832\\ +0.3355\end{bmatrix}
+\begin{bmatrix}+1.3222\\ +2.9745\\ +3.7952\end{bmatrix}
=\begin{bmatrix}-0.2779\\ +3.2577\\ +4.1307\end{bmatrix}
$$

与 §4.5 的消元结果逐位一致 ✓（对照图见 §4.5 的 `derivation_card.png`）

### 5.5 两项的物理意义（对应那张条形图）

| 项 | 作用 | 条形图里的表现 |
|---|---|---|
| `p·n̂` | **整体抬高**（三根一起涨） | 三根柱子一起变高 |
| `c·τ` | **倾斜**（一根降、两根涨） | C1 往下掉、C2/C3 往上抬 |

**预紧的作用就是给"倾斜"留出向下掉的空间**：
`p` 越大，`c₁τ` 把 C1 往下拉时，C1 还有多少余量。

### 5.6 由此直接得到容量公式

单轴 τ、给定 `p` 时，第 `i` 根绳的张力是

$$
f_i(\tau,p) = c_i\tau + p\hat n_i
$$

要它守住 `[f_min, f_max]`，解出 τ 的允许范围（`c_i > 0` 时）：

$$
\tau \le \frac{f_{\max} - p\hat n_i}{c_i}
\quad\text{且}\quad
\tau \ge \frac{f_{\min} - p\hat n_i}{c_i}
$$

三根绳全部满足 → 取交集 → **上界就是容量**（`c_i>0` 与 `c_i<0` 两个分支都要算，
因为除以负数会翻号）：

$$
\boxed{\ \tau_{\max}(p,\theta)
=\min\left(
\min_{c_i>0}\frac{f_{\max}-p\hat n_i}{c_i},\
\min_{c_i<0}\frac{f_{\min}-p\hat n_i}{c_i}
\right)\ }
$$

`(0,0)`、`p=5`、pitch 方向：`c = (−16.0,\ +2.83,\ +3.36)`，

$$
\tau \le \min\left(
\underbrace{\frac{25-2.97}{2.83}}_{7.79},\
\underbrace{\frac{25-3.80}{3.36}}_{6.31},\
\underbrace{\frac{0.5-1.322}{-16.0}}_{\mathbf{0.0514}}
\right)
=\mathbf{0.0514}
$$

> 最后一项是 **C1**：它的 `c₁<0`（加大力矩会让 C1 **变松**），
> 所以真正的墙是 C1 的**下界** `0.5 N`，而不是 C2/C3 的上界。
> **容量 0.051 就是这么来的**（与 §7 表格一致）。

**这就是"容量 = 谁先撞墙"**：不是公式复杂，而是**三根绳里总有一根先到头**，
而且**卡住的那根会随位姿换**。

## 6. 推导五：容量的闭式解

要求三根绳都在边界内：

$$
f_{\min} \le c_i\tau + p\hat n_i \le f_{\max},\qquad i=1,2,3
$$

对每个 `i` 解出 τ 的区间：

$$
\begin{cases}
c_i > 0: & \dfrac{f_{\min}-p\hat n_i}{c_i} \le \tau \le \dfrac{f_{\max}-p\hat n_i}{c_i}\\[2mm]
c_i < 0: & \dfrac{f_{\max}-p\hat n_i}{c_i} \le \tau \le \dfrac{f_{\min}-p\hat n_i}{c_i}\\[2mm]
c_i = 0: & \text{仅要求 } f_{\min} \le p\hat n_i \le f_{\max}
\end{cases}
$$

三者的**交集**就是可行 τ 区间，其上界即容量：

$$
\boxed{\ \tau_{\max}^{\text{axis}}(p,\theta)
=\min\left(
\min_{c_i>0}\frac{f_{\max}-p\hat n_i}{c_i},\
\min_{c_i<0}\frac{f_{\min}-p\hat n_i}{c_i}
\right)\ }
$$

（`c_i \approx 0` 的那根不产生 τ 约束，只要求 `f_min ≤ p n̂_i ≤ f_max`。）

**推论（很好用）**：

1. **容量是 `p` 的分段线性函数**（三条直线的下包络）；
   → preload 越大，容量越大，**斜率由"卡住的那根绳"决定**。
2. **卡住的绳会换** → 曲线有折点（图上"喇叭"顶部收窄就是因为从"撞 f_min"变成"撞 f_max"）。
3. **容量 ∝ (f_max − f_min)** 近似成立 → 想翻倍就得抬 `f_max`。
4. `c_i` 和 `n̂_i` 都是 θ 的函数 → **容量随位姿变**。

### 6.1 特例：τ=0（纯预紧）

此时 `f_i = p\,\hat n_i`，逐缆要求 `f_min ≤ p\hat n_i ≤ f_max`：

- 下界：`p ≥ f_min/\hat n_i` 对每根缆都成立 ⟹ `p ≥ f_min \cdot \max_i(1/\hat n_i)`
- 上界：`p ≤ f_max/\hat n_i` ⟹ `p ≤ f_max \cdot \min_i(1/\hat n_i)`

$$
\boxed{\ \frac{f_{\min}}{\min_i \hat n_i} \;\le\; p \;\le\; \frac{f_{\max}}{\max_i \hat n_i}\ }
$$

> **注意方向**：下界除以 **`min n̂`**（最"不争气"的那根绳决定的），
> 上界除以 **`max n̂`**（最容易先撞上限的那根）。
> 写反会得到完全错误的区间。

本机 `(0,0)`：`0.5/0.264 = 1.89 ≤ p ≤ 25/0.759 = 32.9`。

**实现**：`wrist_tda.preload_window(r_m, n̂, τ_r, τ_p, f_min, f_max)`
（2026-11-18 起用这个通用式；τ=0 时退化成上面的闭式，已用测试逐位比对）。
接重力补偿后只需把 `τ` 传进去，**公式不用改**。

## 7. 数值：容量到底怎么变

`(f_min, f_max) = (0.5, 25) N`：

| 位姿 | `n̂` | 预紧 5 N：roll / pitch | 预紧 15 N：roll / pitch |
|---|---|---|---|
| (0, 0) | (0.264, 0.595, 0.759) | 0.089 / 0.051 | 0.303 / 0.217 |
| (+10, 0) | (0.194, 0.044, 0.980) | **0.019** / 0.039 | **0.086** / 0.179 |
| (−10, 0) | (0.328, 0.905, 0.269) | **0.202** / 0.050 | **0.557** / 0.212 |
| (0, +20) | (0.148, 0.635, 0.758) | 0.091 / **0.014** | 0.310 / **0.100** |
| (0, +30) | (0.047, 0.618, 0.785) | 0.000 / 0.000 | 0.313 / **0.011** |
| (+12, +5) | (0.077, 0.104, 0.992) | 0.006 / 0.029 | **0.045** / 0.148 |

**三个结论**

1. **预紧抬高容量**（5 → 15 N，容量约 ×3.4）
2. **位姿影响更大**：同一预紧，`roll=+10°` 与 `−10°` 差 **6.5 倍**
3. **存在"容量塌陷角"**：`(0,30)` 的 pitch、`(+12,+5)` 的 roll —— 给多少预紧都不够

## 8. 推导六：外环 `Kp_τ` 与容量的关系（**该环已于 2026-11-18 移除**）

> ⚠ **本节是历史推导，保留作参考。**
> 2026-11-18 起力矩模式去掉 P 外环（`τ_d → TDA → f_d → 内环`），
> 力矩 **P** 外环已删除（实测关掉后摆动 0.075→0.004，见 `腕部控制_原理与实现.md` §6.0）。
> **2026-11-24 加回了"只积分"的力矩修正**（`τ修正` 框，默认 1.0 /s，上限 ±0.3 N·m）——
> 正是本节预言的"残差修正"，只是 `Kp_τ` 仍为 0。
> 所以下面的 `Kp_τ` 现在**不存在**，但 `Ki_τ` 的残差修正思路仍然适用，
> 而且这些式子能告诉你它最多能给多大。

假设存在外环：

$$
u = \mathrm{sat}\big(K_{p\tau}e + I,\ \pm \text{lim}\big),\qquad e = \tau_d - Rf
$$

TDA 收到 `τ_d + u`，若超出容量则**等比缩小**：

$$
\alpha = \min\Big(1,\ \frac{\tau_{\max}}{|\tau_d+u|}\Big),\qquad \tau_{\text{applied}} = \alpha(\tau_d+u)
$$

**所以"线性区"不是 `lim/Kp`，而是**

$$
\boxed{\ |e| \le \frac{\tau_{\max}}{K_{p\tau}}\ }
$$

（`lim` 只是外环自己的硬限幅，本机 `lim=0.97/1.98 N·m` **远大于**容量 `0.09/0.05`，永远轮不到它。）

**设计公式**：想让误差 `E` 以内都保持线性，

$$
\boxed{\ K_{p\tau} \le \frac{\tau_{\max}(p,\theta)}{E}\ }
$$

本机（`(0,0)`、`p=15`、`E=0.1`）：`Kp_τ ≤ 0.303/0.1 ≈ 3`。

### 8.1 还有第二个更紧的约束：级联稳定

内环每拍只走完 `g = S·k_{p,\text{inner}} = 0.696`，所以外环不能"纠正过头"：

$$
\boxed{\ K_{p\tau}\cdot g < 1\ }
\Longrightarrow
K_{p\tau} < 1.44\ (\text{当 } k_{p,\text{inner}}=15)
$$

实测（`τ_d=0.1`、预紧 15）：

| `kp_inner` | `g` | `1/g` | `Kp_τ` | `Kp·g` | 末段摆动 | 结果 |
|---|---|---|---|---|---|---|
| 15 | 0.696 | 1.44 | 20 | 13.9 | 0.071 | 振荡 |
| 15 | 0.696 | 1.44 | 2 | 1.39 | 0.059 | 振荡 |
| 15 | 0.696 | 1.44 | 1.4 | 0.97 | 0.0038 | 稳 |
| **0（移除）** | — | — | — | — | **0.0038** | **稳且最简** |

**两条约束一起看**：容量约束 2.3、级联约束 1.44、而**关掉最好** ——
这就是最终决定删掉外环的原因。

## 10. 论文是怎么做的

### 10.1 概念对照

| 本文/本仓库 | 文献里的标准叫法 |
|---|---|
| `n̂ ≻ 0`（能三缆同时收紧） | **力封闭 / force closure** |
| 有效位姿集合（53% 那圈） | **力封闭工作空间 / force-closure workspace** |
| 能给出的 (τ_r, τ_p) 集合 | **可行外力旋量多面体 / wrench feasible workspace (WFW)** |
| "容量"（单轴最大 τ） | 该多面体沿轴的**支撑函数**（support function） |
| TDA 分配 `f_d` | **张力分配算法 / tension distribution algorithm** |
| 给定 τ 选 `p` | **零空间参数化**（null-space parameterization） |

### 10.2 主流的三种做法

**① 伪逆 + 零空间参数（本仓库就是这一类）**

$$
f = R^{+}\tau + \lambda\,\hat n,\qquad \lambda\in\mathbb R
$$

选 `λ`（等价于选 `p`）使 `f ∈ [f_min, f_max]`。
优点：**解析、快**（闭式解）；缺点：`λ` 的可行区间要自己解（我们做的那一步）。

**② LP / QP（文献里最常用）**

$$
\min_f\ \ \lVert f \rVert^2\ \ \text{或}\ \ \max_i f_i\ \ \text{或}\ \ f^{\top}Wf
\quad\text{s.t.}\quad R f = \tau,\ f_{\min}\le f\le f_{\max}
$$

- 目标可以换成"最小能量 / 最小峰值张力 / 张力均衡"；
- 有约束时必然出现"**不可行**"分支 → 对应我们的 `α<1`；
- 求解器（QP）比闭式解慢，但**能处理任意约束**（比如每根绳的上下限不同、温度模型）。

**③ 工作空间预计算（WFW）**

- 离线把 `(τ_r, τ_p)` 的可行多面体在**每个位姿**都算一遍；
- 得到一个"位姿 → 能给出的力矩集合"的映射（就是我们这张 3D 图）；
- 在线只做**查表 + 夹紧**（`τ_d ← clamp(τ_d, 该位姿的多面体)`），保证永不打折。

> 我们的 `tools/gen_capacity_vs_pose.py` 其实就是"③ 的在线版"：
> 每拍闭式算一次（不用查表，因为 O(3) 很便宜）。

### 10.3 论文里还会做、我们没做的四件事

| 做法 | 作用 | 代价 |
|---|---|---|
| **重力/负载前馈** `τ_ff = τ_g(θ)` | 腾出张力余量 → 容量变大 | 要质量/质心模型 |
| **阻抗控制** `τ = K_d(θ*−θ) + τ_ff` | 同时控位置和柔顺 | 要力矩内环（已有） |
| **张力均衡**（min-max 或加权） | 避免某根绳长期最紧（寿命） | 要 QP |
| **在线 WFW 夹紧** | 保证 `α≡1`，不出现"折扣" | 要预计算/查表 |

## 12. 一页纸结论

$$
\begin{aligned}
&\tau = R f &&\text{（力臂）}\\
&R\hat n = 0,\ \hat n\succ 0 &&\text{（零空间 + 力封闭）}\\
&f = P^{-1}[\tau;\ p] = c\,\tau + p\,\hat n &&\text{（张力唯一解）}\\
&\tau_{\max}(p,\theta)=\min\left(\min_{c_i>0}\frac{f_{\max}-p\hat n_i}{c_i},\ \min_{c_i<0}\frac{f_{\min}-p\hat n_i}{c_i}\right) &&\text{（容量闭式）}\\
&|e|\le \tau_{\max}/K_{p\tau} &&\text{（线性区）}
\end{aligned}
$$

**要控力矩，先问三件事：**

1. 这个位姿有 `n̂ ≻ 0` 吗？（没有 → 根本不能控）
2. 这个 `(预紧, 位姿)` 的容量够我要的 τ 吗？（不够 → 加大预紧或减小 τ）
3. 我的 `Kp_τ` 有没有大到"一有误差就超容量"？（有 → 降 Kp）

> **容量不是常数，是 `(预紧, 位姿)` 的曲面。**
> 现在 `预紧=5` 只够控 0.05~0.09 N·m；调到 15 能控 0.2~0.3；再大就要换硬件。
