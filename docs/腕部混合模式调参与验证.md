# 腕部混合模式调参与验证

在腕部上位机的闭环面板选择「混合控制（C1 张力 + 双轴角度）」。M27 用 C1 张力 PID 追张力目标，M28、M29 用 Roll、Pitch 磁编反馈追两轴目标。「混合模式专用参数」里的目标、PID、前馈及限幅独立保存。角度环用一组增益，Roll 和 Pitch 分别维护各自的误差和积分。

## 首轮设置

在已验证的中位附近让三根绳保持预紧。确认 J16、J17、三台电机位置反馈和 C1 张力在线。C1 上限和行程按实际台架可用范围填写。C1 从上一次开始闭环时的实测收放位置计算可用行程。

| 参数 | 首测值 |
| --- | --- |
| Roll、Pitch 目标 | 填当前实测角度，或留空让上位机在启动时填入 |
| C1 目标 | 5 N |
| C1 Kp / Ki / Kd | 5 / 0 / 0 |
| 角度 Kp / Ki / Kd | 0.20 / 0 / 0 |
| 角度死区 | 0.3° |
| C1 步长、C2/C3 步长 | 都先设 5 counts/拍 |
| 角度前馈、C1 前馈 | 都先设 0 |

旧版布局中的 C1 目标、Kp、Ki 与行程会迁入新面板。首测前核对面板实值。普通位置模式的角度目标和增益由原面板保存，混合模式的角度设置由新面板保存。

## 依次验证

每项开始前保持相同的初始姿态、负载和 C1 预紧。结束后保持当前模式，点观测台「诊断 CSV」，保存对应的 `diag_c1_position_*.csv`。每组只改一个参数或一种前馈。

| 步骤 | 操作 | 重点看什么 |
| --- | --- | --- |
| 1. C1 张力环 | 两轴目标固定。让 C1 稳在 5 N，再做 5 → 4.5 → 5 N，给每段留出稳定时间。 | C1 张力朝正确方向变化，最后能保持。两轴若被拉动，应能回到各自目标附近。 |
| 2. 双轴角度环 | C1 保持 5 N。分别给 Roll 和 Pitch 做约 1° 的正反向小阶跃，另一轴目标保持原值。 | 目标轴是否向目标走、超调多少、另一轴串动多少。比较运动期间 C1 最低张力以及 M27 行程余量。 |
| 3. 角度前馈对照 | 保持 C1 前馈为 0。用同样的 Pitch 小阶跃分别测角度前馈 0 和 0.1。 | 比较跟踪时间、过冲和 C1 张力波动。若更快并且过冲和张力波动可接受，再试 0.2。 |
| 4. C1 前馈对照 | 角度前馈保持上一步选定的值。重复同一路径，分别测 C1 前馈 0 和 0.2。 | 比较 C1 张力最低点、峰值误差和恢复时间。确认补偿方向正确，再逐步调整。 |
| 5. 切换与存档 | 停环后切到普通位置模式，改一个位置增益，再切回混合模式。退出并重开上位机，检查混合参数。 | 两种模式各读自己的增益和目标。重启后混合参数从专用存档恢复。 |

C1 前馈根据磁编**已测得的姿态变化**补偿 C1 绳路变化。第一拍补偿为零。Pitch 往复时，补偿的方向随 C1 几何绳路变长或变短而改变。角度前馈则用现有模型给 C2/C3 叠加绳长修正。

## 看日志决定改什么

- `c1_n` 与 `c1_target_n` 用于对比实际和目标张力。`roll_deg`、`pitch_deg` 和对应的 `tgt_..._deg` 用于看角度跟踪。
- `c1_pid_c` 和 `c1_ff_c` 分别是张力 PID 与几何前馈给出的 counts 修正。`tgt_c1_c` 与 `meas_c1_c` 是已下发和实测位置。
- `c1_travel_limited = 1` 时，先查启动预紧位置和整段路径的收放余量。补偿和增益的调整都要在可用行程内判断。
- `c1_step_limited = 1` 或 `c23_step_limited = 1` 持续出现时，先缩小目标步幅或减慢目标变化。判断增益前先排除长期限幅。
- C1 在可用行程内稳定但响应偏慢，可将 C1 Kp 从 5 增至 6 复测。若反复超调，先降 Kp。静态残差持续存在时，再从小 Ki 开始。角度环也先调 Kp，待重复动作稳定后再考虑小量 Ki 或 Kd。

**首轮通过标准可以用角度最终进入 0.3° 死区、C1 静态波动约在目标 ±0.3 N 内，且无持续行程限幅。** 运动中的 C1 张力波动和另一轴串动应和前馈关闭的基准组比较。C2、C3 的预紧在台架上确认，当前混合模式使用 C1 张力和两轴角度反馈。

## 对比 C2、C3 的预估和实测

1. 打开「张力 · R 观测台 → 张力预估」。若接入了 C2、C3 拉力传感器，先在「张力 · R」页核对 CH 映射，再分别勾选对应的实测传感器。对比表采用绝对张力。
2. 在基准姿态停稳，填写该姿态已知的合成绳力矩（N·m，按 R 矩阵的模型坐标符号），点「采集张力基准」。两框填 0 表示该姿态需要的合成绳力矩为零。输入各绳标定的刚度（N/mm）后，会用磁编和卷筒实测多圈位置连续估算。
3. 换到新姿态停稳，点「记录当前对比点」。若该点的两轴所需绳力矩已知，先按新姿态更新两框，程序会同时静力反算。若载荷未知，清空两框即可只记录弹性估算。
4. 有成对的预估值和传感器读数时，误差按「预估减实测」显示。记录多个点后，表下方按绳和方法显示平均绝对误差及样本数。关观测台前点「导出对比 CSV」，文件名为 `wrist_tension_compare_*.csv`，位于 `run_data/scope_exports/`。

短时弹性估算只用绳路与电机放绳变化。长时间保载时，重复记录相同姿态的对比点，用于观察该模型的误差随时间如何变化。

**观测量与控制量的区分（2026-11-23 晚修订）。** 混合模式里 C2、C3 的张力**不参与控制**：`_cl_tick` 在该模式下提前返回，三缆守卫不运行，C1 反馈只读 f1。但它们的实测值**照常显示并记录**——观测台三张缆卡、τ=R·f、张紧 t、力状态曲线都按三缆真值算，诊断 CSV 末列也补了 `c2_n`/`c3_n`。此前曾把 C2、C3 置 NaN，会把 C1 的好数据一起毒成 NaN，已撤销。也就是说：屏幕上看到的 C2/C3 是**观测值**，不是该模式的被控量；它们松绳或过载不会自动停环，仍需人工看缆卡。
