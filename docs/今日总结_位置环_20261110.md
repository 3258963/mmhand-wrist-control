## 2. 今天确认的结论（可直接引用）

1. **三缆两轴 = 过约束**：可达绳长是 R³ 里的 **2 维曲面**；指令落在曲面外时，法向分量不产生运动，只产生三根绳之间的对拉力。
2. **现律用"切线"代替"弦"**，误差是关节误差的**二阶小量**：
   `ΔL = −Kp(1+Kp/2)·(eᵀHe) + O(e³)`，`Kp=0.6` 时系数 −0.78；实测 **ROLL ≈1.8~2.0、PITCH ≈0.5、双轴 ≈2.4 counts/度²**。
3. **小步看不出来、大步就出事**：单轴 1° 对拉 1.8 counts（0.014 mm）；**双轴 8°+8° 累积 155 counts ≈ 1.19 mm**，按绳刚度折算是**几十牛**。
4. **双轴还慢**：`5 counts/拍` 下 ROLL 9.96°/s、PITCH 3.78°/s（2.6 倍），双轴 8° 要 **2.09 s**——后半程只有 pitch 在跑，是两轴"轮流打架"的窗口。
5. **有效工作区比 UI 小得多**：三缆可同时正预紧的区域只有 `roll ∈ [−18.3°, +15.0°]`、`pitch ≤ 33.7°`；出窗后冗余塌缩成两缆，而某些位姿两缆几乎共线（`(+14,0)` 的 C1+C3 仅 **6.2°**、`(0,+30)` 的 C2+C3 仅 **10.4°**、`(−18,0)` 的 C1+C2 仅 **2.2°**）。
6. **位置环看不见松紧**：起环瞬间的松弛量 `S_i0` 被锚点原封不动保留，闭环里没有任何一项会补它；**过紧会自愈、过松不会**。而且 C2/C3 在整个工作区的行程只有 **0.80 / 0.70 圈**——松超过 0.8 圈就是"死绳"。
7. **活动域会被点动收缩**（今天查"活动域不含 M27·C1"时确认）：单机帧 `0xDE`（点动/Go/手填）会把 P4 的活动域改写成"就这一台"，之后 `0xD3` 批量帧被掩码削掉 → "只有一根绳动"。**对策：点动之后必须急停→重新「使能直控」，再起闭环/紧绳。**

## 5. 交给力控的交接单（明天从这里开始）

### 5.1 三个力控模式的现状与风险

| 模式 | 律 | 能不能现在就跑 | 已知风险 |
|---|---|---|---|
| **张力控制** | 每缆独立增量 PI → trim | 能（台架起步用） | `f_target` 未校验 ≤ `f_max`（配错=一启动就停环）；每拍重读 UI；`trim方向` 热改会瞬时反向 |
| **张紧控制** | `t=f·n̂` 单 PI，步长沿 n̂ 分配 | 能，但**脆弱** | 可行域随位姿漂移 → **运行中直接停环**且真实原因被通用消息覆盖（R7）；`fmin` 方向地板会**破坏 τ 守恒**；n̂ 不存在时停环 |
| **力矩控制** | τ PI → TDA → 张力内环 | 能，但要调参 | 默认 `Kp_τ=100` 全程饱和（α≈0.065），α<1 时外环积分冻结 → 实际是"高 P + 边界推"；内环是逐缆对角，`R·Rᵀ` 耦合靠外环积分收敛（不是论文 §7 的解耦律） |

### 5.2 开跑前 5 分钟检查清单

```
□ 1. 张力串口连上，观测台三缆都有读数、龄 < 300ms（力控对"样本过期"是冻结，不是保持）
□ 2. 「trim方向」= 1,-1,-1（按当前 k=[-,+,+] 算出来的），且三根都点动 +100c 核对过
     —— 界面红字 "k 与 trim方向 ... 不符" 必须消失
□ 3. 「fmin / fmax」填实测值（fmax 是过载停环唯一来源，默认 30N 可能太松）
□ 4. 活动域：做过任何点动 → 先急停 → 重新「使能直控」（否则一键紧绳/力控会"只有一台动"）
□ 5. 三缆都绷紧（负载/张力都 > 0），或者先跑「一键紧绳」/「张紧控制」把预紧建立起来
□ 6. 「每拍限幅」先用 5，`trim限幅` 3000；`Kp_τ` 先 2~5（不要用默认 100）
```

### 5.3 力控第一周建议顺序

1. **先量遥测率**（`servo_abs` 帧率）：力控的增量基准是"实测位置"，帧率 < 100Hz 时有效速度会被帧率限住（R8）。在状态栏/遥测里确认；
2. **修 R8**（基准改 `targets + step`，或按 ABS 帧间隔缩放步长）—— 不修的话"每拍限幅 5"这个数在力控里不代表 500 c/s；
3. **修 R7**（张紧可行域：超上界钳制而不是拒绝；停环消息带真实原因）—— 否则张紧会在运行中莫名停掉；
4. **R13**（运行中禁用 `trim方向` 输入框）—— 错一个字符就停环，改符号就飞车；
5. **R14**（`f_target ≤ f_max` 启动前校验）—— 5 行；
6. 最后再调参（`Kp_f/Ki_f`、`Kp_t/Ki_t`、`Kp_τ`、`trim增益`）。

### 5.4 位置环 ↔ 力控的边界（重要）

| 谁 | 管什么 | 不管什么 |
|---|---|---|
| **位置模式** | 走轨迹、到位 | **预紧/张力**（稳态张力只由死区+模型误差提供，0.1~0.3 mm 量级） |
| **张紧 / 张力 / 力矩** | 张力、预紧分配、力矩 | 位姿精度（张紧保持 τ≈0 但位姿会漂；张力模式是腱空间对角，不保位姿） |

⇒ **推荐组合**：先「一键紧绳」或「张紧控制」把三缆拉到 `f ≥ fmin`，再切位置模式走轨迹；需要长时间保持预紧时，用张紧模式兜底或给位置环加 `δ·n̂` 偏置。

> 注意：位置模式的门禁**不检查张力**，所以"松着跑"是被允许的（只显示 ⚠松绳）。这是今天留下的已知缺口（§4 的 P2）。
