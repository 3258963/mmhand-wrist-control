# 腕部控制 · 原理与实现（四模式合一）

> **定位**：把"三缆两轴怎么控、四种模式各在控什么、为什么这样调"写在一份里。
> 含几何基座、位置环推导、张力/张紧/力矩三套力控、参数速查、安全门禁、已知问题、台架操作。
>
> **基线**：2026-11-11。`k=[−108649.8, +118527.0, +118527.0] counts/m`
> （卷筒 r = 6.0 / 5.5 / 5.5 mm，4096 counts/圈），`δ=[0,0]°`。
> 界面操作细节见 [腕部直控上位机使用说明.md](腕部直控上位机使用说明.md)；
> 今日的改动与取舍见 [今日总结_20261111.md](今日总结_20261111.md)。

## 0. 一页纸

1. **3 根绳、2 个自由度 ⇒ 过约束**。三缆长度只能在 R³ 里画出一张 **2 维曲面**；
   指令落在曲面外时，多出来的那一维**不产生运动，只产生三根绳互相对拉**。
2. **位置环**用"切线"近似（`J=−k·R`）而不是"弦"（先算位姿再取绳长），
   误差是关节误差的**二阶小量**（roll 轴 ≈0.015 mm/度²），单轴小步看不出来，
   **双轴 8°+8° 累积 1.19 mm**（≈6.6 N @K=5.5 N/mm）。
3. **力控三种模式**各控不同的量：张力=三缆各 `f_i`；张紧=`t=f·n̂`（τ 守恒）；
   力矩=`τ=R·f`（TDA 分配）。三者共用"**增量式 + 条件积分 + 残差进位**"的执行器。
4. **单位**：1 count = 0.00920 mm / 0.0506 N（C1）、0.00844 mm / 0.0464 N（C2/C3）。
5. **当前配置**：`闭环 100 Hz`、`每拍限幅 20 counts/拍`（=2000 c/s，配舵机 2000 steps/s）、
   张力 `Kp=15 / Ki=20 / 积分钳制 5 counts`。
6. **不能靠位置环补松绳**：起环瞬间的松弛量被锚点原封不动保留，闭环里没有任何一项会补它。

## 1. 几何基座（所有公式的源头）

每根绳拆成两段：ROLL 段只随 `θ_r` 变，PITCH 段只随 `θ_p` 变（串联解耦假设）。

$$
v_1' = v_1\cos\theta - v_2\sin\theta,\quad v_2' = v_1\sin\theta + v_2\cos\theta
$$

$$
d_1 = v_1' - u_1,\quad d_2 = v_2' - u_2,\quad
\boxed{s(\theta)=\sqrt{d_1^2+d_2^2+h^2}},\quad
\boxed{r(\theta)\equiv-\frac{ds}{d\theta}=\frac{d_1v_2'-d_2v_1'}{s}}
$$

三缆总长与力臂：`l_i = s_i^(r) + s_i^(p)`，`R_ji = −∂l_i/∂θ_j`（2×3，m/rad）。

**`(θ=0)` 处的数值**：

$$
R(0,0)=
\begin{bmatrix}
+0.00025944 & +0.02204970 & -0.01737198\\
+0.05810462 & -0.01180488 & -0.01099035
\end{bmatrix}\ \text{m/rad}
$$

$$
\hat n(0,0)=(0.264438,\;0.594910,\;0.759049),\quad R\hat n=0,\quad
l(0,0)=(40.43,\;30.68,\;34.38)\ \text{mm}
$$

每度 counts（逐路，符号随该路 k）：

$$
\frac{\partial c_i}{\partial\theta_j}=-k_iR_{ji}\frac{\pi}{180}=
\begin{bmatrix}
-0.4920 & +45.6139 & -35.9372\\
-110.1836 & -24.4206 & -22.7356
\end{bmatrix}\ \text{counts/deg}
$$

二阶导（counts/rad²）：

$$
H_r=(+734.4,+3888.4,+5523.3),\qquad H_p=(-432.8,+1056.0,+1111.1)
$$

### 1.1 单位换算（这一节的数天天要用）

## 2. 三缆两轴 = 过约束

### 2.1 一张曲面、两个方向

`θ → l(θ)` 把 2 维参数映到 R³，像是一张 2 维曲面 `M`。

- 切平面 `T = span{−R_rᵀ, −R_pᵀ}`；
- 法向 `n̂`：`R·n̂ = 0`（三缆长度的零空间 = 只增加张力、不改位姿）；
- 任何长度指令分解：`Λ = l(θ_c) + τ + γ·n̂`，`τ ∈ T`、`γ` = **纯对拉**。

### 2.2 位置环的"切线 vs 弦"

现律：`Λ = l(θ*) − Kp·R(fb)·e`（用反馈处的切线外推）。
精确：`Λ = l(θ* + Kp·e)`（曲面上）。

$$
\Delta L = \Lambda_{\text{切}} - \Lambda_{\text{弦}}
= -K_p\left(1+\frac{K_p}{2}\right)e^{\top}He + O(\|e\|^3)
$$

`Kp=0.6` 时系数 **−0.78**，实测：

| `e` | ΔL C1 | ΔL C2 | ΔL C3 | 法向对拉 γ (mm) |
|---|---|---|---|---|
| (1°, 0) | +0.2 | −0.9 | −1.4 | −0.014 |
| (4°, 0) | +2.8 | −11.7 | −24.4 | −0.226 |
| (8°, 0) | +10.9 | −37.4 | −110.0 | −0.976 |
| (8°, +8°) | +0.4 | −59.3 | −132.1 | **−1.192** |

`γ/e²`：roll ≈ **0.015 mm/度²**、pitch ≈ **0.0036 mm/度²**（γ 是长度量，与 k 无关）。

### 2.3 为什么单轴可以、双轴不行（五层）

| 层 | 机制 |
|---|---|
| 1 | 二阶残差**按轴叠加**，且随象限换向（C2 在 `+/+` 被抵消 54%，`+/−` 被放大 53%） |
| 2 | **时间尺度差 2.4 倍**：ROLL 45.6 / PITCH 110.2 counts/°，双轴被慢轴拖住 |
| 3 | **可用工作区比 UI 小**：`n̂>0` 只在 roll ∈[−18.3°,+15.0°]、pitch ≤33.7°；出窗后冗余塌缩成两缆，某些位姿两缆几乎共线（`(+14,0)` C1+C3 仅 6.2°、`(−18,0)` C1+C2 仅 2.2°、`(0,30)` C2+C3 仅 10.4°） |
| 4 | **位置模式稳态没有预紧**：只有死区+模型误差带来的 0.1~0.3 mm |
| 5 | **未建模的 R 误差 = 两个单回路之间的反馈通道**：`δθ ≈ Kp·e + (R_realᵀ)⁺(R_real−R_model)…`，谱半径可能 >1 |

### 2.4 位置环看不见松紧

- 松弛量 `S_i = P_i0 + (C_i−C0_i)/k_i − l_i(θ) ≥ 0`，**起环瞬间的 `S_i0` 被锚点保留**；
- 过紧会自愈（绳被拉长），**过松不会**（除非目标要求收绳）；
- C2/C3 在整个工作区的行程只有 **0.73 / 0.63 圈** → 松超过这个数就是死绳；
- 现有 `⚠松绳` 只是提示，**不阻止**闭环运行。

**建议的改法（尚未落地）**：`θ_cmd = clamp(θ*+δθ)` → `out = origin + k·[l(θ_cmd) − l(ref)]`，
残差 1.19 mm → **0**；限幅移到位姿域（按最贵的绳折算）。

## 3. 位置环实现

| 结构 | 基准 | 表达式 |
|---|---|---|
| **前馈 + PID** | 进入时的 `origin` + 参考位姿 `ref` | `out = origin + k[l(θ*) − l(ref)] + J·δθ` |
| **纯 PID** | **实测位置** | `out = 实测 + J·δθ` |

$$
\delta\theta = K_p e + K_i\!\int\! e\,dt + K_d(-\dot\theta_{fb}),
\qquad J_i = -k_iR_i\frac{\pi}{180}\ [\text{counts/deg}]
$$

- 偏差在**关节角域**算，再经 `J` 折到 counts；积分钳在 `±target_limit_deg`；
  微分作用在**反馈角速度**上（不是误差跳变），一阶低通 `α=0.25`；
- 目标先钳"限幅° ∩ 模型行程"，`θ*` 是运行中的目标，`ref` 只在启动瞬间取一次；
- 门禁：两种结构都**必须载入标定**（没有 k 就没有"角度→counts"）。

## 4. 张力控制（每缆独立）

### 4.1 数据链

```
ZNSV 变送器 250 Hz → raws[8]（1 raw = 1 g，受拉为负）
   → f_i = raw × (−0.00980665 N/raw)        # 受拉为正
   → _tension_last = (时间戳, [f1,f2,f3])    # 控制与守卫唯一数据源
```

年龄即安全判据：启动 >0.5 s 拒绝；逐拍 >300 ms（`STALE_MS`）**冻结**；守卫同 300 ms。

### 4.2 每拍流水线（100 Hz）

> **为什么不是 200 Hz**（2026-11-14 实测文档）：舵机总线是 10 ms 周期
> （`ServoConfig.h`：`kServoBusServicePeriodMs=10`、`kServoFeedbackCollectDelayMs=3`、
> `kServoFeedbackDeadlineUs=4000`，还有 `static_assert` 要求这套时序塞进 10 ms）。
> 位置反馈（ABS）因此**就是 100 Hz**；把 P4 控制任务改 5 ms 只会每拍 overrun。
> 试过一版 200 Hz/10 counts，已全部退回 100 Hz/20 counts。

```
_cl_tick
 ├ 张力守卫：过载→停环；过期→标记；阈值非法（🛡开）→ fail-closed 停环
 └ _cl_tick_tension
    ├ _tension_params()          读 UI（每拍）
    ├ _force_tick_prelude()      关节越界 / 张力丢失 → 停环
    ├ wrist_tension_step()       每缆 PI → trim
    └ _apply_force_step()        out = 实测 + trim → 夹 base±trim限幅 → 一帧 0xD3
```

### 4.3 律

$$
e_i=f_i^*-f_i\ (|e_i|\le0.05\Rightarrow e_i=0),\quad
u_i=\operatorname{sat}_{\pm u_{\max}}\big(K_p e_i+\operatorname{sat}_{\pm I_{\lim}}(K_i I_i)\big)
$$

$$
s_i=\operatorname{round}(\rho_i+u_i),\quad \rho_i\leftarrow\rho_i+u_i-s_i,\quad
\boxed{\text{trim}_i=\sigma_i s_i},\quad
\boxed{C_i^{\rm cmd}=\hat C_i+\text{trim}_i}
$$

三个设计点：
- **P 作用在 `e` 上**（不是 Δe）→ 误差恒定时也每拍走 `Kp·e`，**位置即积分**，`Ki=0` 也能收敛；
- **条件积分**：只有 `|raw|<u_max` 或 `raw·e<0` 才累加 → 饱和时冻结；
- **残差进位**：`<1 c/拍` 的小误差用 `ρ` 攒起来，不丢。

### 4.4 抗饱和三件套（当前值）

| 机制 | 值 | 作用 |
|---|---|---|
| 每拍限幅 `u_max` | **20 counts/拍**（2000 c/s） | 速度上限；`u_max × 频率` 必须等于舵机 steps/s |
| 积分贡献钳制 | **已关闭**（2026-11-14，见下） | 积分实际封顶在 `max_step − Kp·abs(e)` ≈ **17 counts → 顶偏 1.13 N** |
| 积分状态钳制 | `±i_term_lim/Ki` | 只钳贡献不钳状态会让状态无限涨 → 反向滞后无界 |

> **2026-11-14 变更**：积分钳制**已关闭**（`TENSION_I_TERM_LIM_ENABLED = False`，
> `i_term_lim` 退回 `max_trim`）。原因是绳子有**松绳/紧绳两种状态**，同一个 count 在两态下
> 含义不同。关闭后积分**仍被条件积分兜底**（`|Kp·e+Ki·I| ≥ max_step` 就停），
> 实测封顶 **17 counts**（`max_step=20, Kp=15`）→ 顶偏 **1.13 N**、反向峰值 **2.91 N**、
> 回位 **1.94 s**（钳 5 counts 时是 0.33 N / 2.13 N / 1.03 s）。想收回来把开关改回 `True`。

### 4.5 整定：先测 `S`，再定 `Kp`

`f_{n+1}=f_n+S·\text{step}`，未饱和时 `e_{n+1}=(1−S K_p)e_n`：

$$
\boxed{0<S K_p<2\ \text{才稳}},\qquad
K_p\approx\frac{0.2\sim0.5}{S},\qquad K_{p,\max}=\frac{2}{S}
$$

**测 `S`**：电机使能保持，给某缆 +100 counts（0.92/0.84 mm），读 `Δf`，`S=Δf/100`。

**本机**：`S = 0.0506 (C1) / 0.0464 (C2/C3)` N/count ⇒ 推荐带 `4.0~10.8`、上限 `39.5~43.1`。

**当前取 `Kp=15`**（`S·Kp = 0.70~0.76`）：有意超出保守带，为的是
`Kp·e(1 N) = 15 < 20` 能用满每拍限幅（1 N 大步 2 拍）；抖动实测与 Kp=10 相同（2 counts）。

### 4.6 `Ki` 与积分时间

$$
T_i=\frac{K_p}{K_i}=\frac{15}{20}=\boxed{0.75\ \text{s}}
$$

**这不是"积分很大"**：`Ki=20 counts/(N·s)` 换成力就是 **0.93 N/(N·s)**，`Ti=0.75 s` 属常规区间。
本律里 **`Kp` 才是主积分**（位置 = Kp∫e），显式 I 只是"最多 5 counts 的微调旋钮"：
**钳制决定它能到哪，`Ki` 只决定它多快到。**

实测（`u_max=20, i_lim=5, 反向到 1.8 N`）：

| `Kp` | `Ki` | 反向峰值 | 多冲 | 回位 | 破 3 counts 静摩擦 |
|---|---|---|---|---|---|
| 10 | 5 | 2.310 | 0.51 | **3.56 s** | 2.20 s |
| 10 | 20 | 2.264 | 0.46 | 0.90 s | 0.60 s |
| **15** | **20（现在）** | **2.125** | **0.32** | 1.03 s | 0.35 s |
| 15 | 50 | 2.125 | 0.32 | **0.43 s** | **0.13 s** |

稳态抖动与钳制大小无关（**2 counts = 0.093 N**，由死区+噪声决定）。
`Ki=0` 的代价：有摩擦时永远差 0.1~0.15 N 不动。

## 5. 张紧控制（`t = f·n̂`，τ 守恒）

```
t_meas = Σ f_i·n̂_i      （预紧力，沿零空间）
e      = t* − t_meas     → _incr_step（同一执行器）
Δf_i   = e·n̂_i           （各缆分到不同张力增量）
trim_i = trim_sign_i · Δf_i/S   （力→counts）
```

- **只控 1 个量**（`t`），三个自由度里用它管"预紧"，位姿由 τ≈0 近似保持；
- **零力矩靠 `Δf ∥ n̂`**：`Δτ = R·Δf = e·R·n̂ = 0` —— 所以它**不新增**力矩，
  但**也不会消掉已有力矩**（`f` 垂直于 `n̂` 的分量永不动）；
- **入口可行域**：`f_min/min(n̂) ≤ t* ≤ f_max/max(n̂)`，否则拒绝启动；
- `f_min` 方向地板（v8.3）：贴地禁放 + 清积分/残差（会破坏 τ 守恒，已知）；
- `n̂` 不存在（非全正）→ `FORCE_NO_NULL`，停环。

### 5.1 增益同样受 `S·Kp < 2` 约束（2026-11-14 修正）

张紧和张力是**同一个单缆一阶模型**：`e_{n+1} = (1 − S·Kp)e_n`。
本机 `S = 0.0464 N/count` ⇒ **`Kp_t,max = 2/S = 43.1`**。

旧默认 `Kp_t = 50`（`S·Kp = 2.32`）**越界**，用真实律实测：

| `Kp_t` | `S·Kp` | 实测 `t` 行为 |
|---|---|---|
| **50（旧默认）** | **2.32** | **4.30 ↔ 5.67 N 以 50 Hz 等幅振荡，摆幅 1.38 N** |
| 25（部分机器保存值） | 1.16 | 收敛但临界，末段摆 0.08 N |
| **10（现在的默认）** | **0.46** | 平滑收敛，末段摆 0.11 N（含积分抖动） |

⇒ 默认改为 **`Kp_t=10 / Ki_t=20`**，积分钳制与张力一致（**5 counts**）。

> 同样的越界也存在于**力矩模式内环**：`trim_gain=50` 且 `P=I=trim_gain`
> ⇒ 每缆增益也是 `S·50 = 2.32`。**该项尚未修改**，见 §9。

## 6. 力矩控制（τ PI + TDA）

```
τ_err = τ_d − τ_meas,  τ_meas = R·f
u     = K_pτ·τ_err + K_iτ·∫τ_err        （关节域 2 维）
f_d   = P⁻¹·u  （TDA：在 f ≥ f_min、f ≤ f_max 的正多面体内分配）
α     = 饱和缩放（0~1）
trim  = trim_gain·(f_d − f)·(1/S)
```

- **TDA**：把"期望关节力矩"分配到三缆，保证 `f ≥ f_min`（正张力）且不过载，同时 `R·f = τ_d`；
- `α<1` 表示目标力矩不可达，此时**冻结积分**（抗饱和）；
- 内环是**逐缆对角**（`trim ∝ Δf/S`），`R·Rᵀ` 的耦合靠外环积分吸收（不是论文的解耦律）。

**默认值警示**：`Kp_τ=100` 在多数场景全程饱和（α≈0.065），实际是"高 P + 边界推"；建议从 2~5 起。

## 8. 安全与门禁

**启动门禁**（顺序固定）：J16/J17 有数据 → 位置模式要标定 / 力控要张力新鲜(≤0.5 s)且参数合法
→ 至少一绳 → **P4 活动域包含全部勾选电机**。

**逐拍守卫**：`f > f_max` → 停环；样本过期 → 冻结（不发指令，电机保持）；
关节越界（`|roll|>30°` 或 `pitch∉[−30,50]`）→ 停环；阈值非法且🛡开 → fail-closed 停环。

**活动域陷阱**：单机帧 `0xDE`（点动/Go/手填）会把活动域改写成"就这一台"，
之后 `0xD3` 批量帧被掩码削掉 → "只有一根绳动"。
**对策：点动后必须急停 → 重新「使能直控」，再起闭环/紧绳。**

**符号不变量**：`sign(trim_sign_i) = −sign(k_i)`，逐路检查；标定行红字 + `CL_START` 安全日志。

## 10. 台架操作（速查）

**每次开跑前**

```
□ 张力串口通、龄 <300ms
□ trim方向 = 1,-1,-1，三根都 +100c 点动核对过，界面红字消失
□ fmin/fmax 填真实值（fmax 是唯一过载保护）
□ 做过点动 → 先急停 → 重新使能（活动域）
□ 三缆绷紧（或先一键紧绳）
□ 每拍限幅 20 / Kp_f 15 / Ki_f 20
```

**四模式建议顺序**：张力（2~3 N，验方向/帧率/S）→ 张紧（看 `t` 能否稳）→ 力矩（`Kp_τ` 从 2 起，盯 α）→ 位置（走轨迹）。

**常见故障**

| 现象 | 原因 | 处置 |
|---|---|---|
| 只有一根绳动 | 活动域被点动收缩 | 急停→重新使能 |
| 张力锯齿 ±0.1 N 以上 | `S·Kp` 太大 | Kp 减半 |
| 到位慢、差 0.05~0.15 N 不动 | 静摩擦，积分没起作用 | `Ki` 提到 20~50 |
| 反向冲 0.3~1 N 才回来 | 积分顶偏（= `5/Kp`） | 减小钳制 或 加大 `Ki` |
| 一启动就过载停 | `f_target > f_max` | 改 f_target（R14 待做） |
| 闭环命令跑但张力不动 | 舵机速度寄存器没升 | 烧 2000 steps/s |
