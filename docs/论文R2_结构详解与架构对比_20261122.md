## 二、论文的完整控制结构（四层）

```
┌ ① 任务层（可选，式22）───────────────────────────────
│   τ_d = −K(q − q_d)                    刚度/阻抗外环
│   （论文原话：可"在力矩控制器外面再套一层刚度控制器"）
├ ② 分配层（§5，算法2）─────────────────────────────────
│   f_d = α·v + t·w,   v = R⁺τ_d,  w = Wᵀ
│   先 max α（保力矩）→ 再 min t（省张力）
├ ③ 控制层（两条并列）──────────────────────────────────
│   腱空间：u = −k_p(f − f_d) − k_d·ẋ              (21)  ← 有 RRᵀ 耦合
│   关节空间：u = −P⁻ᵀ·K_p(τ − τ_d) − k_d·ẋ        (30)  ← 解耦（贡献②）
│       K_p = diag(k_p·I, k_pi)   关节空间 + 内部空间两套增益
├ ④ 执行器（硬件）─────────────────────────────────────
│   sX = G(s)·U     电机+减速器+丝杠；G ≈ G(0)
└ 腱/关节：f = k_t(x − Rᵀq)，τ = Rf
```

**两个容易忽略的细节**：

1. **底层输出的是电压/电流 `u`，不是位置目标** —— 执行器有动力学 `G(s)`（式23）。
2. **阻尼用执行器实测速度 `ẋ`**（"同位/collocation"），不是关节速度 `q̇`
   —— 论文原话："位置反馈与阻尼项就会因为腱-导管传动的未建模动态而滞后"。

## 三、关键公式（编号 → 含义）

| 式 | 内容 | 一句话 |
|---|---|---|
| (1) | `τ = R·f` | 关节力矩 = 腱映射 × 张力 |
| (5)(16) | `f = α·v + t·w`，`v = R⁺τ*`，`w = Wᵀ` | 解 = 力矩解 + 预紧方向 × 系数 |
| (11) | `f = k_t(x − Rᵀq)` | 腱是线性弹簧 |
| (12) | `τ = (τ; t)`，`t = W·f` | 增广力矩（含内部张力） |
| (13)(14) | `f_min ≤ f ≤ f_max`，`Rf = ατ*` | 界约束 + 力矩可打折 |
| (15) | `f_max/f_min ≥ max(w_i/w_j)` | 可行点存在的设计条件 |
| (20) | `f_d = P⁻¹τ_d` | 腱空间：逆矩阵求目标张力 |

| **(22)** | `τ_d = −K(q−q_d)` | **论文自带刚度外环** |
| (27) | `Q = [I + sK̃⁻¹RRᵀ]⁻¹Q_d` | 腱空间闭环：**有耦合** |
| **(30)** | `u = −P⁻ᵀK_p(τ−τ_d) − k_dẋ` | **关节空间律（贡献②）** |

## 四、你的架构 vs 论文（逐层对比）

| 层 | 论文 | 你 | 差异性质 |
|---|---|---|---|
| **任务** | `τ_d = −K(q−q_d)`（式22，可选）| ✅ 阻抗模式（K/D 可调，`τ_ff=0`）| **同构**；你多 `D` 项，缺 `τ_ff` |
| **分配** | 算法 2：**内生解 (α, t)** | 闭式第 1 步 + **外部钳制 τ** | **你缺迭代**（α 由外部二分代替）|
| **控制** | 腱空间逐腱 **PD**（电压）；或关节空间 `P⁻ᵀ` | 逐缆 **张力 PI**（增量式）→ 位置增量 | **你多积分（抗摩擦），少 `P⁻ᵀ` 解耦** |
| **执行器** | 电压 `u` + 速度同位反馈 | 位置指令 `0xD3` + 舵机内环 | 论文更"底层"；你更简单、更安全 |
| **传感** | 每腱张力 | 三缆张力 250 Hz | 相当 |
| **失效降级** | 专利三级（力→位置+柔顺→纯位置）| 只有"停环" | **你缺 graceful degradation** |
| **阻尼反馈** | 执行器速度 `ẋ`（同位）| 无（D=0 框架）| 你缺 D 的物理输入 |

## 五、我之前提议 vs 论文（逐项判定）

| 我的提议 | 论文有没有 | 判定 |
|---|---|---|
| 闭式 `t = max(s_lo, t_floor)`，`α≡1` | 算法 2 **第 1 步** 就是 `t = max_i(f_min−v_i)/w_i`；但论文**不固定 α≡1** | ✅ **第 1 步一致**（数值逐位相同）；❌ **我缺 α<1 的迭代** |
| 外部"能力二分 + 钳制 τ" | 论文在**算法内部**解出 α，不需要外部钳制 | ⚠️ 我的做法是**替代方案**，能跑但不是论文口径 |
| `t_floor`（预紧下限）| 论文**没有**这个概念（由 `f_min` 承担）| ➕ **我的扩展**（对你有用：保刚度/余量）|
| "用 QP 做分配" | ❌ **论文没有 QP** | ❌ **我的错**（已更正）|
| "α 是退路，不是分配方法"| ❌ 论文把 α 当**决策变量**（与 t 联立求解）| ❌ **我的错**（已更正）|
| "1 维零空间 ⟹ 最优解在端点" | 论文 §5 有等价论证（盒子与直线不平行 ⟹ 最近点唯一）| ✅ **一致** |
| 阻抗层 `τ = K(q*−q) + D(q̇*−q̇) + τ_ff` | 论文式(22) 只有 `τ_d = −K(q−q_d)` | ✅ **论文本来就有这一步**；`D`、`τ_ff` 是我的补充 |

## 六、你离论文还差什么（按重要性）

| # | 差距 | 论文做法 | 你要做什么 | 工作量 |
|---|---|---|---|---|
| **1** | **分配用外部钳制，不是内生 α** | 算法 2 第 3–7 行（2×2 解 α,t）| 补那 4 行 | **~30 行** |
| **2** | **没有 `P⁻ᵀ` 关节空间解耦** | 式(30)，`K_p = diag(k_p I, k_pi)` | 改控制律结构（不是加参数）| **大改（~200 行）** |
| **3** | **`f_min` 数量级差 44 倍** | 8.9 N（保预紧 + 抬到噪声之上）| 把 `f_min`/`preload` 提到 3~9 N | 改参数 |
| **4** | **无传感器失效降级** | 专利三级 + 零空间投影 | 加状态机 | ~100 行 |

**注意第 2 条**：`P⁻ᵀ` 是论文的**核心贡献**（标题里的 "Decoupled"），
但它是**改整个内环结构**——你现在是"τ→张力→位置"串级，改 `P⁻ᵀ` 意味着
"τ 误差直接乘 `P⁻ᵀ` 变成电机命令"，**没有张力环**（或张力环变成外层）。

## 八、一句话结论

> **论文 = 算法 2（内生 α,t 的两阶段 LP）+ `P⁻ᵀ` 关节空间解耦（快 25%），无 QP。**
> **你 = 闭式第 1 步（与论文逐位相同）+ 外部钳制 + 张力 PI（比论文多积分）+ 阻抗框架（与式22 同构）。**
> **差距：① 补算法 2 的 4 行（小）；② 上 `P⁻ᵀ`（大，是论文核心）；③ 把 `f_min` 提到 N 级（改参数）。**
> **你比论文多的：张力 PI、明确告警、位姿钳制、`t_floor`、`τ_ff`（待补）。**
