## 2. 为什么这么做（四个决定）

### 2.1 为什么积分钳制最后落在「5 counts」

中间试过三种口径，差别很大，值得记下来：

| 口径 | 换算 | 值 | 实际力当量 | 能顶偏 |
|---|---|---|---|---|
| 1 N 力当量 | `1 ÷ S` | 19.75 c | 1.0 N | **1.98 N**（太大） |
| 顶偏 0.1 N | `0.1 × Kp` | 1 c | 0.046 N | 0.10 N（太小，破不了静摩擦） |
| 0.1 N 力当量 | `0.1 ÷ S` | 1.975 c | 0.1 N | 0.20 N |
| **5 counts（现在）** | 直接给 counts | **5 c** | **0.23 N** | **0.33 N**（Kp=15） |

**为什么 5 而不是 2**：2 counts 只能破 2 counts 的静摩擦；5 counts 能破 **3 counts**，
台架上更不容易"差一点点就是不动"。代价是反向多冲 0.32 N（而不是 0.19 N），可接受。

**教训**：同一个"0.1 N"在三种口径下差了 10 倍。以后统一用 **counts** 说话，
写清楚"这是积分贡献、还是它产生的偏置"。

### 2.2 为什么 `Kp=15`

`Kp` 本来该由绳刚度定：`Kp ≈ (0.2~0.5)/S` = 4.0~10.8。取 15 是**有意越界**，理由两个：

1. **`Kp·e(1 N) = 15 < 20`**：只有 Kp 足够大，`每拍限幅=20` 才用得上；
   Kp=10 时 1 N 误差只发 10 counts，20 的限幅永远吃不满 → 1 N 大步要 4 拍；Kp=15 → **2 拍**。
2. **偏置反而更小**：积分能顶偏 `5/Kp`，Kp 越大越小（0.5 → 0.33 N）。

代价：`S·Kp = 0.70`，超出保守带（0.2~0.5），但离稳定上限 2 还有 2.9 倍余量；
实测稳态抖动与 Kp=10 一样（2 counts）。**如果台架上出现抖动，第一件事是把 Kp 退回 10。**

### 2.3 为什么 `Ki=20`（看起来很大）

因为 **`Ki` 在这条律里不是"积分增益"，是"积分器的转速"**：

- 积分贡献被钳死在 5 counts → **钳制决定它能到哪**；
- `Ki` 只决定它多快到、多快退 → 给小了就是"又慢又没用"（Ki=5 时反向要 **3.56 s**）。

换成教科书写法就正常了：

$$
T_i=\frac{K_p}{K_i}=\frac{15}{20}=0.75\ \text{s}
$$

常规区间 0.1~10 s，0.75 s 在中间。`Ki=20 counts/(N·s)` 换成力是 **0.93 N/(N·s)**。

### 2.4 为什么 `每拍限幅=20` + 舵机 2000

- 闭环 100 Hz，`20 counts/拍 × 100 = 2000 counts/s`；
- 舵机寄存器低于这个数 → **命令跑在舵机前面**，有效速度被舵机卡住（R8），
  多出来的量程只是"目标超前"，没有任何速度收益；
- 所以两者必须配对：**要么 (20, 2000)，要么 (10, 1000)**，别错配。

物理含义：2000 c/s × 0.0464 N/count = **93 N/s**（原来 46 N/s）。张力响应快一倍。

## 4. 今天修掉的一个真 bug

**积分只钳贡献、不钳状态**：

```python
i_term = clamp(ki*integ, ±lim)     # 只钳了"贡献"
raw    = kp*e + i_term
if |raw| < max_step: integ += e*dt  # → raw 永远够不到 max_step ⇒ 闸门永远开
```

后果：`∫e` 状态无限增长（钳制一卡住，`raw` 就不再饱和），反向时要按状态绝对值慢慢退
→ **"反向滞后"变成无界**。修法：把状态也钳到 `±i_term_lim/ki`。
